## 尚未覆盖，不宣称与生产客户端完全等价

- 当前仍为24个演示采集项，并非55份静态规则对应的完整任务注册目录。正式迁移应直接使用后端贡献列表，不能维护第二套人工任务注册表。
- 身份管理已有节点、申请、登录、服务启停和参数诊断；读失败保留旧快照的过期提示、协议汇总和刷新状态仍需设计。
- 运行详情仍需补足未知总量、Redis-only、无需归档、连续覆盖范围和失败单元清单等专项状态。现有数字仅说明版面。
- 未补 Ctrl+F/Ctrl+S 和跨页返回原筛选；尚未将归档页面与执行计划统一为完整应用状态模型。
- 所有操作仅改变当前预览内存，刷新或关闭即丢失；没有生产后端、真实运行或真实写库。静态规则快照需随来源规则更新。
