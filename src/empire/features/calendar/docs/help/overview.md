# 交易日历

## 浏览细节

切换月份时清除旧日期说明；同月刷新仍保留所选日期，并重新显示来源状态。所选未知日期刷新后仍是未知，不按周末推断休市。

## 如何查看

打开交易日历，默认“月历”；选择年份、月份，或用上个月、下个月、回到本月导航。“日期清单”保留准确逐日值，点击月历日期查看该日说明。交易、休市、未知和来源范围外分别显示；周末缺数据仍是未知，不自行推断休市；未来安排可能修订。

## 数据范围与更新

来源巨潮。首次补齐 1990-12-19 至下一自然年 12 月；后续维护本月至下一年 12 月，并补历史缺月。按整月校验、归档，未来安排可被后续来源修订。

## 字段与日期

每个自然日保存日期与交易标记。已保存交易日、已保存休市日、尚未采集是三种不同状态；缺日不能按周末规则补成休市。月确认及可用摘要可补充时效证据。

## 限制与排错

空月、缺日、重复、跨月日期或非法标记会失败，旧月份不被异常响应覆盖。SQL 与匹配缓存证据共同验收，不让较新时间掩盖缺日；Redis 缺失回 SQL 证据，不为变绿写库。
