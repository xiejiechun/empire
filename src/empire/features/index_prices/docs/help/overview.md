# 同花顺指数历史日行情

## 浏览细节

开始、截止日期均有持续可见标题，范围预设在返回时不覆盖自定义草稿。展开数据说明可核对来源限制；图表显示实际区间和来源点数，不把所选日期范围当作完整覆盖证明。

## 如何查看

打开同花顺指数历史日行情，选择指数名称/来源代码候选；首次日期草稿为最近一年，可改最近一季、一月或自定义，然后查询。默认日K线，可切收盘线，下方量额分面板；鼠标或方向键核对日期，按钮缩放/平移/全范围。图表读取整个指定范围，上限40年及15000日，超限拒绝截断；日线明细每页200条。四价缺失或关系异常留缺口，有效收盘仍可单独画线，原值在明细；成交量为来源单位、额为元，不套股票复权。

## 数据范围与更新

独立采集任务每天北京时间18:00运行，可编辑计划、启停、重试及代理选择，保存到MySQL，下一轮生效。初始化读取last的来源年份目录，再按YYYY补齐缺年；普通更新回看last近期窗口，年度计数变化及窗口外断档按年补齐。从头采集回查全部来源年份，保留已有历史。年度通过共享有界预取下载、按序入队后继续，不逐年等待归档；整轮处理成功才完成。中断按已入队年份续跑，Redis丢失依据SQL年度证明补年；既有历史不随当前目录变动删除。

## 字段与日期

一指数一交易日，开盘、最高、最低、收盘为指数点数；成交量保留来源数值，成交额按接口人民币元显示，不擅自对特殊指数换算口径。使用同花顺六位字母数字代码，不能套股票统一代码。盘中当天不写收盘日线，15:30以前去掉当天；来源最早日并非指数成立日期。数据准备“指数每日价格行情”独立核验，范围栏新增指数代码输入，股票代码仍用于股票/财报检查；留空指数核验当前来源目录，日期范围与实际年度正文核对，不要求基本资料、成分或权重完成。

## 限制与排错

仅来源支持的代码及历史；last.js的HTTP404标为接口当前不可用，不能推断零行情，已有历史保留。网络错误、登录页、JSONP身份错配、重复、数量或集合不一致均失败、不推进对应断点。last通常140条，但以实际num和year核验，不当完整历史。YYYY包括成交额，all压缩响应不作为正式采集路径。last已声明的年度文件临时404按任务重试预算重试，退避、频控和出口分配由共享下载器执行；耗尽仍失败保留年份断点，不跳过或标作无历史，正常响应不重复下载。来源早期四价相同等原值保留；缺失开盘、最高、最低价存NULL并显示“来源未提供”，不代填。数据准备统计范围内缺失条数，收盘收益分析可用，依赖缺失价格的策略不可用。历史较早修订仅从头回查发现，不提供过去可知版本，量额研究须核实指数口径。

来源开高低收关系矛盾时仍保留全部原值，查询的“数据质量”显示“价格关系异常”。采集完整与数据质量分别检查：年度日期集合完整可归档，数据准备质量项仍失败，受影响日期不用于依赖四价的策略；不能据此保证收盘正确。异常不置空、不改价，来源修订仍按版本防止旧响应覆盖。

来源负成交量或负成交额保留原值，数据质量显示“量额异常”，按所选日期统计异常条数；不影响收盘收益分析，依赖量额的分析和策略不可用。真正无法解析或越界的数字仍失败，错误详情明确指数、日期、字段及有界原值，失败不推进年度断点。

收盘后当日接口也可能短暂返回占位行（开高低全空、成交量0、成交额空）。近期接口出现占位时暂缓当天，下一轮重查，不覆盖已存当天及年度证明；年度接口最新日期可能仍是占位或较早盘中行情，缓存滞后可跨午夜或休市日；按本轮近期快照的最后日期采用其非占位有效行，年度日期身份、数量和更早历史内容仍须一致。历史缺值保持原值，近期最后行仍是占位时不覆盖年度；缺日、更早历史差异及非法字段仍报错保留断点，不自动反复下载；观察时间不保证源站已公布最终版本。

成交额来源空值也显示“来源未提供”，数据质量列提示“来源缺少成交额”，不能根据成交量0推断成交额0；已有收盘和日期可用于基础收益分析，依赖成交额的策略不可用。数据准备按所选日期范围统计缺额，年度完整不代表来源量额字段齐全。
