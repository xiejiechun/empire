# 同花顺三大报表

## 浏览细节

窄窗口仅有一只证券时默认收起证券列表，可点击“展开证券列表”；多结果列表最多四行，为科目矩阵留空间。返回恢复列表展开、摘要报告期、矩阵横纵滚动与科目折叠。图表开关直接使用财报科目名，累计与时点口径保持分别标明。

## 如何查看

分别打开利润表、资产负债表、现金流量表，按证券名称/代码候选选择准确市场。左侧证券列表、右侧完整报告矩阵；科目搜索覆盖本证券全部已读取科目，双击分组可折叠，万元/元/亿元切换，按报告期或年度显示。摘要可切换报告期；趋势标签展示三项核心来源科目，利润/现金流为累计口径，资产负债为时点口径，不推导单季度。来源质量警告和未知值仍可从明细核对。每证券完整报告查询上限500期，超限报错而不截断。

## 数据范围与更新

当前沪深北股票池，按来源 report 口径完整历史矩阵采集。普通执行继续证券断点，完成后的新轮全历史回看补缺和修订。日期保留来源原值，包括非季度末与早期年份；不补造来源缺报季度，不承诺退市证券覆盖。

## 字段与日期

金额含来源万/亿舍入，科目名称、单位和精度保留；未知不填零，来源矛盾不自动更正。三表独立采集；不自动计算单季度或 TTM，不强制来源三表期间完全相等。

## 限制与排错

采集完整性、来源质量、用途条件分别显示。来源本身缺值或矛盾可以无损保存并标记；结构无效、矩阵截断、证券错配仍报错。没有公告日期，不宣称历史公告前选股可用；按请求代次防旧覆盖，不能识别源站旧缓存。
