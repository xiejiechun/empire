# 同花顺当前指数及成分

## 浏览细节

刷新目录及成员时保留所选指数身份；成员模式不重复指数名称和编号，证券反查仍显示这些信息。反查模式与空目录不启用历史行情入口，先选择明确指数后查看。

## 如何查看

打开同花顺当前指数及成分，左侧按来源分类字段展示目录，右侧直接读取所选指数成员。搜索指数名称/来源代码；“证券反查所属指数”为明确模式，统一证券代码保留市场。目录和成员分别分页；点“查看所选指数历史行情”带同花顺代码，成员可双击公司资料。暂无来源成员时旧成员标历史参考，不提供权重或历史调样。

## 数据范围与更新

每日 18:00 推荐完整刷新目录及当前成员，计划可编辑。每个指数完整单元校验后入队，继续下一指数，整轮末才确认归档。中断按已入队断点继续；Redis 丢失完整重查。只保存当前目录和关系，不保留历史调样。

## 字段与日期

目录保存名称、分组、成员可用性和数量；成员保留来源证券编号，市场可确定时关联统一代码。来源明确“暂无成份股数据”保存未知可用性，旧成员仅作历史参考，不推断真实零成员。

## 限制与排错

登录、截断、重复、身份不符不能标为来源暂无，也不能推进断点。源码关联不确定属于说明中的限制，不掩盖漏采。当前成员不用于还原历史选股；来源目录不代表官方全世界所有指数。通用响应额度不足时到下载资源保存并重启，不能静默提高已保存上限。
