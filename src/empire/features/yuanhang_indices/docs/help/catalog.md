# 同花顺远航版A股指数

## 如何查看

采集入口：在“同花顺远航版”平台分组选择“A股指数”。

选择“A股指数”任务的数据预览，搜索名称或指数代码；从指数进入对应成分。目录按当前客户端A股指数列表，保留沪深指数及北证50，也包含来源列出的基金、债券及B股指数。

## 数据范围与更新

每日18:00完整核验小目录，当前观测580项但不固定条数。先采集目录，再独立启动成分或日K；已保存计划优先。中断继续已入队轮次，整轮归档后完成；Redis丢失可重读目录。

## 字段与日期

指数保留六位来源代码和原生市场，不能套股票统一代码。只保存当前有效目录；退出仍保留指数身份和日K历史。

## 限制与排错

名称身份或完整目录不一致时报错，不发布部分目录；不提供历史目录、发布方、成立日或基准资料。
