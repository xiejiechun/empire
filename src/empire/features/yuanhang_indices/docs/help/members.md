# 同花顺指数成分

## 如何查看

采集入口：在“同花顺”平台分组选择“指数成分”。

在“同花顺”分组选择“指数成分”任务的数据预览，按指数查看来源成员及可用状态，也可搜索证券名称或编号。目录从远航获取，成分使用原同花顺网页接口。

## 数据范围与更新

每日18:00逐指数完整读取网页当前名单，不保存历史调样；需先准备远航目录。校验后入队即继续下一指数，整轮归档清队后完成；失败保留上次成功内容及已入队断点。Redis丢失重新读取当前名单。

## 字段与日期

来源证券编号和名称按原值保存；只有可靠沪深北股票前缀才关联统一证券代码。网页明确“暂无成份股数据”时当前名单为空、成员数为未知；此前名单从当前关系清除，不推断真实零成员。

## 限制与排错

北证50等网页暂无属于正常结果。网页可能存在成分口径疑点，上证180/380、基金指数等不保证等于官方编制名单；不补其他网站数据、不复制同名指数成员。网络失败、截断、身份错误不是暂无；当前名单不能用于历史成分回放。
