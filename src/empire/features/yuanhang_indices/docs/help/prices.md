# 同花顺远航版指数日K

## 如何查看

采集入口：在“同花顺远航版”平台分组选择“指数日K”。

选择“指数日K”任务的数据预览，筛选指数代码及日期，每页最多500条；观察日历和市场复盘也读取这一路正式日K。

## 数据范围与更新

每日18:00先核验最近十个已结束交易日，再每轮补最多64个指数历史缺口。首次历史从来源实际首日开始；显式重新采集核实所选指数全部历史。按年度入队后继续下载，整轮归档后完成。Redis存活续已入队断点，丢失按SQL可信区间补缺，不因缓存丢失重采全池历史。

## 字段与日期

一指数一个来源日期；开高低收、成交量和成交额均保留来源原值及NULL，不能填零。价格为来源指数值，量额为原生协议口径，不套旧网页换算。盘中不把当天当完整收盘；15:30前使用前个已结束交易日。

## 限制与排错

OHLC矛盾、负量额与缺值单独标质量，依赖这些字段的策略不可用。空协议帧缺乏完整覆盖证明时报错；不推断缺日为休市。十日窗口外的历史修订仅显式核验或已知异常时发现，不提供历史可知版本。完整历史证明与近期行情齐全分别判断。
