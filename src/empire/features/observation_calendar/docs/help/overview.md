# 多指标观察日历

## 如何查看

从顶栏“市场观察”进入，左侧首项为“多指标观察日历”，也可通过功能搜索直达。左侧菜单可收起/展开，与采集管理保持一致。选择已有指数、观察月份及两融市场，条件改变后自动读取；上月、本月、下月用于月份导航。“刷新数据”读取最新归档结果和已有今日Redis汇率快照，不触发采集。页面离开或条件变化会取消旧查询，失败显示错误，可重试。

默认只加载北京时间本月的完整月网格，不因追加历史缩短本月。本月成功读取后，点击月历顶部“向上加载更早月份”，或向上滚动到顶部，逐次在上方追加前一个完整月；追加后保持原可见日期位置，可连续比较多个月。加载中保留已有月份，历史读取失败时保留已读内容并提供重试；不自动全历史预载。月份导航选定观察末月，切换指数、两融市场、指标读取条件、月份或刷新时取消旧历史请求，重新从选定月加载。详情可在全部已读月份之间逐日切换，CSV仍只导出选定自然月。完整月网格不表示该月业务数据已采齐，未来或缺失值照常显示“—”。

点击“来源与口径”打开居中详情窗口，通过指数行情、市场成交、融资融券、汇率行情、交易日历、当月覆盖六个标签切换。各类展示采集平台、任务名称和ID、MySQL业务表、数据粒度及“观察指标—数据库字段—取值/计算方式”对应表；当月覆盖页集中查看所选月份的样本数量、Top限制与汇率日期提示，无提示不表示数据完整。窗口正文独立滚动，可用右上角或底部“关闭”、Esc退出，默认关闭，不占月历高度。日历读取失败仍直接显示错误。样本口径同时保留在指标设置、悬停、单日详情与CSV列名中。

顶部Redis操作区默认开启“自动刷新”，每次请求完成后等待30秒再读取，可设置1～3600秒；开关与秒数在本页面会话中有效，不写入保存视图。只轮询今天缺归档的已选汇率，历史月份或无适用项时不轮询。“刷新Redis”可立即局部读取，即使自动刷新已关闭也可使用。局部更新保留历史月份、滚动、详情及草稿，不重载整个页面、不重新查询SQL或触发采集。单项失败保留上次报价并显示异常，初次无报价的项目可在后续补入；过期状态仍按原采样时间判断。切换条件、开关、秒数或离页时取消旧请求并丢弃迟到响应。归档计算基准来自首次月历读取，新日线归档后点击“刷新数据”更新；跨北京时间午夜需重新加载今天，禁止把新日报价填入昨日。

“专注月历”暂时隐藏指数选择和指标管理，为月历让出更多空间；仍可切月、改密度、读取最新数据，退出后恢复设置区域。专注状态仅在当前页面会话有效，不改变已保存视图。“定位今天”切回北京时间本月并滚动到当天。

月历默认展示已选指标标签，点击“管理指标”展开指标库；“收起指标”恢复更多月历阅读空间，收起不改变已选项。指标颜色在搜索、排序与月历之间保持一致。点击已选指标标签可突出整月该项数据，其他指标淡化；再次点击或“取消指标追踪”恢复，数据和导出内容不变，追踪状态不写入保存视图。指标库支持名称搜索与行情、成交、资金、汇率分类；点击添加，在已选列表中用上下箭头排序或移除。周标题在月历滚动时保持可见，跨月日期显示月份，未来交易日显示“待交易日”。日期卡片在日期旁显示涨跌幅，正值标“+”，不在每格重复指数名称。点击日期打开单日详情，查看已选指标精确原值、单位和指数/市场口径；详情内可切换前一天/后一天（包含休市日，限当前已读取网格），不重新发起查询；切月、切换范围或刷新关闭旧详情。“当月已有行情”仅统计已读取收盘值的日期，不代表采集完成。支持紧凑、标准、详细三种密度。在“管理指标 → 已选指标”中点击每行的“设置”，直接打开该指标的范围、展示口径和高亮阈值；弹窗左侧仅列已选指标，可切换设置。修改先留在草稿，确认后应用并重新计算，取消不改变日历；之后点击“保存视图”才跨启动保留。市场指标可独立选择沪深京合计、沪市、深市或京市，指数指标使用页面当前指数。当前值保留原单位；环比变化为（当前值－前一交易日值）÷前值绝对值×100%，前值为零或缺失不计算。累计N日对非比例指标求和，比例指标提供N日算术均值，N为1～60个正式交易日；窗口不足或中间缺值不计算。高亮按显示后的指标单位填写大于等于阈值，留空不高亮；“异常高亮”统一开关。高亮仅表示达到自定阈值，不是交易建议或统计异常判定。

“保存视图”把指数、两融市场、指标及顺序、密度、高亮开关、各指标独立设置与阈值保存到当前电脑的桌面展示偏好。下次打开恢复已保存视图；未保存编辑离页丢失，月份每次默认北京时间本月。保存不改变任务或站点配置，不同步其他电脑。“导出数据”导出当前自然月、已选指标的CSV，包含日期、日历状态、未来标记、指数和两融口径；缺值为空、零值为零，数值保留原始精度，查看时请避免表格软件自动舍入。

## 数据范围与更新

只读既有正式指数目录、指数日行情、市场融资融券、远航个股日线、汇率日线和巨潮日历，不增加采集任务、第二份业务数据、业务表或Redis键。观察月份支持1991～2099年；实际数据范围由相应任务决定，未来日期不展示业务值。月历周一开始，显示相邻月份补齐完整周；导出仅包含当前自然月。

指数相关指标按所选同花顺指数；融资融券按沪深京合计、沪市、深市、京市独立来源口径，不代表指数成分股，不将合计与分市场相加。更新延迟与来源修订沿用原有采集规则。各服务有界读取，非跨数据集原子快照；归档期间不同指标可能反映不同更新时间。

月历右上工具行的“来源与口径”始终可用。指数行情来自同花顺远航版平台的指数日K任务ths-yuanhang-index-prices，事实表yuanhang_index_daily_price，yuanhang_index仅提供代码名称目录；沪深京成交额及Top来自股票完整历史日K任务ths-yuanhang-prices，读取yuanhang_daily_price.amount_yuan汇总计算；两融来自市场融资融券任务ths-market-margin，读取market_margin_daily；汇率来自历史日线任务ths-fx-daily，读取fx_daily_price.close；A股交易标记来自巨潮任务cninfo-calendar，读取trade_calendar.is_trade。窗口逐项列出字段和计算式，例如两融余额优先source_total、缺失才用financing_balance加lending_balance，查询别名total_balance不是存储列。fx_price_year仅年度覆盖校验，不作为收盘事实或本页直接读取表。页面读取归档结果，并在今天缺归档时补充已标识的Redis汇率报价；刷新不触发采集；来源窗口不因未选Top或汇率而消失。

## 字段与日期

支持指数收盘（点）、指数涨跌幅（百分数）、指数成交额与成交量（保留同花顺来源口径），以及沪深京成交额、融资余额、融资买入额、融资净买入额、融券余额、融券净卖出额、两融余额（元）、两融余额比例（来源小数转换成百分数）。两融余额沿用来源合计，来源缺失时由正式查询使用融资余额加融券余额。金额缩写为万/亿，悬停显示精确原值及范围。

沪深京成交额按来源日期汇总远航已归档沪深京个股的人民币成交额，与所选指数及两融市场独立；它是已归档样本合计，不是官方全市场总额或完整覆盖证明。未归档证券不进入合计；整日无记录或当日任一成交额缺值时不计算，不把缺值填零。支持当前值、环比及累计N日，在已选指标设置中配置。新视图默认加入；旧版保存视图首次读取时补入此项，其他偏好保留，之后可移除并保存。与Top共用同一次有界读取，不增加采集或存储。

指数涨跌幅是当日收盘除以前一正式交易日收盘减一，再转换为百分数。前一交易日行情缺失、前收为零或日历存在未知日期时不跨缺口推算。“—”为未取得可用值，不能当零；周末不自动推断休市。只有正式日历确认的休市日显示“休市”，缺日显示“日历未确认”。

## 融资买入/偿还比与Top成交额占比

融资买入/偿还比 = 融资买入额 ÷ 融资偿还额 × 100%，其中偿还额 = 融资买入额 − 融资净买入额。买入额缺失、净买入额缺失、偿还额为零或负数时显示缺值。融资净买入额和两融余额比例继续作为独立指标，不与买入/偿还比混用。

Top成交额占比默认滚动30个正式交易日、Top 5%，窗口可设1～60日，比例1～100%。每天以当日为窗口终点，按个股窗口内累计成交额降序排列，在有成交个股中取前Top%（数量向上取整），分子是这些股票的窗口累计成交额，分母是全部样本同期累计成交额。按远航已归档个股样本计算，不使用指数成交额作为分母，不按当前股票名单筛掉退市历史。“来源与口径”提供样本数量范围与覆盖提示：未归档证券不进入样本，单个证券缺少日期不自动判断为停牌或零成交，不能把样本结果视为完整市场比例。缺整日、窗口不足、存在成交额NULL或分母为零时不计算。实际结果不保证与参考截图一致。

Top只在加入观察指标后查询。按日期索引流式读取所需窗口，窗口最多60日，额外展示统计最多60日；历史辅助日期有界，最多读取250万行，超限明确失败，不截断计算。结果即时计算，不保存第二份行情或统计业务表，不触发采集。CSV列名带已应用范围、口径和Top参数，保持数值精度与缺值。

## 汇率日线观察

指标库“汇率”提供既有十二品种：美元指数、美元/人民币、美元/人民币(离)、伦敦金、欧元/美元、英镑/美元、美元/加元、美元/瑞郎、美元/港币、澳元/美元、美元/日元和美元/新元。每项独立添加、排序、设置和导出，可同时比较多个品种；新建视图默认加入离岸人民币，已有保存视图保留原选择，可手动添加后保存。

历史展示已归档收盘，不用实时快照补历史。按来源日线日期标签展示，A股休市或日历未确认时仍显示当天汇率；卡片和导出中的“A股”日历状态仅描述内地市场。来源日期标签的时区与最终时刻尚未确认，不将汇率和A股收盘宣称为同一时刻。无日线且无合格今日快照时显示缺值，不填零或前值，不推断外汇休市；来源OHLC关系异常时显示缺值及提示，不修写原始数据。

北京时间今天缺少该品种归档记录时，额外读取实时任务ths-fx-live已存的Redis最新报价。仅接受来源时间、来源更新时间及采样时间均属今天的快照，不把昨日缓存显示成今日；已有同日归档记录（包括异常记录）不覆盖。当前值名称改为“盘中”，Redis标志集中在顶部“专注月历”同栏；超过180秒未成功采样时顶部提示“采样过期”，详情仍保留真实旧采样时间。来源时间不是已确认的成交时刻，采样未过期也不保证来源报价新鲜。

盘中环比以最新报价对前一条归档收盘计算；盘中N期均值使用最新报价和前N−1条归档收盘，明确为估算，不改变历史统计或写入日线。基准不足或含异常记录时结果留空，详情仍可查看盘中原价。悬停及单日详情提供来源时间、来源更新时间、采样时间（北京时间）、原价与估算口径；CSV逐指标附来源、三种带时区原始时间、过期状态和盘中原价。汇率实时查询插件停用、无今日报价或失败不阻塞归档月历，原因在“来源与口径 → 当月覆盖”查看，刷新可重试。指数、沪深京成交额、Top及两融暂无匹配盘中快照，缺值继续保留。

每项设置提供当前值、环比变化、N期均值和高亮阈值。环比为当前收盘除以前一条已归档收盘减一，再乘100%；N期均值使用最近N条已归档日线，N为1～60。异常记录不跳过，窗口不足不计算。已归档记录之间可能缺少尚未采集的日期，计算不证明完整外汇交易日覆盖。辅助历史最多366自然日，每品种最多500条，超限明确失败。月历最多六位小数，详情、悬停和CSV保留精确原值与各品种报价单位，不做汇率换算。

## 限制与排错

没有指数目录时先到采集管理完成指数列表采集；指标缺失请检查对应任务覆盖。查询失败不显示旧月份结果，也不把失败伪装为无数据。查询插件或其依赖停止时明确不可用。观察页不自动补采或修改数据库；没有历史可知版本，不用于严格历史信号回放。

本版未接入北向资金、指数成分股范围及任意自定义公式。图中演示值不是本系统数据。窄窗口可横向滚动月历；鼠标滚轮不改变月份、数字和下拉框值。
