# 自算复权因子与行情

## 如何查看

在数据浏览的数据目录搜索“复权”，选择证券和起止日期，点击“加载K线”。首次日期草稿为最近一年，可查询上市以来已归档历史，最多150年。自动识别市场，也可明确选择SH/SZ/BJ。修改草稿后需重新加载；切换原始/前复权/后复权口径仍使用上次已加载结果。

图表覆盖整个查询范围，支持均线、缩放、拖动和逐日查看；因子明细每页200条。蓝色标记是实际参与计算的除权事件，定位后可跳转远航历史行情页查看同日输入。查询本身不启动采集，也不保存配置或另一份行情。

## 数据范围与更新

唯一行情输入是远航版已归档的不复权日线，唯一复权事件输入是同一来源的分红、送股、转增及配股。原先通达信方案/开盘啦价格不再作为本页输入；通达信预案、实施公告和名义股息率仍由分红业务独立提供。源数据修订后重新加载，结果按当前已归档版本重算，不另写SQL。

纯缩股作为负的每原股净股数变化计算，其他事件分量须全0。同日多条事件在原始权息表分别保留；协议不足以裁定合成口径时，仅显示原始K线并提示具体日期，不自动累加。普通流通股未知不影响纯价格复权，依赖流通股余额的分析仍须检查缺值。

## 字段与日期

区间首个交易日因子归一为1；前复权锚定区间最后交易日，后复权锚定首日。不同起点的绝对因子不能直接比较。原始OHLC乘对应乘数，成交量不复权。现金采用远航版每原股现金字段，不推算个人税后现金收益；除权日期是生效日，不能用作公告信号日期。

完整年度证明核对日线业务键和内容，联合响应证明同时核对权息与三类股本。来源完整历史序列允许停牌缺日，不自行补价，也不要求每只股票每天都有交易。

## 限制与排错

先运行“股票完整历史日K”和“权息与股本历史”，等待归档后再加载。年度证明缺失或正文不匹配时停止；权息证明缺失时仍可看通过核验的原始K线，因子与复权价格保持未知。所选区间包含来源OHLC关系异常时停止计算，原值和质量标记可在远航历史行情页查看。除权日没有行情、价格不合法、现金达到前收盘价或配股价格缺失时拒绝复权，不把缺输入当无事件。

只提供理论未舍入价格，可能与厂商显示算法有差异；不处理合并换股等其他事件，不模拟税、认购、现金到账或总收益，不用复权价作为成交价。数据准备的SQL时效只表示内容变化或回源确认；未核对Redis时不能冒充最新缓存核验时间。当前修订版本可用于普通走势分析，不证明历史时点可知版本。
