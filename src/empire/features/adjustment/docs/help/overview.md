# 自算复权因子与行情

## 浏览细节

市场、证券、开始及截止日期有明确字段标题，证券框回车可提交查询。返回仍分别恢复已应用结果和编辑草稿；数据说明及方案回链保留。

## 如何查看

打开自算复权因子与行情，选择证券及市场，首次日期草稿为最近一年，再加载K线。原始/前复权/后复权切换、均线及计算基准常驻；修改草稿未加载时旧图标明原条件。蓝色标记表示参与计算的除权事件，光标定位该日后可打开对应分红或配股方案，直接定位业务键与输入。因子曲线在单独标签，首日为1只属于本查询范围。缺价、缺配股输入或方案歧义具体提示，仍可切原始行情，不能将原始图标成已复权。

## 数据范围与更新

输入为已归档的通达信分红送转、配股和开盘啦收盘后行情。按所选范围和当前内容重新计算，结果不另写 SQL，不复制一份长期业务行情；源数据修订后需重算。

## 字段与日期

首个输出交易日累计因子归一为 1；前复权以所选截止日为基准，后复权以区间首日为基准。原始开高低收乘价格因子，成交量不调整。相同因子绝对值不能跨不同起点比较。

## 限制与排错

缺输入、核心字段未知、同日多方案有歧义或不能确定除权参考价时拒绝计算，不当作无事件。理论未舍入公式不承诺逐值等于交易所或厂商算法；不模拟税、现金到账、认购支出或总收益，不把复权价当实际成交价。

## 相关说明

分红预案、取消与终止不进入因子。历史实施记录均保留，同日并列方案拒绝；同报告期不同除息日的多条实施也因缺稳定事件关联而拒绝，不按金额相似合并，也不当独立事件叠加。即使其中一条在计算起点之前，另一条在范围内，仍需明确关联。此处计算事后理论价格，不提供股息率、现金收益或修订前的历史可知版本；报告期或最早预案公告日不能替代实施修订可用日。
