# 复权计算契约

## 字段与维护

理论参考价=(前收盘价－每股现金＋配股价×每股配股数)/(1＋每股送转数＋每股配股数)，累计因子乘以前收盘价/理论参考价。使用50位Decimal计算，理论参考价不按交易所最小报价单位舍入。adjustment.query.calculate是严格复权计算入口；页面history沿用同一输入与计算核心，复权失败时仅绘制通过价格校验的原始OHLC，无效日期保留缺口，因子和复权价格保持空值，输入摘要、日期范围和empire-ex-rights-v1算法版本随结果返回；SQL使用单一只读事务快照，核对来源完整单元及规范摘要，不新增表、队列、Redis正文或DDL。
