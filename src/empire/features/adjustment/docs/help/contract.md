# 复权计算契约

## 字段与维护

理论参考价=(前收盘价－来源每股现金＋配股价×每股配股数)/(1＋每股送股数＋每股转增数＋每股配股数)，累计因子乘以前收盘价/理论参考价。采用50位Decimal，不按交易所最小报价单位舍入。454字段已拆除460转增，不能再重复计算。

adjustment.query.calculate为严格入口；history复用同一计算核心，权息失败时仅返回通过核验的原始OHLC。算法版本为empire-yuanhang-ex-rights-v3；来源、价格、事件及查询范围进入input_hash。事实事件以证券、除权日及五分量摘要定位，同日多条完整保留；无法裁定合成口径时计算明确失败并指出日期，不求和或任选。

一次REPEATABLE READ连接贯穿证券、交易日历、年度日线正文/证明和联合权息股本正文/证明；跨业务公开接口yuanhang.api接受调用方conn，不另开快照。年度最多150个、每年366点；金融最多2000事件及30000股本点；计算最多54900行，结果只驻本次查询内存，不新建表、队列或长期因子副本。

完整年度证明保证来源返回的稀疏序列；仍核对所选范围正式日历和非交易日期。不能用其他来源停牌推断补价。空事件须有有效的联合来源证明。源端自身更早历史截断或缓存回滚不由SQL摘要独立证明。

输入须为远航规范版本5，所选区间每行OHLC关系须通过；异常来源原值仍归档，正式行情查询派生quality_flags=1，计算不得自行抬高最高价或丢掉该日。完整采集和用途质量分别验收。

纯缩股的净股数变化在(-1,0)，其他分量必须全0，按同一理论公式计算，分母仍须为正；不把负比例截为0。普通流通股明确NULL不影响纯价格复权，但影响依赖该余额的市值或换手率用途。

来源明确成交量缺值保存NULL，不填0。复权只使用有效价格和同源权息；成交量缺值独立影响依赖量能的策略，不修改理论除权价。

规范5完整日线的精确重复只保留一个业务日期，同日冲突和倒序仍拒绝；复权读取已重核的年度及金融证明，不在计算层再次去重或补价。
