# 分红送转

## 浏览细节

日期筛选按除息日，缺除息日时按报告期；字段标题明确起止口径，空值不限。窄窗口点击方案卡进入“方案与关键日期”页签，宽窗口并排查看；返回恢复所选方案和阅读位置。

## 如何查看

打开分红送转，按带市场证券候选、来源报告日期范围或精确方案状态查询。默认方案列表卡片，选中后右侧查看关键日期与全部数值，明细标签保留原值。每10股派送转由每股值精确换算，0与未知不同；同报告期并列方案分别显示，预案、实施和取消以来源状态为准，不按日期经过判断完成。

## 数据范围与更新

通达信历史方案，按报告期完整列表批量下载，再按当前股票池组装每证券完整历史，中断重新下载范围并续接已入队位置。单期最多请求10000条，达到容量则报错，不截断。股票池变化建立新范围证明，已有历史保留；初始化支持范围不等于已采完范围。

## 字段与日期

含税每十股金额和送转比例换算为每股，万股换为股。按除权除息日记账，预案不入账；同日期不同金额的方案分别保留，不自动求和。缺少值保持未知。

## 限制与排错

不补造取消历史和旧版本，修订方案不能用最早预案公告日提前使用。同日多方案需要核实是否可合并，复权计算发现歧义会拒绝。当前股票池不承诺退市证券全覆盖。报告期参数只支持单日期；目录只有最近20季度。目录maxrq为页面默认选中期，可早于最新可选季度；两者均保留，不因不相等中止。普通轮次复查全部已知历史及默认选中期后的每日日期，新证券先发现历史日期；全新库首次仍需逐股发现。新引入的更早未知非季度日期需“重新采集”全池发现，不以普通轮完成承诺任意历史日期均已发现。

正式查询保留历史记录，可能比本轮当前池来源集合多。预案转实施时每股金额变化会形成不同业务键；不能删除旧键使准备检查通过，也不能把预案和实施方案相加。完整集合摘要不匹配时仍显示准备失败，需按具体键核实池外历史、来源修订和真实漏采；容量通过与历史集合可用是不同结论。仅有当前股票池不能保证历史回测股票池没有幸存者偏差。

## 相关说明

数据准备可按明确证券和事件日期验证：完整证券单元的业务键与内容必须先精确匹配，再判断日期范围；其他证券的未知历史不连带阻断。含额外保留历史而单元不匹配时，不能用日期筛选代替来源成员证明，仍显示缺口。保留预案仅供查看，理论复权排除预案和取消；同报告期多条实施即使除息日不同也可能是修订，缺少稳定事件关联时拒绝计算，不认定它们就是同一事件。当前版本不提供股息率或现金总收益计算；公告日不证明后来修订在当时已可用。
