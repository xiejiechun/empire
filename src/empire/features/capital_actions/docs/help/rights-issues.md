# 配股

## 浏览细节

日期起止筛选按除权日，未知除权日不推断其他日期。点击方案卡打开该方案与缴款区间；窄窗口采用详情页签，保留精确来源明细。

## 如何查看

打开配股，按证券、市场、来源除权日期范围及精确方案状态查询。方案卡片突出每10股配股比例与配股价，选中后查看缴款区间、上市/除权等已提供日期以及来源原值。每10股由每股比例精确换算；没有日期保持未知，不自动判断缴款成功或方案完成。

## 数据范围与更新

通达信完整来源列表，每轮核验完整业务集合，集合改变建立新范围证明。列表校验失败停止且不推进断点；保留已归档历史，不删记录凑数量。

## 字段与日期

每股配股比例、价格及股数按规范单位显示。同登记日不同认购代码或缴款起日分别保留；旧发行日期、缴款结束日和上市日未给出时保持未知。

## 限制与排错

分红、增发、配股各自采集验收，一项完成不替其他两项通过。无完整公告时间及取消历史，不用于公告前选股；配股复权计算不代表投资者实际认购。
