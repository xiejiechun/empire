# 区间名义现金股息率

## 如何查看

在“数据浏览 → 分红送转”输入六位证券及起止日期，进入“名义派息汇总”，点击“计算区间名义现金股息率”。同一范围仍可单独点击“计算名义派息”，不必等待价格齐全。数据准备的分红详情及研究条件也列出两项独立产物；回购检查失败时仍阻断原股东回报/稀释主题，不因此阻断已满足自身条件的派息或股息率。回购当前集合是否可用，以本次正式检查为准。

结果显示证券、分子闭区间、逐笔实施键与金额、分母实际交易日、未复权收盘价、来源与实际证据时间、公式和百分比。修改证券、市场或日期立即撤销页面旧结果，须重新计算。准备报告保留原检查时间，读取缓存时两项具体产物重新核验当前输入；不刷新来源证据时间或延长证明。计算只读，不保存配置或新增业务副本。

## 数据范围与更新

分子复用完整证券单元证明及共享事件资格，再按闭区间除息日选明确实施事件；预案、取消、终止不计入，歧义拒绝。分母由正式巨潮交易日历确定为不晚于截止日的最近已结束交易日。非交易日使用明确显示的对应交易日；截止交易日尚未到北京时间15:30或日期在未来时阻断，不取盘中价格。

价格复用已归档开盘啦quote正式查询。缺数据可在正常关闭桌面后使用现有命令：`Empire.exe collect-intraday --kind quote --securities 000001.SZ --start 2026-01-01 --end 2026-10-20 --proxy-priority`。任务须已启用；这仅限定本次运行，不保存或改变日常策略。普通执行补缺并按既定每周窗口复核，`--fresh`重新核验指定范围。使用同一共享下载、代理、频控、入队、断点及归档；失败保留首缺口，不把后续成功当整轮完成。

## 字段与日期

`Y = 区间已实施名义每股含税派息合计 / 截止日对应未复权收盘价 × 100%`。单位为%，不年化、不称TTM。金额及除法使用Decimal，不逐笔提前舍入；展示原精度。

价格必须是同一证券、精确分母日的原始quote.last_px，具有有效盘后来源时刻与不早于该日15:30的归档观测证据，且为正并在日高低价之间。日历、分红、行情和停复牌在同一只读SQL快照核验；Redis仅依原规则匹配内容、版本和有效期补充分红时效，不可用时回SQL，SQL过期仍失败。

本批简版逐交易日要求完整原始收盘快照及正数总股本、相同上市生命周期和不变股数基准；区间实施送转必须明确为零。完整证明的无派息范围可得0%，但仍需合法价格及基准证据；未证明空集不能填0。

分母日还须有停复牌SQL连续覆盖及不早于该日15:30的真实确认。沪深范围自2004-12-27，超出支持范围阻断。按完整来源身份核对当日出现记录与明确生效时段；早年未知复牌不无限外推，分母日实际出现的未裁定记录仍阻断。此多输入计算保守使用同快照SQL停复牌证据，不以另一时刻的缓存替代SQL内容。

## 限制与排错

这是区间名义现金股息率，不是到账现金、买入成本收益率、持仓收益、总收益或历史可知信号。当前来源修订版缺稳定事件关联与逐次修订可用日期，historical_signal继续来源受限。P3回购完整性诊断及证明修复已交付；持仓、税费、支付日、期间回购支出和稀释计算尚未实现。O7可行性已证明，产品实施暂缓；O8继续暂缓。

缺完整分红、未知金额/日期、实施歧义、缺价、停复牌未裁定记录、错证券、复权价、非正价格、盘中证据、缺日或股数基准变化均阻断本项。不会静默改用更早价格。每日股本快照不证明日内变动或严格历史版本，也不代替事件归因。保留全部历史和原完整历史失败；局部计算通过不冲销原B项、600938及回购历史失配。
