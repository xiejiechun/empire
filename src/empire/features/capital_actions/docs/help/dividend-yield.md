# 区间名义现金股息率

## 如何查看

开盘啦七项行情功能已移除。区间现金股息率需要的收盘价格及逐日股本快照当前没有已登记提供者，点击计算会明确返回“数据阻断”，不会查询保留的旧行情表，也不会用其他来源的价格静默代替。

分红送转采集及名义派息汇总仍可正常使用。远航日行情及自算复权计算保留；它们不等价于本项原来要求的逐日股本输入。

旧 `collect-intraday` 命令已移除。不要通过启动旧任务或运行旧行情维护脚本补齐本项。

## 字段与日期

区间名义现金股息率原定义为闭区间实施每股含税派息除以截止日对应收盘价，不代表到账收益、年化或严格历史可知信号。目前不产生计算结果；以后恢复需要明确新的价格和股本契约并完成对应验证。

## 数据范围与更新

本项当前不提供股息率结果，也不会触发旧行情补采。分红数据仍按原任务更新。

## 限制与排错

“数据阻断”表示所需行情提供者已退役，不是重试即可解决的网络故障。请使用独立的名义派息汇总。
