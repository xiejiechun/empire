# 增发

## 浏览细节

日期筛选按发行日，缺发行日时按上市日；空日期不限，来源状态精确匹配。窄窗口点击方案卡进入关键日期详情，宽窗口并排展示。来源暂无详情与上次有效历史参考分别说明。

## 如何查看

打开增发，按证券、市场、来源发行日期范围及精确方案状态查询。左侧卡片阅读发行类型和价格，右侧档案分别列关键日期、列表字段和详情；可切换检索明细核对原值。来源本次暂无详情时，保存的旧详情明确标历史参考；发行数量不冒充限售解禁日期或金额。

## 数据范围与更新

每轮完整列表核验；新增、变化、缺失或损坏详情以及近期 90 天当日回查范围才请求详情，其余复用已归档内容。从头重新采集强制全量详情回查，保留历史。来源集合改变自动建立新批次。

## 字段与日期

金额按元、股数按股，中签率等按来源明确单位展示。一个来源方案编号可关联新旧代码，分别保存；来源空值保持未知，未采详情不等于源端未提供。

## 限制与排错

源站明确详情错误保留单证券缺口；后续有效单元可继续入队，但有缺口不能整轮完成。同编号别名复用本轮明确失败以避免重复请求。仅详情修订而列表未变且不在回查范围时不保证发现；无公告时间，不用于公告前选股。

旧方案退出当前完整列表后仍保留。来源返回完整结构但详情为空时记录“暂无可用详情”，不能推断方案撤销或补成零。已有有效详情可作为历史参考保留，原本未取得的详情继续未知。正式历史全集与当前来源范围摘要不一致时，完整性准备仍失败；不得通过删除历史或将未知冒充“来源明确未提供”消除失败。
