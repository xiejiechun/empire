# 业绩、股东户数与重要股东持股变动

本包统一定位六类通达信业务。`contract.py`保留六kind字段、唯一键、矩阵消息及版本契约；`source.py`校验完整响应和独立来源总数；`collector.py`复用共享有界预取、下载/代理/频控和原子入队；`dataset.py`经唯一归档器保存结构化数据及单元证明；`query.py`提供正式分页和准备检查；`ui.py`按需创建六个业务页面；`bundle.py`保存各自原插件、任务、数据集、页面及顺序槽位。

四报告初始化及日常均核验1980季度末至来源目录最新期，不能将近期目录当全部历史。户数核验最新来源目录与SQL已知证券并集的可得历史；最新与历史同键矛盾拒绝。股东变动默认1990-01至本轮当前月，也支持明确月份范围。所有完整响应先校验再按市场入队，继续下一单元下载，整轮末才等待归档。失败不推进对应断点，SQL提交后重放；Redis丢失按原来源/SQL计划重建，不保证丢失业务消息恢复。

本批仅归属迁移，无DDL、身份、调度、来源或准备语义变更，无旧路径转发、双注册或启动迁移。NULL、零、未知与月精度分开保留；公告日、预约日、报告期及统计日不互换。来源集合不符或实际日期超前仍拒绝，不为迁移放宽校验。日常操作、生命周期和用途限制见[业绩与户数](../../../../docs/tdx-performance.md)、[重要股东变动](../../../../docs/tdx-shareholder-changes.md)。
