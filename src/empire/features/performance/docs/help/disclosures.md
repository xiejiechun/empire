# 通达信业绩披露时间

## 如何查看

数据浏览目录搜索业绩披露时间，输入证券和起止日期点查询，每页最多200条。报告按报告期、户数按统计日筛选，管理采集跳转独立任务。

## 数据范围与更新

五项独立任务默认每日北京时间18:00，可保存计划及代理策略，重启保留。四项报告每轮核验1980年以来所有季度末至来源最新报告期；户数每轮核验最新目录与SQL已知证券的全部来源可得历史，来源不保证上市以来完整。每个必要完整响应正常请求一次，容量10000。

## 字段与日期

首次预约、三次变更、实际披露分别保存；当前剩余天数按北京时间计算，预约不能当实际公告。

预约日期可在未来。来源实际披露日可能在前一日晚间提前声明次日，程序保留原值，数据准备按当前版本观测日标记尚不可确认的信号日期；不能当作当日已经公布。超过观测日次日的实际披露日期仍拒绝，保留断点供排查。阅读区展示业务字段，不展示内部摘要键。

## 限制与排错

空值未知，当前版本不能还原历次修订。失败不推进断点；正常继续按已入队单元恢复，重新采集重建下载计划，等待归档阶段先确认原轮次。Redis丢失重新核验SQL历史。部分市场中断后响应变化时，从该期起点重发全部市场，保留更早完整期的进度；来源撤回保留历史并暴露集合差异。完成表示本轮全部归档消息已成功处理，数据准备另查字段与集合。

## 采集百分比

报告期/日期/证券完整响应计划；完成响应数。使用本轮实际计划和已成功处理数量计算；准备范围期间不猜总量，空计划表示无需处理。百分比达到100%不替代完整集合校验或本轮归档确认；失败仍按实际结果显示。
