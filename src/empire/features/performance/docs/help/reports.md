# 通达信业绩报告

## 如何查看

数据浏览目录搜索业绩报告，输入证券和起止日期点查询，每页最多200条。报告按报告期、户数按统计日筛选，管理采集跳转独立任务。

## 数据范围与更新

五项独立任务默认每日北京时间18:00，可保存计划及代理策略，重启保留。四项报告每轮核验1980年以来所有季度末至来源最新报告期；户数每轮核验最新目录与SQL已知证券的全部来源可得历史，来源不保证上市以来完整。每个必要完整响应正常请求一次，容量10000。

## 字段与日期

净利润、营收、经营现金流为元，EPS元/股、ROE百分数；是财报摘要，不替代完整三大报表。早期来源公告日等于报告期，不能直接用于严格历史信号。

公告日期为来源声明日期；本次来源提前声明2026-10-13，而观测日为2026-10-12，保留原值并在历史信号检查标记尚未可用。净利润按来源原口径显示，不将未核实的口径代码统一解释为归母。阅读区展示业务字段，不展示内部摘要键。

## 限制与排错

空值未知，当前版本不能还原历次修订。失败不推进断点；正常继续按已入队单元恢复，重新采集重建下载计划，等待归档阶段先确认原轮次。Redis丢失重新核验SQL历史。部分市场中断后响应变化拒绝混合；来源撤回保留历史并暴露集合差异。完成表示本轮全部归档消息已成功处理，数据准备另查字段与集合。
