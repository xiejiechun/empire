# 通达信业绩快报

## 如何查看

采集入口：在“通达信”平台分组选择“业绩快报”。

数据浏览目录搜索业绩快报，输入证券和起止日期点查询，每页最多200条。报告按报告期、户数按统计日筛选，管理采集跳转独立任务。

## 数据范围与更新

五项独立任务默认每日北京时间18:00，可保存计划及代理策略，重启保留。首次和“重新采集”核验全部声明范围。日常四项报告重点复查最近两个自然年，旧季度分组轮换，最长90天复查一次；缺失证明的季度立即补采。户数每轮读取最新目录，只对新增、最新内容变化、证明缺失或到期证券读取完整历史，未变化证券最长30天复查。每个必要完整响应正常请求一次，容量10000；来源不保证上市以来完整。

## 字段与日期

净利润、资产、净资产为元；EPS元/股，ROE及变化为百分数。来源方案总数按公司编号计，同一方案的多同比行全部保留；来源没有营收；来源可能提前声明明日公告日，按原值保留，历史信号检查标记尚未可用。

公告日期为来源声明日期；本次来源提前声明2026-10-13，而观测日为2026-10-12，保留原值并在历史信号检查标记尚未可用。净利润按来源原口径显示，不将未核实的口径代码统一解释为归母。阅读区展示业务字段，不展示内部摘要键。

## 限制与排错

空值未知，当前版本不能还原历次修订。失败不推进断点；正常继续按已入队单元恢复，重新采集重建下载计划，等待归档阶段先确认原轮次。Redis丢失后按已归档完整单元证明重建计划，不因缓存丢失重下全部历史。部分市场中断后响应变化时，从该期起点重发全部市场，保留更早完整期的进度；来源撤回保留历史并暴露集合差异。完成表示本轮全部归档消息已成功处理，数据准备另查字段与集合。

## 进度显示

管理端按本轮已规划的完整单元展示百分比：证券、报告期、日期或证券日以本项目实际计划为准。初始化及续采恢复已成功处理数量，失败单元不算成功；准备范围时不猜总量。分红目录发现和报告期核验分别显示当前阶段进度；采集100%仍需等待整轮归档确认。

## 采集成本记录

运行记录统计本轮实际请求次数（包括重试）和实际接收数据量，失败或取消时也保留这些数字，便于排查反复下载；不改变已保存的采集计划。
