# Redis fx-latest

## 用途与归属

键模板`<namespace>:fx:latest`；fx业务包所有，FxLiveCollector写入，fx.latest.query查询，统一volatile准入控制容量与隔离。实时不发布Stream、不访问日线SQL。观察日历经该正式查询可选读取今天缺少归档记录的汇率，逐品种最多一条，3秒读取边界；不新增物理键或写入。

## 结构与身份

Hash最多24字段：十二白名单品种正文及对应`version:<symbol>`。正文每品种最多2KiB，含symbol、unified_code、latest/open/high/low/previous_close规范价格字符串、source_time、source_update_time、observed_at带时区时间。version为观察时间的Unix微秒，用于原子拒绝迟到样本；身份和必需字段严格校验。查询附名称/单位及超过180秒的sampling_stale，不将这些派生字段持久化。

## 读写与关联

Lua按品种原子比较版本、覆盖正文和版本、续整键7天TTL；较旧或同观察版本不覆盖。每轮结束等待60秒；读取最多十二值，不需要分页历史。两种来源时间不同且语义未最终证实，不能把time当真实成交时间。

完整响应明确暂无报价时不写入对应品种、不刷新该品种采样时间，不创建首次空报价；任务运行记录保留本轮来源缺口清单，恢复报价后再正常发布。不增加可用性永久键或SQL快照。

观察日历核对三个时间均属北京时间今天，不覆盖已有同日归档、不补历史或未来。当前值与盘中估算带Redis及采样过期标记，详情/导出保留原时间与最新价；可选查询停用或失败保留归档读取，刷新不采集、不续TTL。盘中估算不参与历史日线写入。

观察日历的只读 observation.live 通过 fx.latest.query 定时读取该Hash，不写SQL、不续期或修改Hash。首次月历提供最多十二项计算基准（模式、1～60期、有效标志、精确前收/历史合计），后续只用Decimal更新今日盘中结果。日期切换须重新加载，已有同日日线不建立盘中基准；不新增物理缓存键。

## 保留与恢复

整键从最后一次成功品种写入起7天过期；持续有其他品种更新时失败品种旧值继续保留并标过期。不存在历史快照、按分钟记录、回放索引或MySQL镜像。失败不删旧值；正常软件重启Redis存活仍可查询；Redis/电脑重启丢失，下一次实时采集重新获取，不能恢复过去采样。

## 维护与相关说明

不清空共享Redis；任务禁用停止采样但不主动删除最新值。该键与日线归档摘要、断点及队列独立。入口及限制见[同花顺汇率行情](help:同花顺汇率行情)。
