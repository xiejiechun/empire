# 上市与发行资料

## 浏览细节

选择证券候选后直接查询；窄窗口的结果目录最多占四行，单条查询为公司档案留出空间。返回恢复档案及历史沿革阅读位置；空查询清除旧公司正文。

## 如何查看

在数据目录打开上市与发行资料，搜索代码或名称并选择带市场的候选。左侧为证券列表，右侧“上市与发行”按日期、发行与募资字段阅读，“历史沿革”显示完整来源正文。窄窗口上下排列；来源暂无、缺日期及历史参考分别说明，不推算重新上市日。

## 数据范围与更新

同花顺当前股票池的上市资料；普通轮补新增、缺失，每七天全池回看独立详情修订，重新采集逐证券重查但保留历史和正确待归档消息。推荐每日 18:00，保存计划优先。

## 字段与日期

上市日期、来源证券身份及发行字段结构化保存。当前交易所上市日与早期历史日期有不同含义；北交所当前上市证券按已核实的交易所身份和日期，不用旧市场历史冒充当前市场起点。金额、股数和未知日期按来源契约。

## 限制与排错

来源字段缺失不填零；必需上市关联损坏不能放行其他来源依赖。下载或业务校验失败保留该证券位置，不因后续成功跳过；当前目录不承诺退市证券全历史发行资料。

明确“来源暂无”和“来源缺上市日期”可作为本轮已经处理的来源状态，但不表示上市资料准备通过；旧有效资料仅供历史参考，下一轮仍按规则补查。上市日期与成立日期分别保留，成立日晚于上市日时显示来源矛盾，不替换必需上市日。历史沿革是来源当前正文，没有历史公布时间，不能用于严格历史信号回放。
