# 股票列表

## 浏览细节

证券摘要可直接打开资产负债表、现金流量表、历史停复牌、所属行业及所属指数。先选中证券再跳转；空选择清除上次证券摘要。技术身份列仍可显式展开。

## 如何查看

进入数据浏览 → 数据目录 → 股票列表，按市场、代码或名称查询当前证券。选中一行可从下方进入公司资料、日K线、利润表、分红送转或更名事件；双击打开公司资料，并携带准确市场。统一身份及来源代码默认收起，可点“显示技术身份列”核对；当前股票列表仍用紧凑表格，不代表历史股票池。

## 数据范围与更新

当前主用同花顺目录，新浪任务保留可归档还原。每轮获取并核验完整当前目录后发布；列表不完整时保留上一份。两来源共用同一份正式目录，不保留历史股票池。普通执行按本任务断点恢复；同花顺推荐每天北京时间 18:00 核验，显式保存的计划优先。

## 字段与日期

统一证券身份用于关联其他数据；来源目录可能包含尚无行情证券，不能直接推断可交易。页面更新时间属于最后实际内容变化批次；相同目录核验成功不会刷新业务时间。最近成功核验看运行记录。

## 限制与排错

失败或归档中仍可看到旧完整列表，查看当前刷新状态及运行记录。不能用当前名单验证历史退市证券全覆盖。浏览只依赖 MySQL；Redis 不可用时最近临时核验信息可能缺失。
