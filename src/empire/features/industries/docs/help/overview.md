# 同花顺当前行业

## 浏览细节

刷新同时重新查询行业目录和所选成员，尽量保留所选行业身份。成员默认不重复展示行业编号及名称；状态提示标明当前行业编号。

## 如何查看

采集入口：在“同花顺”平台分组选择“同花顺行业”。

打开同花顺行业，左侧行业目录显示完整成员计数，右侧按所选行业独立分页。可搜索行业名称/编号或证券名称/统一代码来反查所属行业。目录和成员分别每页最多200项，不从当前页凑目录总数；双击成员带准确市场打开公司资料。仅当前关系，不提供历史归属日期或无来源的层级树。

## 数据范围与更新

只保存最新完整行业和成员，整轮事务反映新增、退出、更名及转行业，采集中保留上轮完整结果。入队前中断可在同一运行中的采集器内复用30分钟以内、目录未变化的完整行业成员；过期、目录改变、重新采集或程序重启后重新下载，入队后先确认原轮；Redis 丢失再完整刷新。推荐每日更新，保存选择优先。

## 字段与日期

行业编号与证券身份共同表示当前关系；同一来源行业中的成员需唯一，不能仅用条数证明完整。完整响应及当前范围证明参与数据准备，当前成员适用于当前估值分组和筛选。每日复盘也可按当前成员汇总历史日期资金，必须标注“按当前成分股回看”，显示已覆盖数量；这不还原历史行业，成分变更后历史汇总可变化。

## 限制与排错

当前行业不等于交易所上市板块，也不还原历史行业。登录页、重复成员、残留分页、截断均失败并保留旧集合；源码协议改变须修复，不靠反复重读。单行业满请求边界不能证明完整。

## 采集百分比

已验证行业目录；已解析行业成员集合数，最终整份校验和归档另确认。使用本轮实际计划和已成功处理数量计算；准备范围期间不猜总量，空计划表示无需处理。百分比达到100%不替代完整集合校验或本轮归档确认；失败仍按实际结果显示。
