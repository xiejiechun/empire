# 同花顺远航版ETF日K

## 如何查看

先完成“ETF目录”，在同一平台选择“ETF日K”。进入数据预览可按完整代码（例如510050.SH）、开始日期和结束日期查询，按全部筛选结果排序后分页。图表只概览当前加载范围。

## 数据范围与更新

默认每日18:00，用户已保存计划优先。按正式日历固定已结束交易日，首次优先最近十个交易日，再独立补最多64只ETF完整来源历史；逐轮补齐。新交易日回看最近十交易日并补已知缺口，不每天重下全池历史。盘中不归档当天日K。

## 结果、继续与重新采集

每个完整年度区间校验后先入Redis，继续下载；整轮入队完毕才等待本轮所有消息成功处理清队。任务完成不等于全池历史已齐，实际覆盖以数据准备检查为准。“继续”续已入队位置；“重新采集”显式核验所选范围全部来源历史，不受普通64只补缺上限，不删除范围外事实。目录或选择变化不混用旧断点，重新开始会先确认原批次已入队消息。

## 字段与日期

开、高、低、收为来源不复权元值；成交量单位为份，成交额为元。NULL是来源未给，不能当零。保留价格关系或负量额异常并标注质量。普通日频分析使用当前来源修订版，不承诺严格历史版本回放；来源没有的分钟数据、分红及复权因子不属于此任务。

## 限制与排错

Redis存活可继续断点；Redis丢失从SQL年度及日期区间证明恢复，只补未确认范围，不承诺恢复尚未归档的数据。十交易日窗口外旧修订需显式核验。无身份的空历史不能证明无历史。仅在额外一次精确当前行情同时核实身份且价格与成交全空时，报告“来源暂无日K”，不写空事实或覆盖证明；其余合法证券完成清队，下轮重查缺口。当前报价有值或身份矛盾仍失败、不推进断点。
