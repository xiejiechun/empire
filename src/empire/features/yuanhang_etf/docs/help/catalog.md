# 同花顺远航版ETF目录

## 如何查看

在“采集管理 → 同花顺远航版”选择“ETF目录”，立即采集后进入数据预览，按代码或名称查询。目录准备后可分别启动“ETF日K”和“ETF最新行情”。

## 数据范围与更新

范围是远航版“沪深京 → 场内基金 → ETF基金”当前完整集合，数量随来源变化，2026-11-16核实1741只。默认每日北京时间18:00，已保存合法计划优先；计划保存立即生效，网络策略下一轮生效。

## 结果与恢复

先进入Redis待归档队列，再统一归档到MySQL；完整集合成功处理并清队后任务完成。退出目录者标记不再当前有效，日K历史保留。中断继续未完批次；Redis丢失重新读当前目录，不删除SQL历史。

## 字段与日期

代码为六位代码加.SH或.SZ，原生市场USHJ/USZJ。名称按来源保留，不进入股票名单，不提供历史目录、基金分类、申赎或历史净值。集合不完整或身份错误不会替换旧目录。当前目录不能证明历史ETF池。

## 限制与排错

目录失败先查看本任务错误；原有完整集合保留，不能按空目录处理。
