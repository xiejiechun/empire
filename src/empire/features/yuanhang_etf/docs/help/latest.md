# 同花顺远航版ETF最新行情

## 如何查看

完成“ETF目录”后选择“ETF最新行情”，立即采集一次，再在数据预览查看代码、名称、基础行情及来源净值。代码/名称筛选和数值排序对整份结果生效，然后分页。采样更新导致旧分页版本失效时重新查询。

## 数据范围与更新

默认每轮结束等待60秒，在正式交易日09:15～11:30、13:00～15:05定时采样，盘外和非交易日不反复请求；手动执行允许一次盘外采样。用户已保存合法计划优先，保存立即生效，代理/重试策略下一轮生效。日历不完整不能猜测交易日。

## 字段与日期

沪深目标集合及名称全部验证后一次替换Redis最新结果，不进入MySQL业务、collection_state或归档队列。基础值包括现价、昨收、开高低、成交份额和金额；涨跌额、涨幅和振幅由这些原值计算并明确标注，缺操作数保持空。

来源报价时刻和净值日期目前未知；采样时间只表示本机取样，不能证明源价格当前更新。来源净值不等于实时估值，不能当作当日已公布净值或严格历史信号。来源未给现价显示暂无；失败不发布部分结果，保留上次完整结果及其原采样时间，运行记录显示失败。超过180秒显示采样过期，盘外仍不把旧报价当实时。量比、涨速、内外盘、IOPV尚未支持。

## 限制与排错

运行记录区分失败、盘外跳过和有效发布；来源时间未知不作新鲜承诺。

## 保留与恢复

只保留一份最新结果，成功发布后7天过期，不保存分钟或逐轮历史；Redis重启丢失后重新采样。退出ETF随下一份完整集合替换，不长期残留。
