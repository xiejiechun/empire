# ETF份额与净值

## 如何查看

采集管理按平台选择“上交所ETF每日份额”“深交所ETF每日份额”或“ETF历史净值明细”，打开数据预览。输入代码前缀、开始/结束日期，点击查询数据；客户端默认每页50条，查询接口未指定页大小时默认200条，稳定翻页，每页不超过500条。查询不触发采集。份额、净值各自独立，已有结果不等待另一任务。

## 数据范围与更新

上交所同时包含普通ETF和独立交易货币基金页面；深交所使用ETF基金规模完整导出的精确份额，网页万份为截断或四舍五入的两位小数展示值。天天基金保存日期、净值或收益、增长率、申购状态、赎回状态、分红送配七列和来源标记。对象来自可信当前ETF目录，退出目录不删除历史，不宣称包含所有历史退市基金。

默认每轮结束12小时后继续，已保存计划优先。份额近五交易日优先，另外最多补20个完整历史日；净值最近十交易日对应自然日期窗口优先，另外最多补32只历史，每月有界轮转旧区间。长停机按已归档覆盖补缺；重新采集也有界，不清空历史。中断保留未完成范围，普通失败不升级全池重采；仅程序重启可续队，Redis服务重启丢失临时队列时由SQL覆盖重新规划。

历史候选从2004-12-30逐日或证券区间核验。来源早期日期可能明确没有记录；保存合法空范围的覆盖证明，不能解释成该日没有ETF。来源最早有记录日期尚未对全部历史做连续审计。近期份额为空保持待补，不误报完成。深市T日晚为参考，次日复核，来源没有最终确认标志，不伪造标志。采集完成、历史归档进度和数据准备用途检查分别呈现。

长历史按年度依次入队，中断后继续尚未入队的年度，已入队年份仍由统一归档处理；不会因为单只基金历史较长而把全部年度挤进同一批次。查询早期日期时，近期窗口以当时实际已有交易日为准。

## 字段与日期

总份额单位是份，不是成交量。数值按精确小数保存；空净值不填零。货币基金收益与真正单位净值分列，当前“每百份收益”标签不作为全部历史的基数证明，历史收益基数未知保留空白；NAVTYPE不用于猜测指标类型。净值披露日期可含周末收益，并非下载日期或历史公布时刻。有效版本观测时间是北京时间，重复核验不刷新事实时间。

## 限制与排错

源端字段缺失忠实保留，不冒充漏采或填值修复。网页显示数据不是独立的日期无遗漏证明。来源分页不完整、同条数不同集合、日期/单位变更或导出与首页不一致时失败不推进断点；原始错误样本有界保留，查看成功不自动清理旧错误。

每日复盘的“ETF净申赎估算”只读已有份额和净值，需两日连续份额、当日真实单位净值、确认币种以及非申赎份额变动校正依据。现在币种和折算等事件依据缺失时保留金额“缺少数据来源”，展开“ETF数据覆盖与缺项”查看候选覆盖与原因，不把缺值写成0。按当前ETF目录回看，部分覆盖不代表全市场。份额与净值成功归档不等于估算全部输入已就绪。
