# 历史停复牌

## 浏览细节

窄窗口先显示来源记录；点击“展开来源日历 / 全部历史选项”再选日期或切换全部历史。宽窗口仍并排显示日历和记录。事件卡链接选择对应完整记录；来源查询日期与停复牌生效时间分别呈现。

## 如何查看

打开历史停复牌，选择来源日历日期后立即查询；“全部历史”列出独立来源记录。“来源记录”卡片分别标明停牌、复牌生效时间、说明和原因，“精确明细”便于核对长文本。月历显示归档条数和日期核验状态，未核验的空日不能当无记录。查询应用证券条件后，编辑草稿不会改变当前结果与翻页条件。

## 数据范围与更新

沪深 A 股范围自 2004-12-27 至今。首次逐自然日核验完整集合，按月份或有界连续日期单元归档；后续从最后 SQL 连续确认日当天重查至今天。失败日期保留缺口。休市日期的响应与交易日历证据按现行来源规则核验，不自行生成停复牌记录。

## 字段与日期

来源查询日期与停牌、复牌生效时间分别保存。按实际出现的来源日期展示，不能从生效时间猜来源日历日。相同证券同停牌时间下的不同复牌时间、未知复牌和不同说明/原因分别保留；完整来源记录重复去重。

## 限制与排错

来源日期未知不等于当天无记录。来源遗漏不自动删除已有事件，停复牌时间仍按来源响应和版本规则保存。多个来源记录不代表已裁定唯一回测交易约束；判定可交易时需按用途核实事件生效时间。

同一完整来源身份在两个查询日内容冲突时，整段拒绝入队，断点不推进。在“采集管理 → 运行记录”的错误详情查看 metadata.conflict：包含完整身份、两个实际来源日期及差异字段的前后值。仍经过公共脱敏和大小限制，不保存整份成功响应。旧错误未记录的字段不能追补推测；后续一次成功也不自动清除旧错误。
