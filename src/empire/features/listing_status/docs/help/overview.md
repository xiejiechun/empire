# 暂停恢复终止上市

## 浏览细节

点击事件卡的“查看来源说明”打开独立可滚动的所选事件说明页签。说明按来源纯文本呈现，可选择复制；空选择取消旧说明请求并清除旧正文。

## 如何查看

在数据目录打开暂停恢复终止上市。可按证券、事件类型和来源日期范围查询，默认最新在前；“事件时间线”用于阅读，“来源明细”用于精确核对，选中事件读取完整来源说明。日期是来源业务日期，暂停不等于退市，未知的最后交易日不补造。

## 数据范围与更新

通达信，1990-12-19 至本轮固定启动日，沪深 A 股，不按当前股票池过滤。初始化按月、月内逐自然日完整查询；普通轮续未入队月份、补缺并回查本月和上一自然月。从头重新采集复核声明历史，保留已有记录；整轮归档清队后才完成。

## 字段与日期

暂停上市、恢复上市、终止上市按事件类型、生效日期和证券身份保存。未知日期保持未知；终止上市不是某日暂时停牌，当前名单缺失不自动生成退市事件。

## 限制与排错

起点是声明边界，不宣称来源最早记录；北交所、B 股和栏目不提供的重新上市不承诺覆盖。先核对未过滤来源总数再提取沪深 A 股，不能用事件最大日期证明全范围完成。最后交易日不倒推，来源简称不承诺历史当日名称；缺月和无事件已核验月份分别处理。

月份完整和时效通过，只证明所选来源范围的当前归档集合可查。估值分析可结合明确事件日期筛选；普通日频回测还须核对停复牌成交约束及实际历史证券池。事件日期不代替最后交易日或公告可用日，缺少这些日期时不能把事后事件提前用作选股信号，也不能据当前目录缺失反推退市日。
