# 东方财富明盘暗盘资金榜

## 如何查看

采集入口：在“东方财富”平台分组选择“明盘暗盘资金榜”。

采集管理选择“明盘暗盘资金榜”，打开数据预览，默认进入“盘中资金榜”并查询北京时间今天，按暗盘资金从高到低排列。顶部显示交易日期、实际采样起止时间、完整快照证券数；页面读取时间与采样时间分别展示。按代码前缀（例如000001）或完整代码（000001.SZ，后缀不区分大小写）筛选，可排序、翻页。

“查看今天”将日期切回北京时间今天并应用当前输入的证券条件；“刷新最新”保留已查询条件和排序、返回第一页读取最新完整快照，不触发采集，也不覆盖尚未提交的筛选草稿。翻页绑定同一快照，过期需重新查询。没有快照时提示查看运行与记录或稍后刷新；已有快照但证券条件不匹配时明确显示无匹配记录。

收盘后的历史记录在“已归档日榜”，按交易日期范围和证券筛选；当天盘中尚未归档时请查看“盘中资金榜”。盘中栏不会用昨日数据冒充今天，已归档栏不会混入盘中采样。

“市场观察 → 每日复盘”的资金流向复用完整已归档日榜，展示所选日明盘、暗盘合计和含暗盘主力个股流入/流出前5；来源本身不提供板块榜或ETF净申赎。每日复盘在当前行业证明一致时另行汇总行业成分的该日资金，固定标注“按当前成分股回看”并显示完整或部分覆盖，不冒充历史行业归属。未收盘、未归档及集合不完整时保留缺值，不使用盘中快照或上一交易日替代。

资金金额自动以元、万或亿缩写显示，万/亿保留至多两位小数；悬停查看精确元值。活跃度与涨跌幅显示百分比，悬停保留来源小数；行情时间显示时分秒。排序仍使用精确原值，不按缩写文本比较。表格支持显示列、行距和展开预览。

## 数据范围与更新

个股榜以2026-05-11为已核实起点；2026-11-03逐交易日核查页面允许的一年范围，此前交易日接口均无数据。这不是保证源站永久保留该起点。按正式日历补齐实际可用历史，不以最大日期代替完整覆盖。

推荐固定间隔60秒，从上一轮结束后开始等待，任务不重叠；这不保证一分钟内完成5000多证券的全部分页。已保存的合法计划优先，需要调整时在任务配置中修改并保存。以下时段均为北京时间，计划开启且程序运行时才会执行。

| 更新阶段 | 请求范围与结果 |
| --- | --- |
| 盘中采样 | 交易日09:25–11:30、13:00–15:05采集当天完整榜单，内容变化时保存Redis快照，不写MySQL。 |
| 首轮日终复核 | 每天15:30后的首轮核验最近3个正式交易日，完整日榜经统一归档后可在“已归档日榜”查询。休市日核验最近已结束交易日，不采休市当天。 |
| 当天延迟复核 | 交易日16:00、16:30……21:00，每30分钟重新核验当天完整日榜，含21:00最后窗口，接收延迟数据及来源修订。 |
| 历史补缺 | 近期和到期复核完成后，后续轮次从2026-05-11起按正式日历与SQL完整覆盖补缺，每轮最多5个缺失交易日。较早且已完整归档的日期不自动轮转重查。 |
| 无需更新 | 无到期复核、无历史缺口时不请求来源。15:30前非盘中时段不请求；15:30后仍可复核近期和补历史缺口。 |

程序晚开或前轮延迟时，只处理最新到期的半小时窗口，不补发所有错过窗口；21:00窗口在当天21:00后的下一可运行轮次补做。日终未完成批次优先恢复，成功归档后才记录复核完成；失败保留断点，下轮继续。Redis维护状态丢失后先重核近期3日，并按当前时间处理复核，不重放全部历史窗口。

收盘计划在同一轮内复用，历史补缺只返回最多五个缺失日期，不反复下载最新日期第一页。复核窗口随断点保存；恢复完成或补记窗口失败后的重试，会补齐完成标记，避免重采刚完成的最近三日。旧断点没有窗口信息时保守执行原范围。盘中相同内容先原子核对摘要、索引和正文有效性，确认相同则免压缩和整榜传输；过期、缺失或变化仍完整保存。

“运行与记录”的更多运行信息保留本轮实际请求、重试及已观察字节统计；失败和取消也保留已发生的成本。逻辑成功页数与实际网络尝试分别统计，不能把页面数量当作包括重试在内的请求总数。

盘中变化快照仅留Redis，最多72小时、32MiB或2048份，达到上限淘汰最旧；不入MySQL。相同内容不新增快照，晚到旧观察不覆盖；日终与盘中使用不同状态；运行记录按本轮标记Redis、MySQL或无需请求，切换时不沿用上一轮的存储标记和计数。每页100条，日期、页数、总数和唯一证券集合完整后才发布。使用已实测的固定来源获取顺序，资金数值在分页间变化，不以资金值跨页顺序证明完整，重复证券/缺页/数量变化仍失败并保留上一份快照；采样起止时间不同，不能认为同一瞬间冻结榜单。

日终整日校验后入队，所有日期发布后统一确认归档。暂停后继续恢复未完成日终批次；未完成日重新下载。Redis重启丢失盘中记录，不能补建过去盘中采样；日终按SQL日期覆盖补缺。重新采集在盘中重新采样，收盘重核近三个交易日，较早历史修订需显式日期核验。任务需要正式日历完整，缺日时先补日历。

## 字段与日期

明盘资金、暗盘资金和主力净流入（含暗盘）单位为元，可为负或零；三项满足明盘加暗盘等于含暗盘主力净流入。价格为元，活跃度和涨跌幅保留小数（0.01表示1%）。来源行情时间不是数据公布时间，来源序号允许跳号，不作为暗盘资金排名；页面按金额排序使用资金字段。交易日使用实际响应日期，不把休市日回退结果写到请求日期。来源市场值0同时含深市和北交所：已核实92开头映射为.BJ，0/3开头映射为.SZ；市场值1映射为.SH。未核实代码族明确失败，不按市场值0一概认作深市。

## 限制与排错

该榜是东方财富基于公开行情和历史数据的模型测算，不是实际暗盘成交，不包含板块榜，也不提供历史分钟回补。没有历史公布时刻和完整修订版本，不支持严格历史信号回放。当前约定单日最多10000证券、100页及4MiB规范正文，压缩消息最多480000字节；超界、缺页、重复、来源报错或日期不符明确失败，不能以去重或填零通过；同一解析失败只记录一次错误。无稳定服务器快照版本，收盘后整日核验不等于盘中一致快照保证。

来源较老数据不可用时保留缺口，不把它当空日。历史范围内连续性以实际逐日归档及数据准备检查为准。查询已归档日榜只需MySQL；盘中查询必须有Redis保留快照，不以日终结果代替。
