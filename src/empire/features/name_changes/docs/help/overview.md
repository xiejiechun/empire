# 公司与股票更名

## 浏览细节

所选事件旁显示完整证券及日期；没有选择时其他数据入口不可点击。公司更名与股票更名相互跳转按钮明确写目标名称；展开来源详情和返回阅读保留位置。

## 如何查看

在数据目录分别打开公司更名或股票更名，搜索名称或证券候选，按来源日期范围查询，选择最新/最早在前。默认事件时间线，按年分组列出旧名 → 新名；更多来源信息可展开，来源明细保留完整字段。选择事件后可跳公司资料、另一更名类型或ST栏目，保留统一证券身份。并列事件不强行拼成完整名称链。

## 数据范围与更新

通达信公司、股票两个栏目，1990-01-01 至本轮启动日，正常各请求一次完整历史响应，不按当前股票池裁剪。每轮核验总数、身份和范围，按沪深北三个市场归档；已入队轮先确认，Redis 丢失重新读取全响应。推荐每日 18:00，用户保存优先。

## 字段与日期

保存来源更名日期、旧名、新名及接口行业标签。公司同证券同日不同组合独立保留，完全相同事件记录来源出现次数；股票同证券日期须唯一。公司全称不是证券简称，更名不是证券代码变更；行业标签不能当作更名时历史行业。

## 限制与排错

来源缺名、名称链断裂、早期方向疑点允许查阅但说明限制，不宣称历史全称回放可用；完整证明下某证券无更名可为合法空结果，仍不能证明首个名称。协议错配、总数错误和股票重复身份报错。本功能不提供股票代码沿革或 ST 状态认定。
