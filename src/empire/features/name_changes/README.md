# 公司与股票更名

本包集中业务职责；`contract.py`定义身份、类型和规范集合，`source.py`校验一次完整来源响应，`collector.py`经共享预取下载并将三个市场原子入队，`dataset.py`经唯一归档器事务保存，`query.py`提供有界正式查询与准备检查，`ui.py`按需创建页面。`bundle.py`保留原插件、任务、数据集、schema、页面及各贡献槽位。

每轮核验1990-01-01至启动北京时间日期的全部可得历史；来源计数、集合、字段和容量校验后SH/SZ/BJ同时入队，整轮统一归档成功并清队才完成。入队前失败不改断点，入队后中断继续确认，SQL提交后失败安全重放；Redis丢失重读完整来源，不保证丢失消息恢复。完全相同不写业务表，迟到旧响应不覆盖。

公共EventTimeline、QueryScope、preparation契约、下载/代理/频控/入队/摘要/归档只有原共享路径。无DDL、启动迁移、兼容转发或双登记。来源空值、名称方向/链与风险状态用途限制保持原说明，不补造记录。操作、字段字典和来源生命周期见[业务说明](../../../../docs/tdx-name-changes.md)。
