# 财经快讯

## 浏览细节

复制、来源及正文操作对应页面显示的“当前所选”新闻；筛选没有结果只说明本条件无已归档新闻，不认定未进行过采集。新消息提示保留当前阅读。

## 如何查看

打开财经快讯，默认连续阅读流，按北京时间日期分组，正文可展开/收起；检索明细仍提供表格、完整正文、复制与来源链接。可按标题/正文、重点和日期范围查询，游标翻页保持本次范围。后台检查新消息只显示“有新消息 · 点击查看”，不会替换阅读内容或跳动滚动位置；“查看最新”回到第一页。来源正文按纯文本显示，缺来源链接时按钮不可用。

## 数据范围与更新

来源新浪 7×24 财经新闻。首次和从头重新采集只取最新一页，最多 50 条；后续遇到上轮已归档上界停止。停止页仍比较去重和来源修订，保留后续积累的历史新闻。

模块化更新后仍从原来的数据目录和采集任务进入，已保存计划、插件开关和增量断点继续使用；正常关闭程序并启动新版即可，无需重新初始化新闻或迁移业务表。财经快讯页面与新闻采集器仍可分别启停。

## 字段与日期

新闻 ID、标题、正文、分类、重点及发布时间用于查询；发布时间按北京时间显示。同一来源 ID 修订后更新当前正文，不另保留所有旧正文。

## 限制与排错

可见窗口结束还没接上断点会报 coverage 错误，不宣称无缺口。重新建立最新窗口基线不能补回全部历史。新闻作为信号不能在公布前使用；没有新闻证券关联或全历史正文的通用保证。
