# 开盘啦分时及竞价

## 浏览细节

七项查询页显示市场、证券名称代码与当前查询日期标题。各完整单日图保留原来源点及实际时段，图例使用线型和科目名。逐笔默认精确明细，另提供“当前页价格概览”：仅绘制当前明细页，使用原来源序号，不能当作全天走势或整个时间窗。图表选择与明细行联动，不重新编号。

## 如何查看

在数据目录分别打开六种序列及独立盘口页，搜索本项目已归档证券，选候选后读取最近归档日；上一/下一归档日只查本证券本项目。也可手输市场、代码和日期查询。分时为价格/均价与来源量；竞价用来源序号轴保留同分钟点；分钟量额分量/额面板；委托分买卖量及额面板；大单净额保留零轴和来源正负，不再累加。完整有限单日序列用于图表，明细每页200点，午休及缺分钟不连线。可隐藏面板、用按钮缩放/平移、鼠标或方向键查看精确值并定位明细。分时成交明细默认指定时间窗，分页只解码有界块，来源序号不重编，同秒不合并；来源标记和未解码字段可展开，Ctrl+C复制所选行。来源量额单位未确认，不推导区间合计、买卖成交方向或主力资金。

## 数据范围与更新

各项独立任务、计划、断点与验收。quote支持命令行显式有限运行范围，其他六项保持原全池入口。`collect-intraday --kind quote --securities 000001.SZ --start 2026-01-01 --end 2026-10-20 --proxy-priority`仅本次运行优先代理，不改保存策略；最多50证券、3660日。范围绑定断点，待归档时不得切换范围；中断恢复复用原参数，完成后无参数的日常计划仍按全池规划并从SQL补缺。初始化完成须范围内每个必要证券日校验入队及确认归档、无来源缺口；失败和取消使用原公共恢复/清队规则。默认停用，推荐每天 18:00 更新，显式保存优先。数据目录中的七个入口、已保存策略及页面顺序在业务模块收拢后保持，切页只读查询由页面取消，采集与归档仍独立运行。2021 年起至最近已结束交易日，限当前上市沪深北证券，排除上市前、北交所开市前和明确全天停牌日；普通轮补缺、新日，每周复核最近五个交易日。无待补或复核日期时不请求行情。

停复牌区间排除完整停牌日，复牌日仍采集。复牌时间未知、说明明确全天或连续停牌且生效不晚于09:30时，只排除生效首日；不将未知复牌延伸到后续日期。空说明、盘中开始或同一停牌时刻存在当日明确复牌时，不据未知记录排除整日。采集与数据准备采用同一规则，排除集合改变后自动重建范围，不写空行情行。

## 字段与日期

分时、量额、委托及大单校验 241 个精确分钟键；竞价保留完整来源数组，但无独立总点数。分笔校验 Count、total 和数组长度，同秒不合并。不自造 OHLC、复权或交易所事件编号。当前股票池有幸存者偏差，更早修订不保证回查。

## 限制与排错

查不到不等于无成交或停牌。缺分钟、总数错配、证券日期错配、全零占位行情均报错保留缺口。每个完整证券日入队后继续采集，整轮末确认归档；前序失败不能被后序成功掩盖。当前无沪深 300 / 中证 500 范围选择。

HTTP 成功、errcode 为 0 也可能缺少分钟；缺失的委托量不能填零、插值或按前值补齐。errcode 1017 不区分历史无权限、不支持证券或其他来源故障，不能据它自行排除证券日。核验旧缺口必须保留原证券、产品和日期，新日期有数据不能证明旧日期已恢复。
