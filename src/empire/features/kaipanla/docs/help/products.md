# 历史盘口与日行情摘要

## 浏览细节

证券身份和日期提示可换行，五档买卖价格与数量列保留合理宽度。更多字段及来源说明仍按需展开；独立关联分时和查询日期保持明确。

## 如何查看

打开历史盘口与日行情摘要，选择证券及归档日。页面突出某日历史快照，报价、估值/股本/日统计、五/十档盘口与独立分时分区；窄窗口盘口移到图下。技术来源字段按“更多来源字段”展开，负估值、0和未知分别保留。分时来自独立归档，盘口有值而分时缺失时分别提示；可带证券日跳独立分时页。不从快照造走势，也不把来源time原值解释为精确时间戳。

## 数据范围与更新

开盘啦七项中的 quote 独立任务。来源保存证券日历史摘要；生命周期、补缺、计划和每周复核沿用七项规则，不是全天秒级盘口回放。归档成功才可查询。查询与其他六项分开，页面按需创建；停用本项界面不等于停用采集或删除已归档数据。

## 字段与日期

原始 OHLC 来自收盘后历史摘要，零、显式空值和缺字段分别保留。日字段与分钟/档位有类型保存，分笔用有界块保持顺序；稳定字段可有界投影查询，页面分页不每次解码全年历史。

总股本（total_shares）、流通股本（circulation_amount）与总/流通市值同属证券日快照。“实际流通市值”（actualcirculation_value）是金额，不是来源直接公布的自由流通股数；用市值除以股价只能得到派生值，不能冒称来源公布值。快照日期不是公告或法定变更生效日期。数据准备统一从本项引用这些字段，取消独立股本采集规划；市值重算仍是待接入的计算工作。行情完整性通过不表示所有股本值、大小关系及估值公式输入均已验收，零值和未知保持可见。

## 限制与排错

摘要不证明完整每日原始行情、全天盘口变化或券商席位。量额单位不确定时不能用于复权量或总收益；必需字段为空不归档。完整整日核验与数据准备仍可能更慢；分笔块不能直接在 SQL 任意逐笔聚合。

`1017`表示接口未提供有效响应，不能一律当作停牌或空日；已归档的明确停牌生效首日由规划排除。正文日期不符仍保留缺口。北交所新旧代码映射入库不表示来源全部历史日期已可用，近期查询成功也不能证明旧日期已补齐。
