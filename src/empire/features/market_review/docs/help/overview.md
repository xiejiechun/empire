# 市场复盘

## 如何查看

从“市场观察 → 每日复盘”进入全景导图。整体行情、资金流向、连板梯队、晋级断板、核心判断、次日观察六条分支可分别收起或展开；“全部展开”恢复六条主线。沿用明暗主题和可折叠侧栏。

“复盘日期”首次进入或重启默认北京时间今天，选择或输入年月日后立即读取当日已归档行情；切页保留会话所选日期。“今天”回到北京时间当天，“刷新行情”重读同一天已有归档，不触发采集或盘中轮询。滚轮不会修改日期。准备交易日按正式日历显示，日历缺口时不推算。

## 数据范围与更新

整体行情已接入真实数据，包括涨跌停、首板和连板、归档个股成交额及较前交易日变化、含暗盘主力资金、资金榜样本涨跌家数，以及已存储的主要指数收盘点位和涨跌幅。展开“指数点位与数据口径”查看说明。

成交额是已归档沪深京个股合计，显示当日与前日样本数，未归档证券不计入。资金和涨跌家数来自东方财富完整资金榜，显示榜内证券数量；资金为含暗盘模型测算，涨跌家数不代表全市场。涨跌停沿用远航实际来源池范围，首板和连板按正式连续交易日涨停集合计算。

资金流向已接入同日完整个股资金榜：显示含暗盘主力净流入、明盘和暗盘合计。展开“个股资金排行与口径”查看净流入、净流出各前5只及证券代码、当日涨幅；流入仅取正值从大到小，流出仅取负值从小到大，同金额按代码排序。完整日榜没有相应方向个股时明确显示“当日无净流入个股”或“当日无净流出个股”，不是缺值。板块主力流入、流出按同花顺当前行业成分股汇总所选日的含暗盘主力净流入，正值降序、负值升序各取前5，同金额按行业编号排序。固定标注“自行汇总 · 按当前成分股回看”和“按已覆盖成分股合计排名”；每行显示覆盖x/y只，部分覆盖只合计已有记录，缺失证券不填0，无覆盖行业不入榜；若全部行业均无覆盖，榜单显示“缺少数据来源”并解释原因。已覆盖合计为0不进入任一方向，方向无结果显示已知空榜。历史结果不代表当时行业归属，当前成分更新后可改变。展开口径可见当前成分归档核验时间及完整、部分、无覆盖行业数量。行业集合与归档证明不一致时仅板块显示“缺少数据来源”及原因；本日、前一交易日“ETF净申赎估算”读取上交所、深交所精确每日份额与天天基金净值。展开“ETF数据覆盖与缺项”查看候选覆盖、有效覆盖以及缺份额、缺净值、仅收益、币种未核实、事件校正依据缺失等原因；同一证券的币种和事件缺项可重叠。当前缺少可靠币种及折算等非申赎事件来源，不默认人民币或零校正，金额保留“缺少数据来源”。按当前ETF目录回看，部分覆盖不代表全市场，份额与净值已归档不等于估算全部输入就绪。

指数点位改从同花顺远航版指数日K读取，北证50使用899050；目录来自远航A股指数。尚未采到对应事实、外围缺来源，或日期、前日基准、集合完整性不足时，字段显示“缺少数据来源”。休市、未来日期与当日15:30前不展示日终统计，不将上次交易日移到当前日期。指数点位存在但前一交易日缺失时保留点位、涨幅仍显示缺值。

## 字段与日期

复盘日和准备交易日分开展示。金额用亿元或万亿元，悬停资金金额查看精确元值；点位与涨幅分别显示，缺值不填0。真实整体行情、个股资金与其他分支的虚拟分类、判断、预案分别标识，不能相互推导。明盘加暗盘等于含暗盘主力净流入，均为来源模型测算，不是实际暗盘成交。

## 虚拟模块与本机保存

其余四分支暂仅保留2026-07-31的虚拟样例，每区标注“虚拟示例”；其他日期为待接入。“查看虚拟样例”切到该日期，整体行情和资金流向仍读该日真实归档，不再使用虚拟资金排行或ETF金额。虚拟样例的90家首板分类、10只连板、判断与次日观察不代表实际市场，不与真实行情统计相互推导。虚拟证券详情同样独立标识。

虚拟样例的“列入预案”立即保存在本机，“复盘笔记”需显式保存；成功后跨启动保留。未保存草稿在当前会话切页或关闭编辑窗后保留。切换日期不丢失样例草稿；其他日期笔记不可编辑。笔记与预案不写MySQL或Redis，清除本机数据会丢失，也不会同步到其他电脑。

## 限制与排错

读取失败单独提示并可刷新。同日刷新失败保留上次结果与查询时间；切日期清除旧日数据，迟到回执不覆盖新日期。没有把失败查询回退成虚拟行情。数据缺失时到原采集任务核查，查询自身不会补采。保存失败时编辑内容保留，可重试；本机记录损坏时明确提示，保存前须核对。
