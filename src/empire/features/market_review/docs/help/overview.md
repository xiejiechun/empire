# 市场复盘

## 如何查看

点击左侧一级主菜单“市场复盘”。输入开始、结束日期，点击“查询复盘”，再切换复盘交易日。默认最近90自然日，单次最多120自然日。修改日期不会自动覆盖当前结果；点击查询才应用草稿。日期切换只使用已查询结果，要读取新归档数据请再次查询。

市场趋势支持悬停、方向键查看、放大缩小和前后移动；晋级趋势单独对比封板率、1进2率和连板晋级率。当日梯队、最高板时间线、题材轮动、近10交易日热度及完整统计分别放在页签。题材轮动可横向滚动，点击同一题材高亮，再次点击取消。表格可复制核对。默认选中范围内最近有涨停池归档的交易日，仍可主动切到尚未归档的交易日查看缺口。

## 数据范围与更新

只读远航日终涨停/炸板/跌停池、正式交易日历和开盘啦每日题材列表。查询不启动采集、不修改任务配置，不保存第二份业务数据；MySQL独立可用即可查询，不依赖Redis。数据由既有采集任务更新，重启不会补造未采集历史。

涨停池使用HS/GEM2STAR来源口径，包含来源实际返回的ST等成员，不按当前股票名单裁剪。查询额外读取前30自然日用于确定连续涨停起点。题材历史仅包含实际归档日期；不足10个交易日时明确显示覆盖天数，不用缺日当0计算热度合计。

## 字段与日期

封板率为涨停证券数除以涨停与炸板证券并集数。连续板按相邻正式交易日是否在涨停池计算；来源“N天M板”仅展示，不等同连续涨停。1进2率为昨日首板且今日涨停数除以昨日首板数；连板晋级率为昨日连续至少2板且今日涨停数除以昨日连续至少2板数。所有比率显示百分数，零分母显示“—”。

连板起点未知或中间缺池时不猜测连续高度，完整连板数及最高板显示未知。并列最高证券全部保留，“最高板”不等于主观总龙头或人气股。题材按稳定身份关联，轮动采用来源排名；子题材没有排名，不为其编造全局名次。

## 限制与排错

本页复现可计算的市场事实，不复现外部Excel作者的势能、动能、情绪阶段、建议仓位或人工操作策略。来源报告空池与未归档缺池分别呈现；空池不能证明早期市场没有事件。缺数据不会在曲线上填0。

日历不完整时查询明确失败。池头和成员数量不一致时拒绝出统计；这不是对原始来源的重新实采审计。行情来源更新范围、股票过滤方式和题材排名方法可能与其他看板不同。查询超容量请缩短日期范围。采集缺口须回对应任务检查，查询页面不会直接补采。
