# 交易规则与税费

## 如何查看

在“数据浏览”目录搜索涨跌幅、买入后何时能卖、最小买卖数量、最小价格变动、交易时段、印花税或过户费。业务归组后仍使用原七项入口与保存设置，独立采集、查询、页面插件的启停方式保持。七项有独立页面，市场筛选及每页最多200条；市场、板块和参数用中文显示，涨跌幅与税费率显示百分数及%单位，未知终止日显示“未明确”。选择参数查看原文和依据链接。“管理采集任务”直接打开对应项目。

## 数据范围与更新

七项独立项目，默认并已通过正式任务配置保存固定间隔259200秒，即每轮结束后3天再次运行，不重叠；修改和保存立即影响后续计划，网络与重试下一轮生效，已保存计划在MySQL保留，电脑重启不丢失。普通采集和重新初始化均重查已登记文件，保留历史生效段；已入队轮次先确认归档，下载中断从未入队整轮重查。Redis丢失重新核验官方文件，不承诺恢复丢失的待归档消息。

本次只需当前规则。涨跌幅、买入后可卖、数量、价格档位和时段当前核验沪深北2026-07-06生效普通竞价版本；主板、科创板和创业板分别记录。北交所盘后条款仍暂缓，不列为可用时段；更早历史本次不补齐。印花税保存2022-07-01法定千分之一及2023-08-28减半后的万分之五，卖方缴纳，买方不缴。过户费保存新华社转述中国结算的2022-04-29调整公告：沪深北A股按成交金额十万分之一双向收取；这份历史公告不能证明2026现行完整收费表已经核实。

五项交易所任务共用一分钟内已核验的解析结果，必要文件每轮默认请求一次，不保留成功原文。三个税费网页和过户费报道独立核验。交易所新目录版本、参数集合、引用条文变更会失败并保留旧数据，需审核新契约后再采集；固定税费文件复查不是全部新政策目录扫描，后续政策仍需审核补充。

北交所目录已更新为2026-10-16的43号实施公告：3.6.5条第二、三款的大宗交易报价范围在10月26日实施，普通竞价参数及生效日期不变，盘后交易仍未启用。五项任务使用新公告核验来源；遇到新的公告日期、条款范围或目录变化仍报错，须重新审阅后更新程序。

## 字段与日期

参数按市场、板块、条件、参数和生效起点识别，数值采用精确十进制；比例0.10表示10%，税率0.0005表示万分之五；数量单位股，价格单位人民币元，时段为北京时间。结束日期为空表示来源未明确终止，不能把它解释成已确认永久适用。税费的买卖方向分开，不能用交易所经手费代替过户费。

买入后可卖暂存“交收前不得卖出”的正式条款，数值T+1交收依据尚待补充；科创板最低200股及上限已明确，递增数量尚缺单独依据；过户费最低费用保持未知，不填零。这些缺项在数据准备显示失败，与采集及归档完成分开。

## 限制与排错

数据准备按证券及日期范围比较全部参数、引用和归档证明。空白证券范围包含北交所，普通竞价条款已采；沪深T+1数值、当前数量递增、北交所涨跌价舍入及现行过户费表仍未齐，相关质量检查保留失败。早于支持起点的历史回测仍缺历史规则，当前规则不能回填早期。停复牌和特殊上市日还须结合事件数据，不能仅靠本表决定每日是否可以买卖。

上交所现行通知附件地址更换后，须重新核实正文条款摘要、生效日和暂缓范围，再更新已审阅地址；当前已同步新地址，业务参数不变。附件校验页、缺条款、同数异集、未审核规则或断点合同变化不会推进成功断点。SQL或确认失败保留待归档消息，提交后可安全重放。若官方文件发生新修订，先核实生效日期、暂缓条款及业务条件，不以重复请求代替修复。中国结算现行PDF在本次调查返回校验页，保留该来源限制，历史公告采集完成不等于现行费用准备通过。
