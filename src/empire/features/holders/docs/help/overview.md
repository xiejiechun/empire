# 同花顺前十大持有人

股票定期前十栏目保存完整来源名单，最多200人；000065可含末位并列，000430的2026-03-31流通股东有11人且末两人数量不同。按全部成员核验数量和比例汇总，保留页面顺序，不截取十行或推断扩展原因。旧库通过scripts/migrate_holder_ties.py显式升级人数约束，已有业务保留，启动不自动迁移。

空名债券缺口包含报告期和页面定位，数据准备明确列出；来源补齐后重新采集恢复。旧版积压消息通过显式维护入口migrate_holder_source_rows.py --pending-only转换后统一归档，不在启动时转换。

若整轮仅有已隔离的空名债券，检查至末尾并确认有效报告全部归档后显示“已结束（来源缺口）”。运行详情分别显示失败单元、身份缺口证券/报告数和连续补采起点，债券数据准备仍显示实际缺口。混合结构校验失败或归档失败继续报错；历史失败记录保留原结果。

## 如何查看

数据浏览目录搜索“前十大股东”“前十大流通股东”或“十大债券持有人”，输入证券代码、报告期范围后查询。选中一份报告查看当前名单和退出名单；债券名称用于区分同一发行人的不同债券。列表每页20份，翻页保留筛选条件。

数据准备选择证券和分析用途后检查，逐证券核验本栏完整报告集合；无关证券缺口或旧整轮证明不会影响已核验证券。全市场范围保留真实缺口并提供证券定位。来源明确未提供栏目与缺少归档证明分别提示；确认时效按每证券检查，质量异常保留源值并说明用途限制。

## 数据范围与更新

采集管理有一个“股东研究（同花顺）”任务，开发时配好每日北京时间18:00、代理优先且允许回退。新任务初始停用，保存启用后下一轮生效；已保存任务和网站配置在MySQL，重启保留。每轮按当前股票池逐证券核验三个栏目全部可见期，一证券HTML正常请求一次，三栏一起校验、入队和同事务归档。三个浏览页均定位到同一个采集任务。来源窗口外的已归档历史保留，但较早修订无法通过当前窗口发现。持股详情弹窗属于某持有人的历史及其他持仓研究视图，不属于本次前十名单范围。

暂停或正常关闭后按连续成功前缀恢复；有缺口时后续有效证券可以继续归档，但连续起点仍保留在首个缺口。当前股票池变化会重建本轮范围；重新初始化只重核当前页面窗口并保留历史和已入队数据，若正等待归档则先确认原轮次。Redis服务重启后内存断点与待归档消息可能丢失，程序从当前池首证券重新核验，MySQL中已归档历史仍可查询。

## 字段与日期

当期/退出持有数量为横线时保存未知（NULL），与显示倍率和小数位同时为空；明确零仍为零，不按比例、减持量或其他报告推算。未来报告期保留来源日期并提示早于来源报告期观察到的限制，不能提前用于历史信号。空名债券报告隔离为身份缺口，同证券可识别报告保存，其他证券继续；债券准备提示报告期，股东两栏不受空名债券连带阻断。数量按股或张保存，显示原页面万/亿及小数精度；行内单位必须与栏目一致，显式“股/张”按自身倍率换算，不能重复套用表头倍率；比例为百分数，比例基数保留总股本、流通股或A、H流通股的来源口径；“累计持有A、H流通股”汇总标签按同一契约识别，完整名单和汇总均保留。持股变化、股份类型和质押字段按来源提供，未提供保持未知。退出名单数值来自上期，不能当本期持仓。报告期不是公告日，来源未提供可信公布日期，不能提前用作历史选股信号。

## 限制与排错

“主要股东持股变动公告”可能超过或少于十人，单独标记为变动公告，汇总未知，不冒充完整前十。同日公告与定期报告各自保留身份。债券来源排名独立于行位置保存，可并列或缺口；退出排名为上期参考，名单按组内页面行位置显示，不补造记录。完整页面明确未提供债券栏目时记录“栏目未提供”，不表示没有债券持有人。

同一页面的一个空名债券块与另一个有名债券块即使报告期相同，也不能据此认定是同一债券。正式查询可显示可识别的报告，但该日期的空名块仍是身份缺口；用于估值或持有人研究时须保留这项限制，不能把其他报告的名称补进来。

结构或必需字段损坏、重复身份、非法日期及报告标签不匹配会拒绝该证券入队；可识别报告的未知数量/比例或来源汇总矛盾保留原值并标记质量限制。父头当前/退出计数与正文不符也会报告不完整。单证券结构校验失败后继续检查后续股票，有效报告照常归档；整轮末确认已入队消息后仍显示失败，不生成完整范围证明。仅空名债券按前述“已结束（来源缺口）”处理，不能以已归档有效报告冒充债券栏目完整。

已检查进度包含失败证券，连续进度停在首个缺口；再次继续从首个缺口补采。网络、配置及归档故障仍按公共流程停止。后续股票不等待逐批归档，无缺口的整轮确认全部消息成功才显示完成。相同内容不写业务表，插入、修订、相同和旧版确认成功均清理对应队列，归档失败保留待重试。
