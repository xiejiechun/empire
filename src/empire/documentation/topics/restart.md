# 重启与配置保留

| 场景 | 配置与数据 | 下次执行 |
| --- | --- | --- |
| 只关闭、重开 Empire | MySQL 配置和数据保留，Redis 仍运行则保留断点与记录 | 保留原 next_due；已到期计划在启动后执行 |
| 电脑或 Redis 服务重启 | MySQL 配置和数据保留；Redis 待归档数据、断点、下次执行时间与记录丢失 | 固定间隔从应用启动重新计时；每日计划选择下一个北京时间时间点；手动和禁用任务不执行 |
| MySQL 暂不可用 | 无法保存配置，不显示保存成功；采集依赖未就绪 | 先恢复连接，再保存或启动相关插件 |
| MySQL 已保存，Redis 同步失败 | 配置已经持久化并在当前进程生效，界面显示同步提示 | 下次启动以 MySQL 为准校正运行计划 |


## 正常退出

关闭窗口会等待采集、归档和已接收数据库操作结束，然后释放单实例锁。应用关闭期间不采集，不是后台常驻服务。
