# 归档与错误记录

运行记录页面分成“采集记录 / 归档记录 / 错误记录”三个标签。后两类由 `collection.records` 插件管理；错误列表按 `project_id` 每页读取 50 条，新记录在前。摘要只含表格所需字段，选中后才按 ID 读取一条完整详情；修订号未变化时轮询不重复返回列表。

## 正式记录路径

字段分别查 [Redis collection-control](help:Redis%20collection-control)、[Redis archives](help:Redis%20archives)、[Redis errors](help:Redis%20errors)。列表修订号只用于轻量查询，不证明归档或修复已完成。

## 修复与清理

先登记项目和确切错误 ID，先修复并验证，再按确切 ID 清除；保留并发新增与未解决记录。查看记录或后续一次成功不会自动清除错误。用户主动日志清空属于记录管理，不代表问题解决，操作见 [日志清空与修复记录](help:日志清空与修复记录)。

## 脱敏

文本、URL、元数据和后台快照通过同一脱敏器处理，覆盖密码原文及 URL/JSON 转义形式。结构化内容先脱敏再序列化，不能对完整 JSON 字符串简单替换密码；敏感字段键名和正常业务结构保持可读。成功正文不进入这些列表。
