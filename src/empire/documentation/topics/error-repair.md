# 日志清空与修复记录

## 日常清空展示历史

在采集记录、归档记录或错误记录选择项目，点击“清空日志”。确认窗口显示所选项目和记录类型；清理包含该范围全部分页，选择“全部项目”时覆盖当前记录类型的所有项目。默认取消，确认后显示删除数量，之后新产生的记录继续显示。

## 数据与计划边界

只删除操作日志，不改变任务启停、计划、断点、待归档消息或 MySQL 业务数据。清空错误不表示问题已修复，之后仍可能再次报错。Redis 服务重启也会丢失有界运行和错误记录，不作为永久审计库。

## 程序错误如何结案

根据错误记录修复时，先登记项目和错误 ID，复现并验证后用精确 ID 清理已解决项，在处理记录中注明结果。保留尚未解决和并发新增错误；一次成功不能证明旧错误已经修复。
