# 下载资源与生效时间

**入口：采集管理 → 下载资源。**

## 保存步骤

1. 查看“当前生效”和“已保存”的区别。
2. 输入容量或选择 100～1000 台十档生成推荐草稿。
3. 检查窗口、共享缓冲、单响应、文件和磁盘限制，点击保存。
4. 正常退出并重开 Empire，确认新值成为当前生效值。

配置保存于 MySQL app_setting，电脑重启保留；未保存草稿不保证跨重启恢复。当前请求和资源对象保持旧值直至正常关闭。

## 推荐值是什么意思

默认 100 档为 128 窗口 / 512 MiB 缓冲，1000 档为 1024 窗口 / 4096 MiB。规划设备数不是在线独立出口数，也不是实测吞吐。推荐不自动改每 IP 访问间隔、全站保护或任务代理策略。

## 限制与校验

必须满足“3 × 最大内存响应 + 256 KiB ≤ 缓冲预算”和“单文件上限 ≤ 目录配额”。默认股票、新闻、日历正文上限分别为 1 MiB、4 MiB、512 KiB；正文和临时复制计入预算，预算不是整个 Python 进程内存上限。

文件下载默认单文件 256 MiB、并发 4、目录配额 2 GiB、磁盘余量 128 MiB；当前不因此新增公告或 PDF 业务。详细参数见 [连接与容量参数](help:连接与容量参数)。
