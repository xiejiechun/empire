# 配置位置与首次运行

## 当前默认位置

打包程序只读取 Empire.exe 同目录的 config.toml；源码及维护脚本默认项目根目录 config.toml，与工作目录无关。--config 是显式覆盖入口，不搜索旧用户目录或旧版 config/local.toml。

## 首次启动

缺少配置时仅在程序目录生成模板，填写 Redis / MySQL 后再次启动。程序目录不可写会明确报错，不静默回退 C 盘。配置包含凭据，不提交 Git、不作为公共分发文件；复制带配置的程序目录也会复制凭据。

## 旧配置与业务表

旧连接配置仅经 scripts/migrate_program_config.py --source <已核实旧配置> --destination <程序目录/config.toml> 显式迁入，保留旧文件，目标不同拒绝覆盖。应用启动不自动迁移或重建业务表；结构维护遵循独立维护入口。

日志、单实例锁、插件偏好和默认下载位置仍在用户数据目录；不要把业务数据库故障当成配置迁移。维护契约见 [配置表与迁移](help:配置表与迁移)。
