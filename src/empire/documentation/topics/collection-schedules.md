# 执行采集与计划

**入口：采集管理 → 采集任务。**

## 手动执行

1. 在“采集任务”左侧展开一级数据来源（新浪财经、巨潮资讯、通达信、同花顺等），选择二级具体任务；支持名称、分类、来源及状态筛选，全部匹配任务一次展示，不分页。一级来源仅用于分组，不能启动或配置整个来源。
2. 确认任务已启用；修改启用状态后先保存。
3. 点击“立即采集”，已有断点会继续执行。
4. 在“运行记录”查看结果。归档完成前，数据页面仍可能显示上一次结果。

“重新采集”用于明确重新建立采集批次。股票重新拉取完整列表，新闻从最新一页开始，日历重新核验全部范围；已有 MySQL 业务数据不会直接清空。

## 批量启动与停止

在“采集管理 → 采集任务”展开来源，点击第一个任务，按住 Shift 点击最后一个任务可连续选择；Ctrl 点击可增减不相邻任务。列表下方显示已选数量，来源标题不计入任务。自动刷新保留多选；筛选后仅保留仍在列表中的选中任务，不对隐藏任务操作。

点击列表下方“批量启动”，逐项启用并保存所选任务，使用各自已保存的计划、网络和重试配置立即采集或续采；正在执行的任务跳过，不重复启动，不创建 fresh 批次。暂停的任务可直接批量启动，启用后的自动计划也恢复生效。未保存编辑草稿保留，不自动保存到任务配置。若启用成功但启动失败，会明确提示已经启用，需按错误处理或批量停止关闭计划。

“批量停止”沿用暂停流程，停止所选任务当前执行并将禁用状态保存到 MySQL，关闭后续自动计划；保留采集断点、已入队消息和业务数据。重启后仍停用。批量操作期间按钮暂时禁用，切页不会取消已经提交的操作。结果显示成功、跳过、失败数量，最多预览三项异常的简短原因，悬停结果可查看完整逐项结果；某项失败不阻止处理后面的任务。任务已归档则跳过。

## 自动更新

所有采集任务的“单次请求失败重试”可设置 0～100 次，首次请求另计，100 次最多为 101 次普通尝试。初始仍为 2 次，已有设置不变；点击“保存执行计划”存入 MySQL，下一轮生效。网络异常及 429/502/503/504 按该预算重试；同花顺指数YYYY年度文件额外将已声明历史中的临时404纳入相同预算，耗尽仍报错并保留断点。其他请求的404规则不变，业务校验错误仍停止且不推进断点。退避依次为 1、2、4、8、16 秒，之后每次最多 30 秒；共享频控与全站 429 冷却继续执行。默认总时限为 120＋max(0, 重试次数－2)×60 秒，100 次为 6000 秒；显式更短时限、暂停或取消可提前结束，不承诺每次都耗尽预算。

暂时不用的任务可点击“归档任务”：停止当前采集与后续计划，保留配置、断点及已归档数据；已入队数据仍正常归档。默认列表隐藏归档任务。进入“采集管理 → 归档任务”，选中后点击“还原任务”，沿用原来的计划和启停状态；原先暂停的任务仍需启用并保存。归档状态保存于MySQL，电脑或Redis重启后保留。

同花顺股票列表默认每天北京时间18:00核验一份当前目录，可修改计划。普通轮次请求一次完整单页，校验后分块入队，整轮归档才完成。股票单响应至少需要容纳整份HTML，当前推荐8MiB，通过“下载资源”保存并正常重启后生效，仍受共享缓冲校验。新浪股票任务可保留在归档中，恢复后走同一当前目录写入器；当前目录只保留一份，最新有效完整批次替换之前内容。

股票目录请求使用程序内固定的同花顺校验协议生成临时会话，不读取浏览器资料。若来源校验规则改变而返回401/403，错误记录会保留，任务不推进断点，旧目录继续可查；需要更新协议后重试。

开盘啦七项开发时已配好推荐默认任务配置：每日北京时间 18:00 检查更新，首次补历史，之后补新增日与缺口，每周复核最近五个交易日。可直接使用，也可在任务配置中修改手动、固定间隔、每日定时及对应时间；启停、重试和网络方式仍可编辑。修改后点击保存执行计划，配置存MySQL，重启和Redis丢失不覆盖已保存选择。推荐默认值只用于未保存配置的新任务。

| 方式 | 执行规则 |
| --- | --- |
| 仅手动 | 点击采集时才运行。 |
| 固定间隔 | 从每次任务结束后等待 1～2592000 秒，同一任务不会重叠。 |
| 每日定时 | 按北京时间在选定时刻执行，应用需要保持运行。 |

任务菜单与详情独立显示，宽窗口左右分栏、窄窗口上下布局。来源括号中的数量表示当前筛选匹配的任务数。刷新保留菜单选择、展开状态和滚动位置；切换任务或筛选保留按任务保存的未保存草稿。

右侧顶部显示任务名称、来源和分类；悬停任务名称可查看任务 ID，业务说明位于运行详情内。立即/继续采集、暂停任务、重新采集在同一行，暂停仍会关闭后续计划并保留断点，重新采集会建立新批次。一级来源仅显示选任务提示，不展示空的详情表。

下方分为“运行详情”、“任务配置”和只读的“采集规则”。采集规则逐任务展示来源链接、全部请求参数、初始化、增量、范围边界、恢复和Redis/MySQL去向，可按章节定位并复制；不改变草稿或触发采集。宽详情区将状态与进度、时间与计划并排显示，网络及异常随后展示；空间不足时自动改为纵向。长说明和完整错误在详情内部滚动，菜单、操作栏和配置保存栏保持在内容滚动区外；较小窗口仍可滚动整页访问底部操作。配置字段宽时按标签/输入两列对齐，窄时换行，保存和撤销只在配置标签底部出现。菜单分页采用简短页码及上一页/下一页箭头，悬停显示完整分页信息。

修改后点击“保存执行计划”。配置立即写入 MySQL，电脑重启后保留；未保存草稿不保证跨重启恢复。暂停任务会同时保存禁用状态，恢复前需重新启用并保存。
