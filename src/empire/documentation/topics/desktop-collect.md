# 采集与计划

## 立即采集

选择任务后点击“立即采集”。任务须处于启用状态；需要启用时在“执行计划”中修改并保存。已有进度时，按该任务的恢复规则继续。同一个任务不会同时运行两轮。

只有需要重新核验范围时才使用更多菜单中的“重新采集”，先阅读确认框里的范围说明。它不等同于删除已有数据，也不保证所有来源都从最早日期重采。

## 自动执行

打开“执行计划”，选择执行方式并点击“保存计划”：

| 方式 | 何时执行 |
| --- | --- |
| 仅手动 | 点击采集按钮时执行 |
| 固定间隔 | 每轮结束后等待设定的秒数，再开始下一轮 |
| 每天定时 | 按设定的北京时间执行 |

计划保存后生效；代理和重试设置从下一轮生效。关闭面板会保留本次会话的未保存草稿，但退出软件前仍须保存。后台刷新不会替你保存输入。

## 暂停、归档与批量操作

更多菜单中的“暂停并停用计划”会停止当前采集及后续自动执行，保留已有进度和数据。恢复时重新启用任务并保存计划。

不再常用的任务可以“归档任务”，它会从普通任务列表收起并停止后续计划，已有业务数据保留；可从“已归档任务”还原，还原后检查计划状态。

批量操作完成后查看逐项结果，部分成功不代表全部完成。
