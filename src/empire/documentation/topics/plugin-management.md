# 运行状态与插件管理

## 检查服务

在“系统设置 → 运行状态”查看数据库连接、待归档数量、浏览/持久化通道及后台异常。浏览最多执行 2 项、等待 16 项；持久化最多执行 1 项、等待 32 项。排队满会明确拒绝本次操作，可稍后重试。

版本行显示版本、短提交号与工作区状态；停留在版本提示上可查看完整发布 ID、源输入 SHA-256、构建时间及依赖摘要。排查某个安装包的问题时据此确认实际运行版本，更新程序后正常重启即可生效，无需保存设置。

## 启停插件

“插件管理”按功能启停。停用界面插件释放页面及草稿，不等于暂停对应采集器；日常暂停任务请在采集任务页操作。依赖未就绪的能力不能正常执行，不自动修改业务表解决问题。

## 故障恢复

关键后台循环退出显示运行失败，临时服务问题显示运行异常。先解决原因，再正常停用后启用或退出重开；仍拥有资源的失败插件不能直接重复启动。

如果启动时提示 `Invalid Empire build manifest` 或 `Missing Empire build manifest`，说明安装包的构建清单不兼容、损坏或缺失，需重新执行正式构建并完整替换程序包，保留同目录配置。不要手工删改清单或改数据库来绕过检查；源码运行的“开发环境”提示不能用来解释正式 EXE 缺少清单。
