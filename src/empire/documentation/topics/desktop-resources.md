# 连接与资源

## 代理与采集出口

任务“执行计划”里可以设置“优先使用代理”和“代理不可用时允许回退直连”。通常保留当前设置；关闭回退后，代理不可用时不会自动改用直连。

“采集出口”用于查看当前出口情况。多个任务会共享站点访问限制，等待许可不一定是程序卡住。站点限流时不要反复重新采集。

## 平台身份

从任务“资源与身份”或侧栏“身份管理”查看平台身份和当前操作。身份服务可能由同平台多个任务共用，调整前注意影响范围。刷新页面只是读取状态，不会自动重新认证。

## 何时修改资源

“共享资源”同时展示当前生效值和已保存值。“生成容量草稿”只填写建议值，仍需点击“保存资源配置”，再正常退出并重新打开才能生效。不要把规划设备数当成实际在线出口数或下载速度。

站点访问规则从任务“资源与身份”进入，修改会影响同站点任务；保存规则不会解除来源要求的限流等待。
