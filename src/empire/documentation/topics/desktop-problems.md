# 常见问题

## 任务失败怎么办

打开任务的“运行与记录”，查看错误时间和详情。反馈问题时提供任务名称、操作和错误内容，不要附连接密码。

临时网络失败可以在恢复后再次立即采集，具体恢复范围见“采集说明”。持续出现同一错误应先处理原因，不要反复“重新采集”。清除错误记录不能修复问题；仅清除已经修复并验证的记录。

## 100% 了为什么还没完成

采集完成后还需要等待数据归档。查看是否显示“等待归档”，以及是否有归档或数据库错误。累计入队数量不等于当前尚未处理数量，不要为了消除等待而重新采集。

## 数据没有更新

先确认这一轮是否完成，再检查预览中的证券、栏目及日期条件。读取失败时页面可能保留旧值并提示过期，应先恢复连接。是否支持某个时间范围，以任务“采集说明”为准。

## 设置保存了为什么没变化

执行计划保存后生效；代理和重试从下一轮生效；共享资源要正常重启软件才生效。未保存的编辑只是草稿。

## 无法启动或连接

本机启动入口为 dist/EmpireDesktop/Empire.exe。连接配置在它旁边的 config.toml；当前启动器依赖本机项目环境，不能仅复制一个 EXE 到其他电脑使用。

如果提示已有程序运行，先正常关闭原窗口，等待退出后再启动。如果提示数据库连接失败，检查相关服务和连接配置。不要删除锁文件或公开配置里的密码。

## 退出与重启后会怎样

关闭窗口时等待后台收尾，不要强行结束进程。已经归档的数据和已保存计划会保留；电脑或 Redis 服务重启会丢失尚未归档的数据、临时进度和运行记录，后续按各任务恢复规则补齐。只重启客户端且服务仍运行时，可以继续利用保留的临时进度。
