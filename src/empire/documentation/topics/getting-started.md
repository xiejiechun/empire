# 开始使用

## 先做哪一步

| 你的目的 | 从这里开始 |
| --- | --- |
| 查看已经保存的数据 | [查找与浏览数据](help:查找与浏览数据) |
| 更新一份数据、设置自动执行 | [执行采集与计划](help:执行采集与计划) |
| 判断范围、质量和用途是否够用 | [数据准备](help:数据准备) |
| 查不到数据或任务报错 | [任务失败与数据未更新](help:任务失败与数据未更新) |
| 查数据库表、键与文档分工 | [文档分工与更新](help:文档分工与更新)、[数据库职责与查阅](help:数据库职责与查阅) |
| 第一次配置程序 | [配置位置与首次运行](help:配置位置与首次运行) |

## 一次完整的使用流程

1. 在“系统设置 → 运行状态”确认本地服务与所需插件就绪。
2. 从“数据浏览 → 数据目录”搜索数据名称，先查看已有结果。
3. 需要更新时进入对应采集任务，确认启用和计划后保存，再执行采集。
4. 等本轮归档完成后刷新数据页；在“数据准备”核对声明范围和用途。

## 目录与搜索

左侧按目的组织说明。数据说明再按证券基础、交易与行情、公司事件、财务报表、行业与指数、资讯分组；先选一份数据，再读同一套“如何查看、范围与更新、字段与日期、限制与排错”。

数据库参考独立按 MySQL、Redis 分组，逐项查结构与归属；技术参考负责流程和协议。两个参考目录默认收起，维护人员可展开查找。搜索覆盖所有文章，可输入多个空格分隔的关键词；标题和摘要匹配优先。上方显示当前路径与文章摘要，“本页章节”定位小节，“返回 / 前进”保留阅读位置。相关链接只跳转说明，不会执行采集、保存设置或启动迁移。

## 快捷键与时间

F1 打开说明，Ctrl+F 搜索；Alt+1 工作台、Alt+2 股票列表、Alt+3 采集任务。显示时间为北京时间。页面、表格和说明正文可以使用鼠标滚轮或拖动滚动条翻阅；滚轮不修改数字、日期、下拉框或滑块值。
