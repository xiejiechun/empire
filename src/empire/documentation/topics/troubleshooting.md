# 任务失败与数据未更新

## HTTP 200 但正文不完整

HTTP 200 只表示服务器返回了状态，不能证明正文完整。压缩响应未结束或实际传输短于声明长度时，程序保留已读字节数和脱敏前缀，将完整原文长度及摘要标为未知，并按已保存的单次请求重试次数执行有界重试；例如重试2次，最多请求3次。每次重试仍遵守代理选择、网站频控和本轮总时限，不把不完整正文入队。

正文大小超限、无效压缩格式、额外压缩成员等仍直接失败，不靠重复请求绕过限制。重试耗尽后保留断点，后续继续采集或已启用的运行计划从未完成位置恢复。重试成功不自动清除早先错误记录；程序缺陷经验证修复后，只清理对应的确切错误ID。

新轮次成功启动后，“运行详情”的当前失败原因清空，旧轮次的错误仍在运行历史和错误记录中保留。若启动状态无法保存，原失败状态保留，不伪装为已经开始。

## 数据查询不符合预期

**采集成功但页面没变？** 页面读取已归档的 MySQL 数据；检查归档状态。不完整股票列表不会发布；内容相同时不会更新业务表时间。

**新闻首次只有 50 条？** 首次及“重新采集”仅获取最新第一页；后续增量接上上次归档上界就停止，不承诺全历史补齐。

**日历显示未采集？** 缺失日期不等于休市。执行日历采集并等待整月校验、归档；未来安排可能被来源修订。

## 暂停、退出与错误记录

**暂停和退出有什么区别？** 暂停任务会持久保存禁用状态，重新打开仍暂停；正常退出仅结束当前运行，保留已保存的启用与计划设置。

**错误记录怎么处理？** 先修复并验证，再按确切 ID 清除已解决记录。记录仅查看或后续采集成功不会自动删除。

## 按项目取得只读诊断

维护时可运行 `Empire.exe doctor --project sina-news --output diagnosis.json`，将任务 ID 换成需要检查的项目。源码运行使用 `python -m empire doctor` 的相同参数；配置默认仍来自程序目录，`--config` 是显式覆盖入口。无 `--project` 时只检查 Redis/MySQL 连接。

报告汇总项目声明、已保存的任务状态与计划、断点、归档确认、有限队列样本、错误摘要和正式查询预览；每项有读取时间和状态。需要查看一条错误正文时加 `--error-id <确切ID>`。它不启动采集或归档，不清错误、不刷新摘要，不改变任务设置，可在桌面运行期间使用。

默认 SQL 最多 10 次、Redis 最多 20 次操作预算，单次 I/O 最多 5 秒、总预算 30 秒；错误摘要最多 50 条，单条错误正文最多 64 KiB，输出报告最多 1 MiB。超时、限额、服务不可用或未覆盖全部记录会明确标为未完成/截断；队列样本中的项目数量是已见下界，不能据此推断全项目没有积压。单侧服务失败时仍保留另一侧取得的证据。

SQL 预算包含每个物理连接的五次只读初始化探测预留，连接协议、SET 会话初始化及事务清理另计；Redis 按脚本内读取命令最大次数预留。需要证券筛选时使用 `--security 000001.SZ`，日期范围用 `--date YYYY-MM-DD`；日期默认为北京时间当天。预览最多 20 条，日历按整月查询；不支持相应有界查询时明确提示。输出文件必须是新路径，避免覆盖已有报告。

命令行无法直接读取另一桌面进程内的即时隔离状态时显示未知，历史错误不能证明当前已解除或仍在隔离。正式查询预览只证明所列查询与范围，不能代替全范围数据准备或实采完整性验收。检查完成后无需保存或重启，报告文件供排错使用；修复和精确清理仍按原流程执行。

退出码 0 表示所请求证据齐全，2 表示存在部分或未知项，1 表示参数、配置等错误。独立 CLI 通常因无法读取进程内隔离而返回 2，应阅读逐项状态，不能把它直接当成数据库故障。

## 插件失败或运行异常

**插件显示运行失败或运行异常？** 到“系统设置 → 运行状态 / 插件管理”查看原因。关键归档、调度、代理目录或 Redis 监测循环意外退出时显示运行失败；服务暂时故障或依赖异常显示运行异常。先处理原因，再正常停用后启用，或正常退出并重开。仍有资源的失败插件不能直接重复启动，程序不自动重启故障循环或重放写入。正常一次采集完成和正常关闭不会因此报错。插件后台摘要仅保留本次进程中最近 100 条，每条最多 2048 字节，不代替项目的 Redis 错误记录。

切换页面时，隐藏页面的展示定时器和只读查询会停止；重新进入再刷新。只读页面实例采用有界缓存，被回收后会恢复搜索、筛选、分页、稳定身份选择和滚动位置。采集任务、站点规则、运行记录与下载资源等编辑/写入页面保持常驻，切页不会取消保存、精确清理等写命令，也不会清除未保存草稿。

## 网站限流与网络失败

**网站限流要等多久？** 429 冷却由所有代理和直连共享，合法长时间不截短；非法等待值回退 30 秒。极端超长整数会保守阻断并提示，不能靠换出口绕过。取消或请求超时只结束当前等待，不删除冷却。跨站跳转不会带出认证和 Cookie，HTTPS 跳到 HTTP 会拒绝。
