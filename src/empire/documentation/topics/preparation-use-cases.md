# 回测与估值准备范围

## 按用途准备

进入一级“数据准备”，用数据分类和搜索选择本次研究需要的输入；工作类型切换采集、计算、核对。清单不会要求每个策略都用完全部数据。待开发和来源未核实的项目保持未完成，不能把规划当成已有接口。

| 用途 | 保留内容 |
| --- | --- |
| 历史股票池与身份 | 当前股票、上市、暂停恢复终止上市、公司及股票更名；当前列表不代替历史股票池 |
| 交易与收益 | 交易日历、停复牌、实施/撤销ST、日行情、复权因子与复权行情、含分红收益、缺日核对 |
| 持仓与估值输入 | 分红送转、增发、配股、拆合股、换股；总/流通股本快照与来源市值由日摘要提供 |
| 基本面与估值 | 三张财报、业绩预告/快报、三表核对、市值、PE/PB/PS、股息率 |
| 分组与基准 | 当前行业、当前指数及成分、指数基本资料/行情/全收益、历史成员和权重 |
| 股东因子 | 十大股东/流通股东、户数、解禁、增减持计划与结果、质押及冻结 |
| 资金与交易因子 | 融资融券个股/市场汇总及标的、沪深港通公开数据、大宗交易、龙虎榜、开盘啦策略行情及大单净额 |
| 成交规则及费用 | 每日限制价、涨跌幅、T+1、买卖数量、价格精度、交易时段、印花税、过户费 |
| 收益比较与折现 | 无风险利率曲线；它仍是准备项，折现估值模型需另行实现 |

## 移出范围与生效

退市整理期按用户要求移出。每日涨停价和跌停价使用日行情已有字段，不单独列为准备项目或采集任务；可在“历史盘口与日行情摘要”中查看来源价格。新闻正文及历史/版本/股票识别、公告列表/文件/文字解析、GDP/CPI/PPI/PMI/货币供应量/社融、汇率、ETF 四项、交易所逐笔成交和逐笔委托撤单均不再列入本次准备。

清单随程序版本更新，重启后生效，不需要保存为任务配置。已有新闻采集、分页浏览、归档和业务记录继续保留。检查缓存包含目录契约，旧清单缓存不能复用，首次打开会按新清单检查；旧缓存自然过期，无需清空 Redis。

## 用途限制

股东、财报及资金数据作为选股信号时按公开/可用日期使用。当前行业和指数成员只能用于当前分组，不能回填历史。开盘啦分笔与分钟数据是策略原料，不表示已经生成日频因子或具备交易所完整事件流。退市整理期移出后，不承诺模拟该阶段特殊交易安排，不能从退市日期倒推补造。
