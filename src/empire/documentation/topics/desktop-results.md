# 查看结果

## 先看运行结果

选择任务，打开“运行与记录”。百分比表示采集单元的进度；达到 100% 后可能还在等待数据归档，应以本轮最终状态为准。没有明确总量时显示“采集中”，不估算百分比。

历史轮次可通过选择器切换，查看后可以返回当前轮次。采集和错误按所选轮次展示；无法关联的旧记录独立显示。归档记录展示该任务保留的跨轮次处理记录，不一定只属于当前轮次。

## 再看数据预览

打开同一任务的“数据预览”，页面会按该项目的数据内容提供专门的阅读方式。多个栏目直接点标签切换；在同一任务预览内切换栏目会保留各栏目的筛选草稿、排序和页码，关闭页面后不作永久保存。填写条件后点“查询数据”，输入框里的新条件在查询前不改变已有结果。点“展开预览”可以获得更大的阅读空间。

- 财务报表：查看报告目录后，进入单只证券的科目对照。报告期横向排列，科目纵向完整展示；空值与该期未提供的科目分开说明。
- 日行情与股本：查看当前查询页的走势和明细，价格、成交量及成交额分别标注单位。走势只描述当前已加载数据。
- 交易日历：按月查看交易、休市和未知日期。没有取得的日期不会按周末推断为休市。
- 股东与龙虎榜：从报告或上榜记录进入详情，查看当期及退出持有人，或上榜原因、买入及卖出席位。
- 行业、指数和题材：从目录进入对应成员或题材详情，阅读简介、关联证券及理由。
- 财经快讯：选择标题阅读完整正文。公司事件、融资、解禁、回购和交易规则按本项目的日期、状态、单位与说明组织。

预览沿用客户端的紧凑工具栏、蓝灰配色和表格布局。右上角“阅读说明”展开当前栏目的数据口径与限制；“展开预览”提供更大的阅读空间，按 Esc 可收起。

宽表可以横向滚动，首列和表头帮助定位；数值右对齐并保留来源精度。用“显示列”选择需要对照的字段，用“紧凑 / 舒适”调整行距；同一栏目翻页、排序和返回时保留这些选择。事件默认显示对照表，“展开记录”打开完整字段，需要进一步读取的业务明细另有“查看明细”入口。

## 排序和比较

点击表头可依次切换升序、降序和默认顺序，也可使用筛选区下方的“排序字段 / 排序方向”。分页列表先对全部符合筛选条件的数据排序，再取当前页；切换排序会回到第一页。数值按数值比较，缺值和空文本在两种方向中都放在最后，同值按稳定业务身份排列。较大范围的正文或计算列排序可能需要等待；超过查询资源限制时会提示缩小日期或证券范围，不会改成本页排序。

持有人、席位等已完整加载的明细在完整集合内排序和查找，不会重新读取或改变上级列表。财报先显示报告目录；打开证券历史后，可点科目或任一报告期表头按名称或该期金额排列全部科目，再点回默认顺序恢复科目层级。财报缺值与未提供科目仍保留区别。

停复牌的“来源出现日”按当前筛选范围内最早的实际出现日期排序，不代表停牌或复牌生效日期。回购的未知进度保留来源代码，不擅自解释为完成、取消等状态。

归档数据翻页期间仍可能新增或修订，连续翻页不是历史冻结快照。盘中数据翻页绑定同一个保留快照；快照过期或丢失时会提示返回第一页，不会混入另一时刻的数据。

证券代码须包含市场后缀，例如 000001.SZ；小写后缀在查询时自动转为大写。行业融资融券按完整行业名称查询。

详情中的“返回”恢复原查询条件、排序和页码。“第一页”“上一页”“下一页”用于翻页；本页条数不是全市场总量。查询不会自动触发采集或补历史，读取失败时显示错误，不将上一组结果冒充新条件的数据。

空结果可能是尚未采集、条件不匹配或来源不支持该范围，不能直接理解为当天没有数据。日期和单位以栏目说明为准，缺失值不代表零。

盘中快照与已归档数据分开标识；股票项目展示的是共享的当前股票列表，不是某一次采集的历史快照。财报用于历史选股时仍需核对公告或可用日期，停复牌的来源日历日与事件生效时间分别阅读。

## 了解数据范围

该任务的“采集说明”列出证券与市场、开始和结束范围、首次采集、后续更新、恢复规则及用途限制。支持某个历史范围不代表当前已经采完。

记录只保留最近一部分；电脑或临时服务重启后，运行记录可能消失，已经归档的数据仍可查询。

[没有数据或采集失败怎么办](help:常见问题)

## 月份筛选

行业解禁按月份查询，开始和结束月份均包含在范围内；选择年月后即可查询，无需手动补写日期。
