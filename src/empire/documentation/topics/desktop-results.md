# 查看结果

## 每日复盘

从顶栏“市场观察”进入左侧“每日复盘”。全景导图按整体行情、资金流向、连板梯队、晋级断板、核心判断、次日观察六条主线组织，用于收盘后复盘和下一交易日前准备。点击分支标题收起或展开，点击“全部展开”恢复；指数外围、首板分类和断板明细可分别展开，点击连板证券查看收盘快照。

“复盘日期”首次进入或重启后默认北京时间今天，可选择或输入年月日；切页保留会话日期，点击“今天”回到当天。整体行情已读取真实归档，“刷新行情”只重读已有数据，不触发采集。休市、未来及当日15:30前不展示日终事实；缺失项统一显示“缺少数据来源”，准备交易日按正式日历显示。

成交额为归档沪深京个股合计，显示当日与前日样本数；资金和涨跌家数来自东方财富资金榜样本，资金采用含暗盘模型测算。涨跌停及连续板沿用远航池和正式日历；指数涨幅只与正式前一交易日同代码收盘比较。展开“指数点位与数据口径”查看范围。刷新失败保留同日旧结果和查询时间；切日期清除旧日值，迟到回执不覆盖新日期。

资金流向读取完整个股日榜，显示明盘、暗盘合计和个股资金方向前5。板块主力流入、流出按同花顺当前行业成分股汇总所选日的含暗盘主力净流入，正值降序、负值升序各取前5，同金额按行业编号排序。固定标注“自行汇总 · 按当前成分股回看”和“按已覆盖成分股合计排名”；每行显示覆盖x/y只，部分覆盖只合计已有记录，缺失证券不填0，无覆盖行业不入榜。已覆盖合计为0不进入任一方向，方向无结果显示已知空榜。历史结果不代表当时行业归属，当前成分更新后可改变。ETF净申赎仍显示“缺少数据来源”。展开“个股资金排行与口径”查看成分核验时间和覆盖说明。

其他四个分支仅2026-07-31有独立标注的虚拟样例，准备2026-08-03，其他日期显示待接入。“查看虚拟样例”可返回，整体行情仍读取该日真实归档；虚拟首板分类和证券梯队不与真实统计相互推导。其他日期笔记不可编辑，样例草稿保留。

“列入预案”勾选后立即保存到本机；“复盘笔记”需点击“保存到本机”，成功后可跨启动保留。未保存笔记在本次客户端会话切页或关闭编辑窗后保留，重启会丢失。保存失败会提示并保留当前编辑。笔记与预案只在当前机器，清除客户端本机数据会丢失；页面不触发采集或写入业务数据库。

## 多指标观察日历

观察日历顶部“专注月历”同栏提供Redis自动刷新，默认开启、30秒，可调整1～3600秒或关闭；本页面会话有效。“刷新Redis”只更新今日适用盘中值，保留历史月份、滚动、详情与草稿，不重读归档SQL或触发采集；失败保留上次报价并提示。无今日适用指标时不轮询。新归档基准与跨日通过“刷新数据”重新加载。

月历右上工具行的“来源与口径”打开带六个标签的详情窗口：指数行情、市场成交、融资融券、汇率行情、交易日历、当月覆盖。每类列出采集平台、任务名称/ID、实际MySQL业务表和字段映射，区分直接读取与系统计算；当月覆盖集中显示样本数量和缺值限制。窗口可滚动，通过关闭按钮或Esc退出，默认不占月历空间。指数、市场成交、两融、汇率、日历分别读取yuanhang_index_daily_price、yuanhang_daily_price、market_margin_daily、fx_daily_price、trade_calendar。归档数据之外，今天缺少日线的汇率补充已有Redis报价，来源标签同时列出实时任务和Redis键；刷新页面不触发采集。

顶栏“市场观察”下，左侧首项是“多指标观察日历”。侧栏支持收起和展开，与采集管理保持一致。选择指数、月份和两融市场后，点击“管理指标”展开指标库，添加行情、成交、资金或汇率指标，按上下箭头调整顺序；收起后保留已选指标标签，为月历留出空间。指标颜色保持一致，点击标签可突出整月同一指标，再次点击取消。点击日期可查看该日精确原值及口径，并在详情内逐日前后切换；周标题随月历滚动固定。“专注月历”收起设置区域扩大阅读空间，“定位今天”切回本月并滚动到当天。月历按正式交易日历区分交易日、休市和未确认；“—”表示没有可用值，不能当作零。融资数据属于所选市场，不是指数成分股统计。

可切换三种密度，设置各指标大于等于阈值时高亮。点击“保存视图”在本机保留指数、市场、指标顺序及显示设置；未保存编辑离页丢失，月份默认本月。导出数据为当前自然月所选指标CSV，保留缺值与原始精度。刷新只读已有数据，缺失需到对应采集任务核查；本版不含北向资金或自定义公式。

多指标观察日历在“管理指标 → 已选指标”每行提供“设置”，直接配置该项，弹窗只列已选指标；确认应用，取消丢弃，保存视图后跨启动保留。融资买入/偿还比由买入额÷（买入额−净买入额）×100%计算，分母非正或缺值时不计算。指标库“汇率”可同时添加十二品种的归档收盘，A股休市仍按来源日期展示；支持前条已归档日线变化、最近N条均值及阈值。缺行不推断休市或补值，详情与CSV保留精确报价和单位。

默认加载北京时间本月完整月历；向上滚动到顶部或点击“向上加载更早月份”，逐月在上方追加完整历史月并保持阅读位置。加载中或历史读取失败不移除已读月份，可重试；切换读取条件或刷新后从选定月重新加载，CSV仍只导出选定自然月。完整月历不表示业务数据已采齐。

沪深京成交额汇总已归档沪深京个股的当日成交额，与所选指数成交额独立，不代表官方全市场总额。Top成交额占比按滚动窗口内个股累计成交额排名；两者的样本数量与覆盖限制在“来源与口径”中按需查看，不常驻占用月历空间。详细公式与缺值处理见[多指标观察日历](help:多指标观察日历)。

今天缺归档日线的汇率会额外显示已有Redis盘中报价，名称用“盘中”，顶部集中标识“Redis”；采样超过180秒提示过期。悬停、详情和CSV保留来源时间、来源更新时间、采样时间及盘中原价；三个时间均核对北京时间今天。盘中环比及N期均值会标明估算，基准不足时留空；历史仅用归档日线，已有同日日线不覆盖。Redis读取失败或插件停用保留归档月历，在“来源与口径 → 当月覆盖”说明。其他指标暂无匹配盘中快照，缺值不补零。

## 先看运行结果

选择任务，打开“运行与记录”。百分比表示采集单元的进度；达到 100% 后可能还在等待数据归档，应以本轮最终状态为准。没有明确总量时显示“采集中”，不估算百分比。

历史轮次可通过选择器切换，查看后可以返回当前轮次。采集和错误按所选轮次展示；无法关联的旧记录独立显示。归档记录展示该任务保留的跨轮次处理记录，不一定只属于当前轮次。

## 再看数据预览

打开同一任务的“数据预览”，页面会按该项目的数据内容提供专门的阅读方式。多个栏目直接点标签切换；在同一任务预览内切换栏目会保留各栏目的筛选草稿、排序和页码，关闭页面后不作永久保存。填写条件后点“查询数据”，输入框里的新条件在查询前不改变已有结果。点“展开预览”可以获得更大的阅读空间。

- 财务报表：查看报告目录后，进入单只证券的科目对照。报告期横向排列，科目纵向完整展示；空值与该期未提供的科目分开说明。
- 日行情与股本：查看当前查询页的走势和明细，价格、成交量及成交额分别标注单位。走势只描述当前已加载数据。
- 明盘暗盘资金榜：默认查看今天的盘中资金榜，按暗盘资金降序排列，并显示采样区间与完整快照证券数。“查看今天”切回今天，“刷新最新”按已查询条件回到第一页读取新快照，保留未提交草稿。收盘后的历史记录切到“已归档日榜”；资金缩写为万/亿时可悬停查看精确元值，涨跌幅和活跃度显示百分比。
- 交易日历：按月查看交易、休市和未知日期。没有取得的日期不会按周末推断为休市。
- 股东与龙虎榜：从报告或上榜记录进入详情，查看当期及退出持有人，或上榜原因、买入及卖出席位。
- 行业、指数和题材：从目录进入对应成员或题材详情，阅读简介、关联证券及理由。
- 财经快讯：选择标题阅读完整正文。公司事件、融资、解禁、回购和交易规则按本项目的日期、状态、单位与说明组织。

预览沿用客户端的紧凑工具栏、蓝灰配色和表格布局。右上角“阅读说明”展开当前栏目的数据口径与限制；“展开预览”提供更大的阅读空间，按 Esc 可收起。

宽表可以横向滚动，首列和表头帮助定位；数值右对齐并保留来源精度。用“显示列”选择需要对照的字段，用“紧凑 / 舒适”调整行距；同一栏目翻页、排序和返回时保留这些选择。事件默认显示对照表，“展开记录”打开完整字段，需要进一步读取的业务明细另有“查看明细”入口。

## 排序和比较

点击表头可依次切换升序、降序和默认顺序，也可使用筛选区下方的“排序字段 / 排序方向”。分页列表先对全部符合筛选条件的数据排序，再取当前页；切换排序会回到第一页。数值按数值比较，缺值和空文本在两种方向中都放在最后，同值按稳定业务身份排列。较大范围的正文或计算列排序可能需要等待；超过查询资源限制时会提示缩小日期或证券范围，不会改成本页排序。

持有人、席位等已完整加载的明细在完整集合内排序和查找，不会重新读取或改变上级列表。财报先显示报告目录；打开证券历史后，可点科目或任一报告期表头按名称或该期金额排列全部科目，再点回默认顺序恢复科目层级。财报缺值与未提供科目仍保留区别。

停复牌的“来源出现日”按当前筛选范围内最早的实际出现日期排序，不代表停牌或复牌生效日期。回购的未知进度保留来源代码，不擅自解释为完成、取消等状态。

归档数据翻页期间仍可能新增或修订，连续翻页不是历史冻结快照。盘中数据翻页绑定同一个保留快照；快照过期或丢失时会提示返回第一页，不会混入另一时刻的数据。

证券代码须包含市场后缀，例如 000001.SZ；小写后缀在查询时自动转为大写。行业融资融券按完整行业名称查询。

详情中的“返回”恢复原查询条件、排序和页码。“第一页”“上一页”“下一页”用于翻页；本页条数不是全市场总量。查询不会自动触发采集或补历史，读取失败时显示错误，不将上一组结果冒充新条件的数据。

空结果可能是尚未采集、条件不匹配或来源不支持该范围，不能直接理解为当天没有数据。日期和单位以栏目说明为准，缺失值不代表零。

盘中快照与已归档数据分开标识；股票项目展示的是共享的当前股票列表，不是某一次采集的历史快照。财报用于历史选股时仍需核对公告或可用日期，停复牌的来源日历日与事件生效时间分别阅读。

## 怎样确认目前已经有哪些数据

先按上述清单找到任务，再进入数据预览查询。对证券类输入完整代码，对日期类设置范围，目录类先看目录再进成员或明细。列表与明细分别计数，例如一份股东报告可以有多名持有人，一条龙虎榜记录可以有多个原因和多个席位；不要把它们合计为“事件数”。

核对实际存量时应同时记录：核查时间、来源、栏目、证券或市场范围、记录数量、采用的日期含义、最早和最新日期、缺口与质量限制。当前股票数不等于历史证券总数；事件涉及证券较少也不自动说明漏采，因为并非每只股票都会发生该事件。

最早至最新只是已存在记录的两端，不证明中间没有缺日，也不证明其他证券同样覆盖。未来解禁、预约披露、分红安排和上市计划可以合法晚于核查日；它们不是已经发生的业绩或交易事实。明显异常日期应保留问题提示，不能拿来宣传历史覆盖。

本页清单说明已经接入哪些内容；它不是自动刷新的库存报表。当前实际数量以预览查询为准，带日期的人工盘点只反映当时状态。运行达到 100% 还需确认本轮归档结束；历史数量很多也不能代替本轮成功。来源没有数据、尚未采集、临时快照已过期、质量限制和查询失败须分别判断。
