# 快速开始

## 日常使用只需三步

1. 在“采集管理”中按平台选择任务，也可以搜索任务名称。
2. 点击“立即采集”。需要自动执行时，打开“执行计划”设置并保存。
3. 在“运行与记录”确认结果，再到同一任务的“数据预览”查看数据。

首次采集可能需要较长时间。具体采集哪些证券、从哪天开始，以及来源有哪些限制，查看该任务的“采集说明”。

## 按需要阅读

- [采集与计划](help:采集与计划)：立即采集、自动执行、暂停和归档任务。
- [查看结果](help:查看结果)：看懂进度、历史记录和数据预览。
- [连接与资源](help:连接与资源)：代理、身份和资源设置何时需要调整。
- [常见问题](help:常见问题)：失败、没有数据、等待归档和退出。

## 界面与退出

右上角可切换明暗主题，设置菜单可调整显示密度。Ctrl+K 搜索功能，Ctrl+B 收起或展开侧栏。

关闭窗口或选择设置菜单中的“正常退出”，等待后台收尾。重新打开后会按已保存的计划运行。
