# 任务归档与还原

## 何时使用归档

不再日常使用的任务可从采集任务页归档。归档停止计划并取消当前采集，保留配置、断点和已归档业务；正确待归档消息仍由统一归档器处理。它不是删除数据。

## 归档与还原步骤

在采集任务选中项目，使用任务菜单中的归档操作。默认任务列表隐藏已归档项目；到“采集管理 → 归档任务”选中后还原。

还原沿用原计划和启停状态，原先暂停的任务仍要启用并保存。归档状态保存在 MySQL，Redis 或电脑重启不会丢失；当前股票列表仍只有一份，不因还原新浪任务增加第二份股票表。
