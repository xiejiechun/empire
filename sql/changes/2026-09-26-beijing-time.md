# MySQL 业务时间改为北京时间

Empire 的 `DATETIME(6)` 不携带时区。旧版本写入 UTC，无论直接查询还是数据库工具查看都会比北京时间慢 8 小时；界面曾在读取后补 8 小时。

本维护将 stock、finance_news、trade_calendar、app_setting 的现有时间列整体增加 8 小时，并写入 `app_setting` 维护标记。以后 MySQL 连接固定为 `+08:00`，业务写入在数据库边界转换为北京时间；Redis 消息仍保留带时区的绝对时间。

本维护已经执行完成，旧脚本已退役，不应再次对现行数据加 8 小时。历史操作在 Empire 正常退出、待归档队列为 0 后取得单实例锁，在一个事务中更新并记录幂等标记；未清空 Redis 或删除业务数据。当前升级入口见 [正式路径维护](2026-09-26-formal-paths.md)，应用启动不执行迁移。
