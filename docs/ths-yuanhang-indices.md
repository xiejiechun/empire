# 同花顺远航版指数组件设计与实施

2026-11-16：三个组件已实现并切换生产，旧插件归档、旧四表删除；671项定向发布测试及29个完整指数的开发实采通过。生产目录与当前成分已完成首轮，日K仍在初始化，不能视为580项全历史已齐。正式桌面、重启续采及实际范围见[交付记录](evidence/yuanhang-indices-delivery-20261116.md)。

## 来源、业务粒度与字段

三个独立项目为ths-yuanhang-indices（目录）、ths-yuanhang-index-members（当前成分）、ths-yuanhang-index-prices（日K）。目录和日K固定来源ths_yuanhang；成分固定来源ths，使用原同花顺网页接口，成分任务名称为“同花顺 指数成分”、归“同花顺”平台分组；目录和日K归“同花顺远航版”。每项目一行collection_state，不存逐轮业务日志。

目录从远航240的USHI、USZI、USTI市场文件展开所有CodeList段，按客户端D2集合保留沪深指数及北证50；200按市场批量取字段5身份和55名称，名称按UTF8。当前580为观测数量，非固定数量条件。保留基金、债券、B股；不根据代码猜原生市场。原生身份为native_market+index_code；指数不伪造股票unified_code。

成分使用 `https://q.10jqka.com.cn/zs/detail/code/{index_code}/field/code/order/asc/page/1/size/10000/ajax/1/`。仅完整单页、请求身份、闭合表格、严格排序和低于上限的唯一集合可成功；明确暂无正常完成且当前名单为空。有名单→暂无清除旧当前关系，与状态同事务；失败保留上次归档内容，不伪装暂无。同名代码不互相复制。网页名单的来源质量不等于官方编制准确性，不提供历史调样和权重。

日K使用210，原始指数代码和USHI/USZI/USTI身份，字段1/7/8/9/11/13/19为日期/开/高/低/收/量/额。数值采用DECIMAL(28,10)的无损十进制字符串规范，允许来源NULL及负值，OHLC关系和负量额作为质量限制保留。无效日期、身份、重复冲突、截断和溢出报错，不填零或插值。量额保留原生协议原单位，未确认与股票股数/人民币元统一，查询不换算，不套用旧HTTP换算。

正式表：yuanhang_index（代码主键、名称、原生市场、当前有效性）、ths_index_member_state（指数主键、可用性及集合摘要）、ths_index_member（指数+来源成员身份主键、名称和可靠unified_code）、yuanhang_index_daily_price（指数+日期主键、六项可空数值）、yuanhang_index_price_year（指数+年份主键、实际日期/内容摘要、覆盖及版本）。具体SQL字段字典以本次DDL及对应数据库参考为准。固定来源通过业务登记声明，不重复source列。

## 正式查询、索引与预算

目录和成员后台分页每页200、最多500；成员按指数查和按unified_code/来源编号反查，分别使用主键及两条反查索引。日K按指数日期范围/图表、按日期跨指数浏览，使用指数日期主键及日期优先索引。年度证明每指数最多150年，每年不超过366个真实日期；不根据交易日历强造日K。

目录上限1000，成员单指数少于10000、全池不超过100万；当前关系长期不按日累积。日K按1000指数×150年×366行约5490万行的硬边界，当前580×36×250约522万行仅容量估算，不是已采数量。预算含索引8GiB日K、512MiB当前关系及证明；按实测行宽和索引分配更新估算，不提高边界掩盖失败。目录/成员页P95目标50ms，单指数年度P95目标100ms，10万成员初始写入目标20秒；隔离容量测试给出冷热条件、EXPLAIN和实际测量，未测不得登记measured。

## 生命周期、版本和恢复

目录每日18:00完整小集合；成分同时间基于可信已归档目录逐指数完整核验；日K同时间最近十个正式交易日优先，随后独立批次补最多64个指数的历史缺口。已保存配置优先。首次缺目录不启动下游；成员和日K互不等待。完整日K首次来源起点由完整响应确认，不把SQL最小/最大日期当完整证明；新年份初始化必要前缀。无身份空帧不算全历史完成。

业务校验后与已入队断点原子发布，继续后续下载；整轮末尾确认全部消息成功清队。统一摘要、旧版防覆盖、零业务DML和提交后重放沿公共归档；区间按日期版本合并，不能用旧整年覆盖新日期或把局部窗口替换成整年。可信命中免SQL；故障不推进断点。目录退出保留日K历史，当前查询仅显示有效目录；重入目录重新核验成员状态。

Redis存活按已入队断点续跑；丢失则从SQL可信覆盖恢复日K范围，目录/成分允许重新读取当前小快照，不全池重下日K。窗口外修订仅明确异常或显式重新核验，不安排全历史日常轮转。历史未补齐显示实际范围，源端暂无成分正常成功但标来源限制。

## 网络与成本

复用远航既有身份、节点绑定、登录会话、共享HTTP/TCP、站点频控、有界预取及实际字节预算。240文本和200名称采用专项解码，原有股票历史校验保持严格。目录基础6个逻辑请求，网页成分基础N个请求（全量例外），近期日K至多N个区间请求及历史有界单元；必要认证、辅助及重试另计。分别验证无变化、新日、补缺、Redis丢失的请求/传输/入队/写库成本；来源调查代理优先可回退，正式开发实采按proxy-only入口，不改用户已保存策略。
