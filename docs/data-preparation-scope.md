# 数据准备用途筛选研究（2026-10-11）

范围：A 股日频回测、股票估值，并保留用户指定的股东、资金流、融资融券等策略扩展因子。

清单数量以现行页面和唯一目录为准；2026-10-12 补充移出每日涨停价和跌停价、独立总/流通股本及自由流通股本规划。总/流通股本复用已接入日摘要；已有实际流通市值不等于直接公布的自由流通股数。此清单是用途筛选，不表示来源已核实、功能已开发或数据已采齐。

现有开盘啦七项保留作为价格、量价及资金流策略原料；分笔不是交易所逐笔协议，分钟数据须按策略截止时点汇总，不冒充已实现日频因子。无风险利率用于收益比较及折现，保留。公司及股票更名用于历史身份核对；当前行业与指数成员仅用于当前筛选，不回填历史。

移出仅针对数据准备目录；现有新闻采集、查询、SQL 与 Redis 业务数据不删除。未开发来源没有核实前仍是待开发。
