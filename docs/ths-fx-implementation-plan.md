# 远航版汇率实时行情与历史日线实施记录

2026-11-09，用户已授权实施。范围为页面十二品种：USDIND、USDCNY、USDCNH、XAUUSD、EURUSD、GBPUSD、USDCAD、USDCHF、USDHKD、AUDUSD、USDJPY、USDSGD。来源已核实，当前代码已接入，开发验证进行中，以下目标不代表已经实现或验收。

## 用户确认的行为

- 两个独立任务归入“同花顺远航版”分组：实时任务每轮结束等待60秒，仅覆盖Redis各品种最新值；日线任务默认每日北京时间09:00集中维护MySQL，最终时间以实际来源边界校正。
- 不保留分钟历史、变化快照或回放索引；日线直接使用来源日K线，不从60秒采样合成。
- 实时采集不查询SQL日线进度、不发布归档消息；配置加载及既有公共基础服务访问不冒充采集业务零SQL。
- 日线任务批量读取可信覆盖，合并新增、缺口与最近30自然日修订范围。结束后不轮询SQL；失败使用有限重试，剩余下轮补齐。
- 初始化有界补历史，不扩大为全市场；实时任务独立。来源交易日不套A股日历，不推算周末或缺失日；未结束日线不得归档。

## 来源准入与实施顺序

先核实真实市场和品种身份、来源时间、收盘边界、最早历史、字段精度、完整性、区间/批量/分页能力，再冻结业务表设计卡与SQL。现有远航历史身份校验只接受沪深北股票，不能绕过校验把外汇伪装为股票；内置配置与实际页面清单有差异。资讯页面whhl_list不是行情接口。

复用共享下载、代理、频控、认证与有界预取。来源核实代理优先且可回退；正式有界实采验收仅代理。禁止临时直连客户端替代正式网络路径。初始化、无变化、新增、恢复分别记录认证、逻辑请求、传输/解码、入队和SQL写入成本。

## 生命周期与恢复

实时首次执行获取全部所选品种，按来源身份及数值校验后原子覆盖；防迟到，失败保留旧值并显示源时间与采集时间。Redis丢失重新请求，不从SQL伪造实时值。过期语义与键容量在来源核实后登记。

日线初始化起点为来源实证边界，终点固定于本轮已结束日线边界；按完整响应/区间校验集合，失败不推进断点。下载与归档解耦，整轮入队后等待所有消息处理清队。SQL业务与collection_state同事务；摘要命中、相同内容及迟到旧消息均由统一归档成功清队。重复零业务DML，修订仅写受影响事实。

仅重启Empire使用存活Redis断点；Redis丢失依据SQL可信覆盖恢复，不能仅用最大日期判断历史完整。最近30日以外来源修订通过显式范围核验，不新增自动全历史扫描。源站未提供可靠最终标志时须记录保守截止依据，不能根据两次价格相同认定已收盘。

## 验证与交付边界

原生当日日线的品种、日期、交易状态校验后，OHLC四字段均明确为空字符串时，以DailyQuoteUnavailable进入现有来源缺口路径，保留该品种数据与最早断点，继续后续品种并确认整轮有效消息归档。缺字段、部分空、非法数值及历史正文缺值仍失败。空报价不追加年度回读或重试，不作为历史核验完成证据，不重复生成格式错误；下一轮按原计划从缺口恢复。适用全部十二品种，存储与请求预算不变。实现及真实验收见[处理记录](evidence/ths-fx-daily-empty-prices-2026-11-12.md)。

专项覆盖实时零SQL/零归档消息、最新值唯一性、失败保留、防迟到、跨日/夏令时/休市/源站延迟、初始化/无变化/新增/修订/缺口/恢复、重复零业务DML及SQL提交后重放。相关公共安全和独立库集成不缩减。

实采按最小完整业务单元约5%向上取整，固定样本失败不替换；记录种子、总体、范围、请求和内容/集合校验。Redis实时验收与日线正式归档分别报告。新表执行独立维护、完整性和容量验证，启动不迁移。同步任务预览、采集说明、字段/Redis字典及覆盖，执行文档契约、定向发布门禁、真实桌面验证。

## 来源证据与已冻结设计卡

共享代理核实记录 `build/fx-verified-source.json`：十二品种 realhead 与 last 均成功；固定USDCNH 2025年度261条，2025-01-01至12-31；共30次代理请求（含重试），无直连。正式接口：`https://d.10jqka.com.cn/v4/realhead/wh_{symbol}/last.js`；`https://d.10jqka.com.cn/v4/line/wh_{symbol}/01/{last|YYYY}.js`，来源页面 `https://fe.10jqka.com.cn/`。复用同花顺站点频控、共享HttpPlugin，无客户端登录/SQL身份续租。原生股票历史协议不适用于本次已验证路径，不增加第二实现。
