## 已实现来源层

`kaipanla_source.py` 提供匿名请求构造、字段及证券日校验、两个响应的关联核对和接入共享下载器的调用函数。请求不读取旧项目配置或登录会话；每个正常逻辑请求生成随机设备 ID 和 Android 机型，不读取模拟器设备身份。共享下载器内部网络重试当前沿用同一逻辑请求身份；最终接入仍须处理用户“每次请求”的重试身份要求，并保留原有重试预算、出口频控及 429 全站冷却。

普通分时验证精确分钟键集合：09:30～11:30 和 13:01～15:00。相同条数的重复 A、遗漏 B 仍拒绝。竞价按来源数组顺序保留每一点；同一分钟多点、完全相同的并列点以及量下降均保留，不能以分钟去重、相减或负数归零。来源价、均价、标记、量以原字段数值保存于解析结果，量单位与标记业务含义仍待核实，不宣称已形成回测可用成交量。

竞价接口样本只有分钟标签，没有秒时间、稳定点 ID 或总点数。无法确认上游是否遗漏某个竞价点；保存完整返回数组不等于逐笔成交或完整竞价委托档位。收盘竞价时段包含在普通分时末段，不把它称为另行取得的收盘竞价明细。

## 错误与覆盖边界

000001 / 2021-01-01 返回 errcode=1020，920002 / 2021-01-04 返回 errcode=1017。错误码不能证明休市、未上市或停牌，也不能推进覆盖。空数组、错证券、错日期、非有限价格、负量、结构变化和分时缺分钟均拒绝；没有合法空日证明。

新股上市前、北交所改代码前、退市后和停牌日期需要正式证券生命周期与代码映射证据。当前股票名单无法证明包含期间退市证券，不能直接宣称全市场 2021 年至今完整。
