# 采集任务页面排版优化

2026-10-02。用户反馈上版两级菜单已建立，但整体布局仍需进一步优化。

## 问题与改动

顶部描述重复、按钮占两行、运行分区纵向堆叠、菜单分页过宽；详情文本的首选高度还会被外层滚动页面使用，导致普通窗口中的菜单、按钮和保存栏一起滚出视野。

本次采用紧凑标题及数量汇总、一行采集操作、约320逻辑像素来源菜单及紧凑分页。任务 ID 放在标题提示中，业务说明放入运行详情；前两个分区按详情实际宽度并排或上下排列，网络及异常随后展示。配置表单宽时标签与输入两列对齐，保存反馈及按钮同处固定底栏。一级来源展示选任务空态，任务叶子才展示详情。默认帮助句改为提示，不重复占用操作栏。

任务页重写高度计算，只让结构的最小高度影响外壳；完整说明、长错误及配置内容仍由标签内滚动区处理。小窗口结构不足以容纳时允许整页滚动，不强行裁掉内容。公共分页仅新增可选紧凑显示，保留完整提示及无障碍名称，其他页面默认行为不变。公共主题新增仅供该页面使用的控件样式。

没有变更采集、调度、归档、数据范围、网络策略或SQL结构；按钮改为“暂停任务”“重新采集”，仍分别暂停并禁用后续计划、建立新批次，原操作含义不变。

## 验证方式

使用实际MainWindow外壳做离屏几何回归：1320×860、1320×700无需手动滚动即可看见菜单分页、采集按钮及配置保存栏；长错误只增加内层滚动范围；1024/880/680宽度不强制扩大窗口或产生横向溢出，小窗口滚到页面底部后保存栏可达。来源空态、配置草稿、刷新与选择继续回归。正式门禁四档缩放增加常规窗口不发生整页滚动的检查。
