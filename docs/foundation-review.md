# 基础优化与逐项验收（2026-09-26）

本轮不新增采集业务。代理节点在线状态由 RouterProxy 管理，Empire 只读取目录和租约；请求失败后的临时冷却仍由 Empire 管理。

| 项目 | 实现 | 验收依据 |
| --- | --- | --- |
| 等待调度开销 | 无出口时共享一秒目录刷新；释放连接唤醒；分配前重新核实 | 50 个同时等待请求在短等待窗口只读取一次目录；取消后 waiting 回零 |
| 每出口频控 | 自动模式取消隐含的全站合计间隔，显式全站保护和固定策略保留 | 容量与许可分离测试；同出口共享许可、50 模拟设备、429 冷却、直连回退回归 |
| 查询生命周期 | 公共 QueryScope 管理只读请求，页面销毁取消；筛选及保存后的旧读取取消 | 查询取消测试与原有草稿、分页、插件启停测试；写入操作不由页面销毁取消 |
| 表格刷新 | 复用单元格，只改变化内容；保留滚动位置，支持业务键选择恢复；列宽可手调，数字右对齐 | 单元格身份、选中行、滚动位置测试 |
| 任务交互 | 运行详情与任务配置分标签；保存与撤销放在滚动区外；主要操作横排，重新采集单独呈现 | 任务草稿回归；两种窗口尺寸下按钮可达性检查 |
| 出口排版 | 代理明细与站点统计添加标题；明细占主要空间，按设备编号保留选择 | 独立代理页面离屏渲染 |
| 站点规则 | 每出口间隔为主要参数；高级配置折叠；理论容量与最近十秒实测分开 | 配置保存回归及页面渲染 |
| 插件边界 | 重新采集说明通过任务声明传给页面，移除页面内采集器 ID 分支 | UI 架构约束、页面按需创建和独立启停回归 |
| 小窗口和缩放 | 外壳提供空间不足时的页面滚动，避免内容挤压重叠；保留页面独立生命周期 | verify_foundation_ui.py 在 100%、125%、150%、200% 下渲染 1320×860、880×560 逻辑尺寸 |
| 文档一致性 | 修正设备间隔、许可键身份、理论容量与全站保护旧表述 | 核对 routing、capacity、proxy_pool 与用户说明 |
| 统一视觉尺寸 | 共享表格行高、采集页面间距与侧栏宽度常量，表格最小列宽避免标题列挤成细条 | 四档缩放离屏渲染与手动查看输出图片 |

## 验收边界

本轮静态检查覆盖 src、tests、scripts。单元及界面套件共 190 项，真实 Redis/MySQL 集成套件共 48 项；布局矩阵为 3 个页面 × 2 种逻辑尺寸 × 4 档缩放，共 24 个渲染场景。代理页面使用 50 行虚拟目录信息核对排版。

最终结果：静态检查、190 项单元/界面测试、48 项集成测试均通过；24 个布局场景成功渲染，任务保存按钮可达性检查通过。新 EXE 构建成功，并通过启动、正常关闭、重新启动检查，最终保留桌面窗口打开。

离屏渲染检查不等于真实显示器切换 DPI、长时间连续运行或几十台实体代理压测。代理数量扩展目前由模拟并发和真实 Redis 集成测试验证。已有归档提交后重放、旧版本防覆盖及插件退出测试继续保留。

复现：运行单元测试、以 EMPIRE_INTEGRATION=1 执行 tests/integration，并分别设置 QT_SCALE_FACTOR=1、1.25、1.5、2 运行 scripts/verify_foundation_ui.py。截图输出在 build/foundation-ui，不包含生产代理地址或认证信息。
