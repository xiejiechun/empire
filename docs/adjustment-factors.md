# 自算复权因子与行情

## 当前正式输入

2026-10-25实现切换为远航版PC原生协议已归档日线与除权事件，算法empire-yuanhang-ex-rights-v3。计算仅查询MySQL，在同一RR事务快照中核对证券、日历、年度日线及金融联合证明，不增加行情副本、因子表、下载或归档任务。

旧通达信分红方案和配股、开盘啦收盘快照不再作为K线复权输入。分红预案与实施信息、名义股息率仍由原业务独立承担，不能把本次K线切换宣称为股息率口径迁移。现有历史业务数据保留。

## 公式和边界

每个生效日，P为前一实际日线收盘价、D为来源每原股现金、S为每原股送股与转增之和、R为配股比例、A为配股价：

参考价E=(P-D+A×R)/(1+S+R)；当日累计因子=前日因子×P/E。

使用50位Decimal和未舍入参考价。来源454已包含转增，规范化扣除460后分别保存送股与转增，计算只加一次。现金沿来源口径，不冒充个人税后收益。首日为归一基准，不应用首日事件；前复权锚定所选最后实际交易日，后复权锚定首日。OHLC乘对应因子，不调整成交量。

规范4支持纯缩股：每原股净股数变化为(-1,0)，其他分量须全0，仍用同一公式，分母必须为正。同日不同完整事件以五分量摘要区分并保存；无法裁定合成口径时复权明确失败，保留原始K线和日期，不累加或任选。普通流通股的源NULL原样保留，价格复权不依赖该余额，换手率或市值用途另查可用性。

查询范围1900年起、最多150年/54900日线，单证券2000事件；不代表证券实际上市于1900年。图表使用全查询结果，明细分页200行。来源完整稀疏序列允许停牌缺日；按年度校验实际日期集合、内容及证明，不能用总条数替代。日历必须完整，非交易日行情报错。除权日不在实际行情序列中时不挪到下一交易日，不推断参考价。

## 使用与恢复

在数据目录打开“自算复权因子与行情”，选择证券和日期后加载。首次草稿为最近一年，支持原始/前复权/后复权、均线、缩放和逐日查看。事件标记回链“远航历史行情”的同日权息输入。修改条件但未加载时保留上次结果标识。

输入缺失先运行两个远航版采集任务，等待统一归档后重新加载；严格复权拒绝缺证明或非法数值，权息不齐时仍可查看已验证原始K线。计算不写SQL，不保存派生断点，Redis/程序重启后按当前归档输入重算。来源修订改变输入摘要，迟到旧响应由原归档路径拒绝。

## 用途与验收

理论价格用于普通走势分析，不用于实际成交、现金账本、税或总收益。未建模合并换股等事件不自动套公式；当前修订版不证明当时可知版本。SQL输入时间可能是最后内容变化/回源确认，未读取可信Redis证据时新鲜度显示未知，不能误报过期或最新。

专项覆盖现金、分别送转、配股、同日组合、多事件、首末边界、完整长历史、缺值、无价事件和重复键。私有MySQL/Redis端到端覆盖归档查询、有效修订、旧响应、SQL提交后重放、联合证明缺失及同数内容改变。实际代理采集验证与全池初始化另行记录，不以计算测试替代。正式发布及真实桌面仍须以同包证据为准。
