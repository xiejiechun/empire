# 自算复权因子与复权行情

## 设计与业务边界

2026-10-09 用户选择自己计算、复用已有数据，不依赖 Tushare Token。参考累计因子输出和常见除权参考价公式，独立实现，不复制来源 SDK。正式输入为已经归档的通达信分红送转、配股和开盘啦收盘后行情；计算只读 MySQL，不另采一份行情、事件或因子，不增加业务表、归档消息和自动采集任务。

一行结果是一只证券一个已有完整交易日的区间累计因子。首个输出日归一为 1，不能与其他起点或 Tushare 的绝对因子直接比较；归一后的因子比才有可比性。首日以前的事件不参与区间因子，但仍核实来源完整单位。前复权以所选截止日为基准，后复权以区间首日为基准。原始行情保留，计算结果不落 SQL，也不作为另一份业务副本长期保存。

## 字段和公式

| 字段 | 含义及契约 |
| --- | --- |
| unified_code / trade_date | 原正式证券键 / 交易日期；一证券一日，不外键依赖当前股票名单 |
| factor | 以区间首个交易日为 1 的累计乘法因子；Decimal 高精度计算，输出十进制字符串 |
| forward_multiplier / backward_multiplier | 当日因子 / 截止日因子，以及当日因子 / 首日因子 |
| open / high / low / close | 已归档收盘后快照的原始人民币价格；不依赖尚未确认的成交量单位 |
| forward_* / backward_* | 原始价格乘对应乘数，不调整成交量，不用于实际成交记账 |
| input_hash / algorithm_version | 输入业务内容、所选范围和计算版本绑定；来源修订后重算 |
| events | 本日实际使用的来源业务键和除权参考价；不是来源原文或永久日志 |

每个除权日，设 P 为前一实际交易日原始收盘价，D 为每股含税现金分红，S 为每原股送转总股数，R 为每原股配股股数，A 为配股价格：

`除权参考价 E = (P - D + A × R) / (1 + S + R)`

`当日因子 = 前一日因子 × P / E`

非除权日因子沿用。结果使用未舍入的理论参考价，不声称逐值等于交易所按最小价格单位处理后的参考价或任何厂商复权算法。含税分红为计算口径，不模拟个人分红税、现金到账、认购支出或总收益账本。配股因子也不意味着所有投资者实际参与配股。

仅“实施方案”参与分红计算，已知预案、取消与终止不参与；未知状态报错。已实施但缺除权日期、现金金额或送转合计时保持未知，不填零。送转合计为明确数值时可直接使用，不强求可空的分项。并列同日分红或配股方案不擅自求和或挑选；同日一份分红与一份配股可以按同一原股口径合并。缺前收盘、除权发生在缺行情或停牌区间、价格非正、现金超过前收盘价等均明确失败，不输出部分因子冒充完整。增发、合并换股、拆细和其他未建模事件不自动套用本公式。

## 存储设计卡与查询预算

本项为派生查询，现有业务表和结构不变；无需 DDL 或历史数据迁移。严格复权计算入口是 `adjustment.query.calculate`，页面 `adjustment.query.history` 复用同一核心和只读输入路径；数据准备调用相同入口，不另写规则。数据浏览页面只在需要时创建，写入命令及网络任务不属于本页。

查询在同一个 MySQL 只读事务快照中读取，核对证券日的规范内容/集合摘要及现行布局契约；分红读取单证券完整记录并与 collection_state 单元的数量和摘要比较，配股完整列表与最终范围证明比较。已知空事件必须由完整来源证明支持，不能把未采集当作没有分红或配股。来源版次和完整性证明改变时使用新输入重算。可信摘要仅作为采集归档原有机制，本项不刷新摘要、不写 SQL，不持有 Redis 业务副本。

| 访问 | 正式 SQL/预算 |
| --- | --- |
| 单证券价格 | 复用 stock_market_day 与类型化明细的证券日期主键查询；最多 3660 自然日、10000 个证券日，按现有 16 日有界批次解码 |
| 日历和停牌 | 读取所选日期的完整日历并核对日期集合；沿用明确全日停牌区间，未知状态不排除缺日 |
| 单证券分红 | dividend_plan 按 unified_code 读取，最多 2000 条；校验完整单元及内容摘要 |
| 配股范围 | rights_issue 至多 10000 条，核对有序单位链与最终 manifest；包含无配股证券的空集合证明 |
| 页面/准备检查 | 单次页面一证券；准备检查明确证券和起止日期，一次最多 20 只，遇缺输入返回具体定位；不做默认全市场历史扫描 |

因子持久化新增空间为 0；页面单证券结果最多 10000 行，图表使用全部查询行，明细每页 200 行。输入的临时工作区受上述条数上限约束，单证券五年约 1250 行因子，不复制全市场历史。重复计算仅执行 SELECT；相同输入结果与摘要相同，来源修订改变输入摘要和受影响结果。现有统一归档负责输入旧版防覆盖、提交重放和成功清队，本项不创建第二归档路径。

## 使用与生命周期

从“数据浏览 → 数据目录”搜索“复权因子”，默认自动识别市场，或明确选择SH/SZ/BJ；手动选错时提示正确市场。选择证券及起止日期后点击“加载K线”。默认从2021年起至昨天，K线图显示全部查询交易日，支持原始/前复权/后复权、MA5/10/20、按钮缩放、拖动平移及方向键逐日查看。“因子与价格明细”仍每页200行，翻页不截断图表。复权输入不完整时，严格计算与数据准备仍失败；页面可以显示已完整校验的原始OHLC，复权字段为空、复权模式提示原因。原始价格无效的日期显示缺口与空价格，均线中断，不代算或连接无效数据；缺日期集合或盘中快照则整个查询拒绝。来源历史时刻15:00起可作为收盘快照，当日查询仍独立使用15:30交易日截止判断。图表不展示尚未确认单位的成交量。不需要另启因子采集任务。输入缺失时按提示到对应行情、分红或配股任务补齐，再重新计算。无已归档行情不代表股票不存在；当前目录与实际行情覆盖独立。来源本身缺除权日期或金额时，重复采集不能保证修复，需公告或其他完整来源补充。查询条件改变及失败后，图表保留上次证券和范围的提示，价格口径切换不能清除该提示。日期范围至少两个完整交易日才能展示事件跳变；可以单日显示基准 1，但不代表历史累计因子已知。首次查询和后续查询都从当前完整归档输入计算，程序或 Redis 重启无需恢复派生断点。

前复权截止日明确固定于所选范围末日，回测不能用未来截止日归一后的价格作为过去可知的绝对价格信号。现有输入只保存当前来源修订版本，不能证明当时可用的旧版方案；普通历史走势分析允许此限制，严格历史信号回放仍不能宣称通过。采集支持和计算支持范围不等同于实际已归档范围。

## 验证和交付

验收覆盖无事件、现金分红、送转、配股、同日组合、多次事件、预案及取消、缺值、并列方案、缺行情、首日归一、截止日和未来事件隔离、重复结果、修订及输入摘要改变。隔离集成复用正式来源规范化、统一 Redis 入队/归档、SQL 完整证明及计算查询；新计算不发网络请求，代理策略不适用，输入来源实采仍遵守共享代理优先策略。实际数据另列证券/日期范围、缺口和部署验证，不以模拟计算替代实采验收。
