## 今日 Redis 盘中补充（2026-11-11）

## 范围与正式路径

独立分析入口，不放进采集任务或基础数据目录。Electron 页面负责选择、展示、保存本机视图与导出；observation_calendar 业务插件只编排已有 calendar.query、index.prices.query、market_margin.query 正式只读服务，桌面桥负责协议映射，不新增 SQL、业务表、Redis 键、采集任务或迁移。

一个自然月以周一开始的完整周网格展示。查询前一自然月到网格结束的日历及行情用于精确确定前一交易日；缺日或前收缺失时不跨缺口计算涨跌幅。未来日期保留日历状态但不展示未来业务数据。金额、缺值和来源范围保留；市场两融不伪装成指数成分股指标，指数成交额保留来源单位口径。

指标：指数收盘、涨跌幅、成交量、成交额；融资余额、融资买入、融资净买入、融券余额、融券净卖出、两融余额和两融余额比例。目录来自实际指数查询，市场使用已有四市场定义。派生指标及既有汇率日线接入见下文；北向资金、自定义公式及指数成分范围不在本次范围内。

## 逐指标设置与派生指标设计（2026-11-05）

融资买入/偿还比 = 融资买入额 / (融资买入额 - 融资净买入额) × 100；分母非正、字段缺失显示缺值。保留净买入额为独立指标，不把净买入或两融余额比例误称偿还比。

设置按指标独立保存范围、当前值/前一交易日环比/累计N个交易日、阈值。弹窗左侧列出指标，右侧维护草稿；确认原子应用，取消不改生效设置。比例指标累计采用算术均值，金额/量采用求和，明确显示名称和单位；缺日不跨越补齐，不把未知当零。指标范围遵循实际来源，不虚构沪深合计或全A指数成交额。

Top成交额占比读取既有远航个股日线，不新建表、Redis键或采集路径。窗口及Top比例有界；使用日期索引读取完整窗口，限制证券数和行数，超限失败。统计按已归档个股样本明确标识，不能声称全市场完整；缺值、窗口不足不填零。默认按窗口累计成交额排序，Top数量向上取整，分子除以样本总额；界面和说明明确展示此口径。新增结果只在查询时计算，现有业务字段、索引、写入与迁移不变。
