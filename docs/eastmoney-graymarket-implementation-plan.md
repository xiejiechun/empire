3. 存储及查询：结构化表、可信摘要、旧版保护、正式SQL分页及准备检查；隔离端到端测试。

## 请求、内存与队列预算

单日P=ceil(N/100)，当前样本P=54、正文约0.97MB。首次D个交易日约ΣP请求；新增一天且回看两天约162请求/2.92MB，最新发现页若属于目标日期必须复用。无新增日期仍有近端核验成本，不能宣传成零请求。精确缺口只采缺口，状态丢失按SQL覆盖补缺。认证请求当前为0，重试独立记录。未核实区间或多日批量能力，不杜撰增量参数。

复用共享HTTP下载器、代理优先且可直连回退、站点频控和字节预算。日期或页预取通过共享有界预取，按序消费，失败取消后续请求并释放额度。整日聚合有独立上限，不能持有多个完整日造成无界内存。先完整校验再原子发布一个有界日单元；消息如需压缩仅为传输表示，SQL仍为结构化事实。不得逐日等待归档；整轮发布后统一确认本轮所有消息成功清队。
