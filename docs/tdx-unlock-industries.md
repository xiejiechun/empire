# 大小非解禁行业（通达信）

## 如何查看
数据目录搜索“大小非解禁行业”。按解禁月份及行业查询数量、市值与比例。采集管理选择同名任务，默认每天北京时间18:00，代理优先且可回退直连。保存MySQL，重启保留，下一轮生效。

## 数据范围与更新
目录tdxsj_cgbd_cache参数[dxfhy,0]提供滚动可得月份和mxt估值基准日；业务tdxsj_cgbd_dxfhy参数[YYYYMM,mxt]一次返回完整行业集合，没有分页/每页参数。初始化以本轮目录为边界，逐月校验入队，整轮确认归档后完成。日常重新读取目录并回查全部目录月份，补缺及接收修订。已归档且退出目录的月份保留历史参考，不用目录外空响应删除。源端不支持完整历史回放。

## 字段与日期
一行是一个解禁月份和来源行业名称，来源无行业代码，不关联同花顺行业代码。T003万股乘10000转股；T004万元乘10000转元；MarketCap、NegotiableCap为来源原始元，zszbl/ltszbl百分数原样保留。基准日由目录mxt保存，不是公告日期，也不是当月收盘价；来源数量、市值和比例分别保留，不用一个数反推覆盖另一个数。

## 限制与排错
目录外历史查询为空表示当前接口不可得，不证明历史无解禁。目录可得月有效空集须有完整协议和月份回显。行业名称必需，数值NULL为未知不填零，重复行业、错月份、缺字段、非法数值和截断失败不推进断点。无公布日期，严格历史信号不可用；不同基准日数据不混算。

## 生命周期及存储设计卡（实现前）
- 项目tdx-unlock-industries，job_key同名-v1，dataset unlocks.tdx_industry_month，固定来源tdx，一个独立采集插件。
- 业务表restricted_share_unlock_industry，主键(unlock_month,industry)，月DATE固定1日，行业VARCHAR(200)，basis_date DATE；shares、unlock_value、market_cap、negotiable_cap DECIMAL(28,8)可空；market_percent、float_percent DECIMAL(28,8)可空；content_hash CHAR(64)、version_observed_at DATETIME(6)。唯一一条正式读写路径。
- 索引主键供月份全行业及范围；ix_industry_month(industry,unlock_month)供行业历史。正式查询月份范围/精确行业，稳定(month,industry)游标单页200；完整单月最多500行业；目录最多120月且有序、唯一。
- 月完整集合独立事务，删除仅当月撤回行业；其他月份不删除。状态每项目collection_state一行保存有界单位证明和最终目录，业务集合/内容摘要同事务绑定。源业务没有修订编号；(basis_date,observed_at)只排序当前观测响应，不能宣称公告版本。
- 重复内容零业务DML，可信摘要命中免SQL，迟到旧基准日/旧观测响应不覆盖，新基准日是有效业务变更。提交后重放与成功清队归统一归档器。
- 下载中断重下未入队月；入队后继续下一月，不逐月等归档；最终等待全轮无残留。Redis存活用目录/basis有界断点；Redis丢失重新发现当前目录并回查所有可得月，旧不可得月保留、不承诺缺失旧队列恢复。普通继续保持冻结目录，fresh明确重建目录；跨日期本轮用冻结基准，下轮更新。
- 预算目录500KiB，月消息512KiB，单月500行；当前24月约1000行，5年留存估计60*100=6000行，含索引≤32MiB；隔离放大120月*100行业12000行≤64MiB，分页/行业/月份查询≤100ms，重复与修订事务≤5秒。提供实测及EXPLAIN。
- 新增空表显式维护，关闭Empire、单实例锁、队列0、前后原业务库存核对；启动不DDL，不修改现有解禁个股数据。来源到正式查询测试覆盖冷热缓存、同数异集、旧记录补齐、旧版、提交后重放、集合失败无断点、延迟归档仍连续发布。
- 当前目录样本2026-09至2028-08；支持范围由每轮目录决定，不编造统一历史起点。开发及实采进度另记。
