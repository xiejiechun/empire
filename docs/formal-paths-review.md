## 生产者契约核实后的调整

原审阅稿建议 proxy 必须带协议。只读检查发现当前两台在线设备的 JSON 内 proxy 无协议，因此按保持现有生产者接入的默认方案，将此形式明确为正式 SOCKS5H 凭据格式，而非保留旧的整条裸目录适配器。显式 URL 保留百分号编码，无协议原始凭据按字面编码，均由同一入口处理。生产者 key 未修改；实查在线 2 条、无效 0 条。未进行几十台实体代理压力测试。
