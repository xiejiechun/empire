# 采集运行详情统一（2026-10-11）

## 范围与根因

用户入口：采集管理 → 采集任务 → 运行详情。界面将未提供 unit_name 的 completed_units 忽略，退回 pages 并统一标记证券，造成4,754页与573个指数同列。停复牌还会把归档批次数当作完成月份。任务结束只保存execute返回值，失败/暂停经常丢失运行统计。
