# 历史盘口页面对照与验证

## 范围与来源对照

用户要求“数据浏览 → 开盘啦历史盘口与日行情摘要”的设计向开盘啦看齐。工作区开工为空，无其他 Empire 开发线程；保留 RouterProxy 工作区及数据，未发送跨聊天指令。

通过 computer-use 观察 MuMu 模拟器的松原安全 300893、2026-09-11 历史分时页面：上方最新价／涨跌额幅及六个日行情指标，左侧价格和均价，右侧卖五至卖一／买一至买五及总买卖。原应用同时有量柱、大单、分笔和回放功能，本次盘口页不把这些来源独立产品冒充盘口接口输出。

## 实现

原字段表替换为报价、走势、五／十档、行情估值股本及可展开附加字段分区。价格按昨收着色，零价档位显示缺位；未知数量单位保留来源单位，万亿只缩写原数值，原值保留在提示或附加字段。主查询只读历史盘口，走势可选读取同证券同日期的独立分时归档，不请求来源、不触发采集。

通过现有 UI 插件登记按需创建，页面使用公共 QueryScope。布局、字段格式、绘图、查询职责分别拆分，保留现有任务导航、查询条件草稿和页面状态。失败的主查询明确标记旧快照；缺分时不阻塞盘口，迟到分时不混入其他证券。

同步内置专门说明主题、页面关联、专项指南和实现状态。本次不改采集语义、数据库结构或归档契约，因此无需重新采集验收；新增绘图只展示已有规范分时，盘口和分时仍是独立业务。
