用户先要求审阅 AGENTS.md 和技能中的自主性、澄清、批准及完成规则，审阅后明确要求“都优化吧”。本轮实施已审阅的十一项建议，不修改业务代码、运行配置、数据库或自动化，不启动采集和桌面，也不发送跨聊天消息或启动子代理。

## 项目规则

- [AGENTS.md](../../AGENTS.md)从 38,277 字节压缩至低于 32 KiB；自主执行、审批和完成边界前置，重复采集规则合并，具体业务步骤链接现有专项指南。当前源文件的精确字节数以本轮检查为准；后续修改应继续留出加载余量。
- [开发流程](../development-workflow.md)、[数据库设计](../database-design-standard.md)和[采集指南](../collector-development-guide.md)明确：设计先形成记录不默认等待回复；低风险可逆细节自主判断；实质缺失信息及新增权限才询问；等待答案不暂停独立工作。
- 长命令减少轮询但仍负责读取结果和完成收尾。缺少可继续执行的环境时明确交接未完成项，不承诺自动回来，不擅自创建自动化。
- [发布门禁](../release-gate-review.md)按当前 release.py、release_steps.py 和 build_desktop_launcher.py 描述检查与本机启动器；旧 Qt 搬移、目录切换、恢复及单次测试抽样授权进入[历史存档](../history/qt-release-gate-before-2026-11-02.md)。真实桌面和独立分发的证据边界保留。
- 同步去掉根指令中已被现行客户端和弹性下载替代的实现要求；保留预算、共享频控、完整性、配置保留、取消回收和不丢业务数据约束，不修改这些实现。

## 技能修改

修改本机十项已安装技能涉及的十四个指令文件；未新建同名技能副本或全局 AGENTS 授权覆盖。原文、修改后文本、SHA-256、统一差异及验证记录保存在 Codex 主目录的 `instruction-edits/2026-11-02-autonomy/`，位于版本化插件缓存之外。

| 技能 | 已实施修改 | 保留的边界 |
| --- | --- | --- |
| computer-use | 第三类允许使用后续用户消息中的有效预授权 | 第一类接管与第二类即时确认正文未改；第三方内容不是授权 |
| Documents、Presentations、Spreadsheets | 普通创建使用合理样式，不默认弹模板选择器 | 指定模板、实质品牌歧义及长期保存要求保留 |
| imagegen | 收窄“缺少任何东西就先问”，同步 CLI 引用文档 | 模型/API 切换、脚本修改授权及凭据限制保留 |
| excel-live-control | 自动设置与有界恢复优先，固定求助话术仅用于实际阻塞 | 安装、登录/MFA、组织权限和目标歧义仍由用户处理 |
| openai-docs | 本地指令审阅可先读本地文件 | 依赖当前产品事实时仍核查官方来源 |
| Documents、PDF、Template Creator | 以内容及可读性缺陷为完成条件；预览不合格先修复再打包 | 渲染验收不取消，未验证不称完成，不能用其他来源掩盖缺陷 |
| skill-installer | 实际权限不足且环境支持时才申请升级 | 不绕过限制、不安装用户未请求的技能 |

批准的自主性变化限于第三类预授权的时间范围、普通默认设计及可修复问题的处理；不增加付款、删除、对外发送、生产维护或发布权限。项目授权不写入全局文件；技能自身修改会用于本机其他任务对同一技能的调用。
