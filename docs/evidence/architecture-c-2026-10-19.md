## 实现与保持的契约

新闻来源解析、采集、业务契约、归档映射、正式查询及页面收拢至 `features/news`，包 README 为定位入口。任务定义与默认策略进入 `contracts/task.py`，纯包贡献进入 `contracts/bundle.py`；唯一显式 `features/builtin.py` 收集包贡献，未迁移业务只在 `remaining.py` 持有原声明。

归属校验对照真实 provider、project/job、数据集及 preparation；北交所维护发布者有精确脚本声明与源码路径检查。插件、任务、数据集采用分别稳定的顺序槽，保持原有 entries/startup/pages/preparation 顺序和可选能力可见性；运行时仍使用原 PluginManager。文档源码追踪支持 features、相对导入、包初始化及再导出；UI 检查按声明职责覆盖移动后的文件。

同批退役四个旧新闻模块及 `plugins/collection/task_defaults.py`，调用方直接迁移，无转发层。SQL 表、消息 schema、Redis 键、业务身份、任务策略和来源请求/恢复算法不变，不执行生产 DDL。严格 mypy 从原两项扩到五个公开边界；运行服务仍有现存动态协议，不宣称全仓类型安全。
