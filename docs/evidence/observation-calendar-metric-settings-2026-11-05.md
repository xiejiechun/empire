# 观察日历逐指标设置与派生指标

## 实现

新增融资买入/偿还比，使用融资买入额除以（买入额减融资净买入额），乘100；分母非正及缺值不计算。保留净买入额和两融余额比例的原身份。新增Top成交额占比，默认30个交易日、Top 5%，按窗口内个股累计成交额排名再计算前Top%占样本总额；用户未回复公式选择问题，本轮按已说明默认口径实施。页面和说明明确已归档样本限制，不宣称完整全市场比例。

13个指标都有左侧导航、右侧参数的独立设置界面。支持适用市场范围、当前值/前一交易日环比/N交易日统计（非比例求和、比例算术均值）、阈值；Top另有窗口和比例。弹窗草稿确认生效、取消不改，保存视图跨启动保留；原有保存视图不会自动丢弃或替换用户所选指标。CSV列名记录应用后的单位、范围和参数。默认新视图包含偿还比和Top，已有视图可在管理指标加入。

只读已有日历、指数、市场两融及远航日线。查询辅助日期有界，Top按日期索引流式读取、最高250万行拒绝截断；不新增数据库表、Redis键、采集或数据迁移。正式页面表覆盖、装配和架构归属已更新。
