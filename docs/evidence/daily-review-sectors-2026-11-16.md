# 每日复盘板块资金汇总 · 2026-11-16

## 目标与授权

按用户确认，使用最新同花顺行业成分汇总所选日个股含暗盘主力净流入；历史日期固定标注“按当前成分股回看”。不补建历史行业库。开工已有修改清单保存在 build/review-sector-git-before-20261116.txt，未清理或混入其他工作；无子代理、跨聊天消息或对外推送。

## 实现范围

market_review.sectors 使用同一只读 REPEATABLE READ 快照，读取 current industry、industry_member、当日 graymarket_daily 及配置 namespace 的行业 collection_state；行业公开 api 复用现有契约2的数量、规范集合摘要与观测版本校验。状态 dataset 使用归档实际登记 ths_industries_v2（不是消息名 industry.snapshot），错误来源、数据集、命名空间或损坏证明均仅令行业统计未知，个股资金可继续显示。

净正值、净负值分别排序各取5，Decimal 汇总及排序，同值按行业编号升序。每行显示覆盖数，部分覆盖只合计已知成分，不填0；零覆盖排除；全部当前成员均无交集时为未知。已知0不入方向榜，有覆盖的空方向明确提示。当前成员变化可改变历史重算，非历史行业归属或严格历史回测。ETF仍显示“缺少数据来源”。未新增表、字段、索引、Redis键、采集器或业务写入。
