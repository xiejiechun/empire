# 同花顺公司资本运作

## 如何查看

数据浏览目录搜索“公司资本运作”，按股票、栏目和公告日/报告期筛选，选择记录阅读全部字段、项目简介和交易详情。采集管理中的“公司资本运作（同花顺）”一次请求每只当前股票的 capital.html，统一采集募集资金来源、项目投资、收购兼并、股权投资、参股IPO、股权转让、关联交易、质押和冻结及其解除。无需逐栏目重复请求。

## 数据范围与更新

只承诺页面完整响应内可得内容；不同栏目、证券的历史起点不同，无统一最早日期。股权投资保存所有可见报告期及汇总/持仓；项目简介包括展开属性，股权转让包括隐藏详情和交易影响。历史已入库记录保留，来源窗口消失不删除历史。未列示栏目表示来源未提供，明确空提示保留其原文，不能推断上市以来无事件。

默认每天北京时间18:30核验，默认停用以避免安装后立即启动全市场请求；用户启用后按已保存计划运行。网络默认代理优先、不可用可退回直连。首次启用或普通新一轮均完整回查当前股票池，不只按最大公告日增量；预计到期前的旧质押也必须回查以发现解除。配置保存到MySQL，下轮生效，已保存选择优先。

### 生命周期与完整性

| 项目 | 契约 |
| --- | --- |
| 初始化边界 | 本轮当前股票池的每只股票完整响应；来源投资报告期不得晚于请求当日北京时间；公告标注日可晚于采集日，原值保存并记录栏目日期提示，无人为补造历史 |
| 完整单位 | 一只股票全部栏目、隐藏表格、全部报告期、明细和解除列表；栏目结构/标题/单位/行宽/期间集合和重复次数校验；总数未公开，证明限于实际完整响应 |
| 初始化完成 | 所有股票校验且统一归档确认，最终范围证明与证券集合/滚动内容摘要对应；失败不推进连续断点 |
| 后续起点 | 新一轮从股票池首只全量回查；未完成轮次从首个未入队股票恢复；池集合改变重建新轮次 |
| 补缺修订 | 每轮重读完整响应补齐缺字段和旧事件解除；页面外消失历史保留，不承诺历史版本回放或源站遗漏检测 |
| 下载/入队中断 | 仅原子入队后推进股票索引；已入队立即继续后续股票，不逐只等待归档；有序有界预取失败取消全部未消费响应 |
| 归档中断 | 统一Stream原位重放；SQL成功后Redis确认失败仍安全重放；整轮末才等待全部队列消息清理 |
| Redis丢失 | 已归档业务和每项目一行SQL状态保留；从头完整回查，不依赖已丢断点；不承诺未归档消息恢复 |
| 普通/重新初始化 | 普通继续未完轮次；fresh重建下载范围，但已入队末尾等待阶段先确认；历史业务均保留 |
| 证据 | 开发验收与实际证券采集范围另存evidence；功能支持全池不等于全市场已采完 |

## 字段与日期

大证券的规范明细采用有界无损矩阵压缩传输，整只股票仍一次原子入队、同事务归档，不拆散质押与解除关联。消息schema为2，解压矩阵最多8MiB、编码正文最多512KiB，完整消息仍受共享ingest.max_page_bytes限制；超限或损坏失败并保留原断点，不截断、不丢行，也不自动调高日常容量设置。SQL八张业务表、业务键及内容摘要口径不变，不保存压缩业务JSON。升级前须正常关闭旧程序并确认该项目旧schema消息为0；运行时只接受现行传输契约，已有正确SQL记录及业务证明无需迁移。

股权投资持仓的所持对象明确为“未公布”等空值时保存NULL，保留报告期、分类、投资类型及金额/数量。缺列、分类或投资类型缺失仍报错；不会按其他报告期猜填对象，不将未知对象并成一条或跳过。相同锚点的多条来源记录按既有规则保留次数；以后对象披露造成锚点变化时保留历史，不推定为同一经济持仓。

解除事件的股数明确为“--”等来源空值时保存NULL，保留公告日、实际解除日及原质押/冻结关联，不填零、不按原始股数推算。缺少股数字段标签、缺公告日或父事件仍报错；数量未知的解除不能用于计算剩余风险股数。

原始质押/冻结股数明确为“--”等来源空值时同样保存NULL，保留股东、公告日、预计期限、机构、说明及全部解除关联；不从说明正文或解除数量猜填，不填零。原始股数字段标签、公告日期或股东缺失仍报错。原始股数参与来源记录锚点，后续披露数量后保留另一来源身份，不能据此推定同一经济事件或计算当前余额。

参股IPO对象明确为“--”等来源空值但审核进度已披露时，保留NULL对象、审核状态及其他完整字段；全行无对象且无审核状态仍报错。完整表头、行宽和来源重复次数继续校验，不按其他股票或正文猜填对象；以后对象披露形成不同锚点时保留历史，不自动合并。

来源页面可能提前列示晚于采集日的公告标注日期，例如10月18日已列示10月19日公告、10月21日发行。保留原公告日和发行日，并在栏目可用性记录source_announcement_after_observation，不将未来标注日改成采集日。该标记属于来源日期提示，不能证明公告已正式发布；用于历史信号时至少晚于标注日且不得早于实际观测，不承诺旧版本可用日期。股权投资的未来报告期仍拒绝，不能当已披露业绩。

交易金额支持加拿大元、加元、挪威克朗、瑞典克朗、越南盾、马来西亚林吉特、印度尼西亚卢比、泰铢、丹麦克朗、澳门元、波兰兹罗提、文莱林吉特、肯尼亚先令、墨西哥比索、俄罗斯卢布、印度卢比、巴西雷亚尔等已登记币种。重叠名称按最长完整名称识别，例如文莱林吉特与马来西亚林吉特分别保留。数值倍率统一支持万、亿、万亿；例如6.00万亿越南盾保存为金额6000000000000、币种“越南盾”，不换算成人民币。例如1.84亿加拿大元保存为金额184000000、币种“加拿大元”，保留来源写法，不换算汇率。例如31.08亿挪威克朗保存为金额3108000000、币种“挪威克朗”，仍为原币金额。数值解析与币种识别共用同一币种表；未知或混合币种报错，不默认归为人民币。

金额为页面展示数值换算到元，原币种单列，不做汇率换算；来源估算数保留估算标志。数量换算到股；比例为百分数，NULL代表未提供，不填零；数值栏的缺值占位符带百分号（如--%）仍保存为空，保留原持仓及其他字段；未知文本或重复百分号仍报错；数值负零统一为0，确保SQL往返和重复比较一致。公告日是自然日、无秒级时刻；股权投资只有报告期，参股IPO无公告日，不用于严格历史信号。当前正文可能含后来补充的进展，不承诺恢复过去某日所见正文。预计截止时间不得当实际解除日期；没有解除记录只能说明页面未披露，不能据此确定当前余额。关联交易预计额度、实际结果和累计金额只保留来源口径，不直接相加。

## 限制与排错

缺少整栏、协议变化、非法日期/单位、截断或详情结构损坏不能当空结果。缺失栏目必须与来源明确不提供状态区分；HTML必须校验页面证券身份和完整结束标志。来源空字段原样保留为未知，不解释为无业务。股票池来自当前正式stock；退市历史及来源窗口外范围不自动扩展。重采不删除历史；源站同锚点多事件无法可靠跨轮匹配时只保证页面来源记录，不能直接生成当前风险余额。

## 相关说明

实采验收统一使用 `scripts/verify_ths_capital.py --test-mysql-settings <独立MySQL连接JSON> --output build/<本轮新报告>.json --random-count 30 --seed <整数种子> --proxy-only`。从只读正式股票池随机抽取至少30只，额外保留八只历史失败证券；`--codes`可增加固定证券，不能替代随机样本或换样。每证券一次完整HTML，经共享下载/代理/预取、原子Redis入队、统一归档和正式列表/详情/范围审计逐项核对集合与内容，报告保留九栏目数据准备原结果；来源链路通过不代表所有历史信号用途可用。

工具核实实际server_uuid与生产不同，再创建UUID私有数据库和Redis命名空间，逐连接SQL守卫限制写入；不修改生产断点或用户任务设置。成功响应不保存，报告保存池/种子/名单、摘要、实际路由、正式查询及待归档0证据；六项关闭清理全部成功后才可输出PASS。旧`--config/--apply/--report`入口已退役。中断后先检查报告的cleanup/remaining；仅用共享 `--cleanup-only --run-state <原报告.ownership.json> --test-mysql-settings <同一连接JSON> --output build/<新清理报告>.json` 恢复精确归属资源，归属或运行状态未知时保留资源，不手工删库、删锁或清共享Redis。ownership文件含私密归属信息，不提交或展示。
