# P3-30 跨页面业务上下文导航验收

日期：2026-09-27。

## 唯一正式路径

业务页面通过 `PageContribution.management` 声明一个 `NavigationTarget`，目标由页面 ID 和受校验的 `NavigationContext` 组成。股票列表、财经快讯和交易日历分别声明 `sina-stocks`、`sina-news` 和 `cninfo-calendar`；按钮只调用外壳的通用管理导航。桌面外壳负责找到目标页面、按需创建页面并投递上下文，不包含股票、新闻或日历的任务映射。

目标页面创建失败时，上下文保留到用户重试成功；成功投递后只消费一次。目标页面不存在或不支持上下文时，外壳清理待投递值并显示提示，不让过期上下文影响后续导航。

## 任务定位与草稿边界

采集任务页收到任务 ID 后进入临时精确定位模式：

- 后端按内部任务 ID 精确返回关联任务，不受当前关键字、分类、来源和状态筛选影响。
- 原筛选值和原分页位置不修改，页面明确提示它们仍被保留；“返回原筛选”恢复原页。
- 编辑草稿继续按任务 ID 独立保存。跳到关联任务不会覆盖其他任务的未保存草稿，保存仍只作用于当前选中的任务。
- 用户主动修改任一筛选条件时退出临时定位并从筛选结果第一页查询，这是明确的新操作，不继续隐藏在定位模式中。
- 关联任务已退役或不可用时显示明确提示，不默认选择另一个任务。

精确定位参数是当前控制器查询契约的一部分，不保留另一套客户端遍历或按任务名称猜测路径。

## 返回数据目录

数据目录继续拥有自己的搜索、分类、来源、分页、稳定页面 ID 选择和滚动状态。从目录打开数据页后再返回，会恢复原筛选、页码和原业务页面；不会因页面重绘默认跳到第一项。股票、新闻和日历各自保留适合业务的分页方式：股票使用偏移分页，新闻使用稳定游标，日历使用年月导航，不为了表面统一增加重复适配器。

## 自动验收

自动回归覆盖：

1. 三个业务页面贡献均登记正确的采集任务 ID，桌面外壳没有业务映射。
2. 同一目标页连续接收不同上下文时各投递一次；不支持上下文时清理待投递状态。
3. 页面工厂首次失败后重试，原上下文仍能准确投递。
4. 精确定位忽略不匹配筛选，并明确报告已退役任务。
5. 定位前的筛选、分页和其他任务草稿保留，退出定位后恢复。
6. 500 个数据页面下，目录仍按需创建页面，返回时恢复来源筛选、深页位置和稳定选择。

离屏 Qt 测试验证状态和路由契约，不替代 Windows 真机上的键盘、DPI、读屏器及人工视觉检查。
