# P2-20 键盘与读屏语义验收

日期：2026-09-27。

## 正式实现

- 公共 UI 模块提供唯一的可访问名称与查找快捷键入口。公共表格从列标题生成稳定名称和键盘浏览说明，分页状态也具有语义名称。
- 外壳一级导航、二级页面导航和当前内容区具有明确名称；导航继续使用标准列表键盘行为，当前位置仍由选中项和面包屑文本共同表达。
- 数据目录、股票、财经快讯、说明文档和采集任务/网站组搜索支持 Ctrl+F。占位文字仅作输入提示，不再承担读屏名称。
- 采集任务与网站访问规则支持 Ctrl+S，快捷键触发原有保存按钮，不增加第二套保存逻辑；按钮禁用时快捷键同样不会绕过校验。
- 数据目录、股票、新闻、交易日历、说明文档、任务、站点、运行记录及插件筛选的关键输入、结果列表、正文和状态标签已补稳定名称。
- 列表、表格和标签栏使用当前条目级焦点标记，不显示整控件外框；主按钮具有独立焦点边界。状态和错误继续以明确文字表达，不只依赖颜色。

## 自动验证

测试通过 Qt `QAccessible` 实际接口读取关键控件名称，覆盖目录、任务和说明文档；验证 Ctrl+F 聚焦搜索、Ctrl+S 复用保存正式路径，以及关闭原生轮廓后仍存在条目级焦点样式。现有表格刷新测试继续验证选择、当前单元格和滚动位置不会被周期刷新重置。

## 验收边界

自动测试不能替代 Windows Narrator、NVDA、系统文本放大或真实键盘全流程核查。本轮没有宣称 WCAG 合规认证，也没有改变 Windows 高对比度主题行为；固定主题的非文本对比度与系统高对比度适配属于 P2-21。人工验收仍应覆盖不用鼠标完成查找、筛选、编辑保存、复制和页面切换，并确认读屏对动态状态变化的播报时机。
