# 开盘啦单日空间测量

## 入门

`scripts/measure_kaipanla_day.py` 是一次性容量实验入口。默认读取正式股票名单和交易日历，对最近已结束交易日的全部当前上市沪深北证券逐一请求已核实接口，使用共享下载器、在线代理目录和已保存的网站频控。运行时强制代理、关闭直连回退，每次实际网络尝试生成匿名设备身份。

测量与桌面正式采集分开：正式采集仍通过原来的 Redis 入队、统一归档和 MySQL 查询；本实验将返回内容写入专属临时文件，测量后删除，保留计数、摘要、错误和空间报告。它没有注册新采集任务，也不会生成正式业务覆盖证明。

## 日常操作

在项目根目录执行：

```powershell
.\.venv\Scripts\python.exe scripts/measure_kaipanla_day.py
```

连接配置取项目根目录 `config.toml`，`--config` 可显式覆盖。日期默认来自正式日历的最近已结束交易日；`--day yyyy-mm-dd` 仅接受日历确认的已结束交易日。`--limit` 和 `--symbols` 用于开发抽样，正式全市场测量不传这两项。

报告默认写入 `build/kaipanla-day-measurement.json`，可通过 `--report` 指定项目内路径。运行中约每20秒更新汇总进度，结束时保存逐证券、逐接口的大小、计数和验证结果。每次运行建立新的 `build/kaipanla-measure-data/run-<随机标识>` 专属目录；正常完成、异常或取消时，关闭下载及文件后核实所有权，再删除这一目录。

只运行一份测量脚本。与桌面采集同时运行会共享出口许可并延长耗时；开发测量时可正常关闭 Empire，结束后重新打开。固定每出口间隔、全站保护和429冷却取现行设置，脚本不根据测量目标扩大网站频率。

## 数据说明

当前请求以下10个接口：

| 接口 | 临时测量内容 |
| --- | --- |
| GetStockTrend | 普通分时全部来源字段 |
| GetStockBid | 开盘竞价完整点数组，同分钟多点保留 |
| GetStockVolTur | 分钟成交量、成交额及标记 |
| GetStockFenBi2 | 分笔完整数组，同秒多条保留，核对Count/total |
| GetStockBsvolume | 买卖委托汇总序列 |
| GetStockDaDanTrend | 大单净额序列 |
| GetStockPanKou | 日末盘口、日行情及附带估值股本字段 |
| GetStockZJMMMin | 来源分钟买卖/净额附加序列，保留原列 |
| GetStockChouMa_New | 来源筹码附加数组，核对Total |
| HisSuperFuPan.StockTrendInfo | 完整历史回放行情、盘口及分钟索引数组 |

历史回放显式使用 `isAll=1、start=0、stop=0`；缺省请求可能只返回开盘的一小段。响应为表单百分号编码的zlib正文，脚本去除传输编码后保存原JSON字节。完整数组保留顺序、重复记录、原始字段和精度；不填造每秒空行，不按分钟或秒合并，不将来源回放序列冒充交易所完整逐笔流。

回放验证价格数组与盘口数组逐点时间对应、完整分钟索引及索引对全部来源点的覆盖；15:00索引可以包含源端稍后更新，不能强制尾点秒数恰好为15:00:00。回放支持范围根据每份响应的 `MinDate` 和来源说明解释，不能套用普通分时2021年起的范围。

输出分别列出：

- HTTP正文经应用层传输编码前后的字节数，供识别源端压缩。
- 每证券一份无损分帧文件的逻辑大小。
- 同内容gzip级别6压缩文件的逻辑大小。
- Windows文件系统实际文件分配空间；目录/MFT开销、数据库行和索引、备份另计。

因此测量所得文件占用不是MySQL表占用。无效响应和失败记录单列，不能把总下载大小、原始条数相等或所有请求结束当作全市场数据完整。大单筛选明细/统计的独立字段契约、竞价附加统计和独立分钟OHLC仍未全部核实，报告保留这些限制。

## 故障处理

代理不可用时等待共享分配或报超时，禁止偷偷直连；网络重试沿用共享有界预算。来源错误、空序列、零价格占位、错日期/证券、缺分钟、总数不符、回放索引越界和结构改变记录为无效。后续证券继续测量，报告同时给出有效范围与缺项；来源不支持、未上市、停牌和请求失败不能无证据混为零数据。

中断后当前实验数据清理，本脚本重新运行会重新冻结名单与日期并重新请求；没有业务归档断点。清理核实专属目录标识、解析后路径及链接边界，拒绝删除所有权变化的目录。HTTP错误样本仍按基础设施的项目限量规则保存，不触及其他项目或共享业务队列。

## 技术参考与验收边界

HTTP使用正式文件输出契约，遵守传输/HTTP解压限制、单文件上限、下载目录配额、磁盘余量和文件并发。应用层zlib另外限制解码为64MiB并借用共享字节预算；正文和副本计入预留，这不是Python进程总内存上限。下载文件和实验文件分属同一专属运行目录，最终一起清理。

生命周期：初始化为当前名单与单个已结束交易日；结束为逐证券逐接口请求结束、文件测量完成、报告持久化和临时正文删除。它是容量诊断，不做增量、修订、防旧版覆盖或数据库结构变更；这些正式插件准入项在本实验中不适用。来源集合校验、失败显式呈现、真实代理证据和开发/实际结果分开仍适用。其中七项已按采集开发指南独立接入，见 [七项正式插件](kaipanla-intraday.md)；其他实验接口仍须单独开发验收，容量实验不能替代 Redis→归档→正式查询验收。
