# P2-19 小屏适配

2026-09-27。本轮完成桌面外壳与采集任务核心路径的响应式基础；实际设备矩阵验收仍单独列明。

## 已实施

- 窗口初始客户区按当前屏幕 availableGeometry（逻辑像素）限制大小，预留顶部窗口装饰空间；最低尺寸从 880×560 降为 640×360，并受屏幕可用尺寸约束。
- 网站访问规则的保存、撤销与反馈移出表单内部滚动区。
- 任务立即采集、暂停按钮移出运行详情内部滚动区，查看任务配置时仍可操作；继续使用已保存配置，不改变命令语义。
- 不重建表单、不改变草稿归属，不调整采集、代理、频控或存储行为。
- 采集任务在窄于 950 逻辑像素时由左右分栏改为上下布局；搜索框与分类、来源、状态筛选自动排成两行。
- 采集任务窄于 720 逻辑像素时隐藏来源、执行计划和下次执行等次要表格列，保留任务名称和状态；恢复宽屏后重新显示。
- 外壳窄于 900 逻辑像素时缩减侧栏、内容边距和间距，仍保留带文字的一级导航和面包屑当前位置。

## 验证与边界

自动测试覆盖初始客户区与逻辑屏幕边界、关键按钮不属于页面内部滚动区、窗口尺寸变化及切换配置后的草稿保留。这里验证的是 Qt 离屏布局及结构，不是实际显示器的高 DPI 视觉验收。

本批全量验证：857 passed、2 skipped（Windows 符号链接权限）；Ruff、现行范围 Mypy、pip check 与 diff 空白检查通过。

外壳仍允许页面整体滚动，因此“移出内部滚动区”不意味着任意极小视口下所有内容同时可见。本轮采用窄屏上下主从布局，而不是额外引入另一套详情页面，选择、草稿和命令路径保持唯一。真实设备的窗口装饰、跨显示器，以及 1366×768、1920×1080、2560×1440 在 100%～200% 缩放下的视觉验收仍未执行，不能由离屏测试替代。
