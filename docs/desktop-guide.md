# 桌面使用说明

界面采用白色简约风格：浅灰一级侧栏、下划线二级菜单、蓝色主操作与选中提示。表格、输入控件、运行记录和离线文档统一使用浅色样式，小窗口下长表单可滚动。

左侧一级入口为工作台、数据浏览、采集管理、系统设置、说明文档。工作台与说明文档点击即打开，不再显示重复的二级入口；其他分类在内容上方显示二级菜单。“数据浏览”先进入数据目录，按名称、分类和来源检索，再打开股票、新闻、日历等具体页面；二级导航仅保留目录与当前数据页。切回分类时保留上次选中的页面和查询状态。

| 分类 | 页面 | 主要用途 |
| --- | --- | --- |

| 数据浏览 | 数据目录 | 按名称、业务分类和来源检索已接入数据，每页 25 项 |
| 数据浏览 | 股票列表 | 按市场、代码、名称查询当前完整列表，复制所选股票 |

| 采集管理 | 运行记录 | 采集 / 归档 / 错误三个标签；按项目查看结果、样本和修复后的精确清理 |

## 常用操作

- 找股票：从数据目录打开股票列表，选择全部市场或沪、深、北市场，输入代码或名称，按 Enter 或查询。清空搜索保留当前市场；查看全部股票时再将市场选为“全部市场”。
- 查交易日期：打开交易日历，选择年份和月份，或用上个月、下个月、回到本月导航。未来安排可能修订；“未采集”不是休市。首次补历史，以后维护本月至下一年年底，详见 [巨潮日历](cninfo-calendar.md)。
- 复制数据：点击一行，Ctrl 或 Shift 选择多行，再用 Ctrl+C 或“复制选中行”。复制内容带列标题，可粘贴到表格。股票刷新按“来源 + 统一代码”保持同一对象；顺序/名称变化不改变所选身份，已不在当前结果中的股票会取消选择，不自动选中占据原位置的另一只股票。选择不会隐藏保留到其他分页。
- 更新数据：打开采集任务，点击立即采集；未完成批次可从断点继续。需要放弃旧断点时使用从头重新采集。已有完整股票列表仍可查询。
- 从数据页管理任务：股票列表、财经快讯或交易日历中的“管理采集计划”会直接定位对应任务，不受任务页当前筛选影响。原筛选、页码和其他任务的未保存草稿仍保留；点击“返回原筛选”即可回到此前任务列表。
- 改自动更新频率：在任务的执行计划中选择手动、固定间隔或每日定时，填写当前方式需要的时间并保存。表格显示已保存的计划，编辑中的草稿有提示，可撤销。切换页面或状态刷新不会覆盖草稿；未保存草稿不承诺跨程序重启保留。
- 改站点访问节奏：打开采集管理中的站点访问规则，设置每个出口 IP 访问本站的最短间隔；同一 `exit_ip` 的多个代理设备共享限制。
- 改采集网络方式：在采集任务选择本机直连、代理优先或仅代理；到采集出口查看在线状态。设置从下一轮任务生效。
- 规划出口容量：打开“采集管理 → 下载资源”，选择 100、200 至 1000 台中的一档，一键生成容量推荐；当前默认 100 档为 128 个全局下载窗口和 512 MiB 缓冲。推荐只填容量草稿，不修改单响应/文件边界、每 IP 频控或任务代理开关；保存到 MySQL 后正常退出并重开软件生效，不自动打断采集。页面分别显示当前值、已保存值与待生效状态，“恢复默认”也只改草稿。网站并发设为 0 跟随全局，正数保留为更严格保护；实际并发取决于当前独立出口 IP、网站规则、预算和页数，不必等规划设备全部到齐。
- 改下载大小：同页可单独调整内存响应与文件下载大小。单响应上限防止异常大响应，不是网速限制；PDF 文件大小与内存缓冲独立。不要为增加设备数同时放大每页上限。完整推荐表及保存方式见 [下载资源边界](download-resources.md)。
- 查采集失败：运行记录的“采集记录”查看失败执行；“错误记录”按项目查看阶段、请求地址、HTTP 状态、元数据与脱敏错误原文。样本每条最多 64 KiB。完整读取时显示完整原文长度/摘要；下载提前终止时明确显示未知，以及已读正文量和脱敏样本摘要，不将片段称为完整响应。
- 查归档过程：在“归档记录”查看每个项目最近 100 条归档尝试、已处理记录、业务写入记录和批次。“已处理”包括内容相同、可信摘要确认及旧版本无需覆盖，不能当作 INSERT/UPDATE 数量；“业务写入”为 0 仍可能是一次成功归档。只有完整列表通过验证并完成事务提交或确认无需写入才算成功发布。
- 看归档是否积压：在“系统设置 → 运行状态”查看分轮扫描、已索引消息、可调度和等待重试项目。大量消息会持续分轮处理，不等下一分钟；“立即归档”启动一轮并继续后台处理，不表示队列已全部清空。一个项目失败时其消息保留，其他已发现项目仍能轮到；未知数据格式仍会全局暂停。完整股票事务不会为抢时间被拆开。
- 清理已修复错误：先修复问题并完成验证，Ctrl / Shift 选择对应错误记录，勾选确认后点击“清除已修复记录”。删除只针对选中 ID，期间新到错误保留；查看页面和下一次采集成功不会自动清除。
- 排查服务：先查看运行状态。插件管理属于高级维护，日常任务暂停应在采集任务页操作。

快捷键：Alt+1 总览、Alt+2 股票列表、Alt+3 采集任务，F1 说明文档。时间统一显示为北京时间。较小窗口下采集设置区域可滚动。

## 后台异常与恢复

“系统设置 → 运行状态 / 插件管理”区分已启用、运行异常和运行失败。归档、执行计划、代理目录或 Redis 健康监测的关键循环意外退出时，会显示运行失败；依赖这些服务的功能会提示依赖异常。普通一次采集完成、手动暂停和正常退出不会被当成关键循环故障。

发现运行失败后先查看原因并处理，再正常停用相关插件后启用，或正常退出并重开 Empire。仍持有资源的失败插件不能直接重复启动；存在依赖时按页面提示先停用依赖功能。系统不自动重启故障循环或重放写入。可恢复的连接故障仍沿用对应服务已有的重试流程，恢复后状态自动更新。插件诊断摘要只保存在本次进程内，不代替采集项目的 Redis 错误记录，也不会自动清理待归档数据。

收到网站 429 时，全部代理和本机直连共同等待；合法长冷却不会被缩短为一分钟。非法 `Retry-After` 使用默认 30 秒；超出时间表示能力的纯数字会保守阻断并提供诊断，不通过换出口绕过。单次请求仍受总超时限制，超时或取消不会清除网站冷却。跨站跳转不传递认证和 Cookie，HTTPS 降级到 HTTP 会明确失败。

## 页面扩展

页面均由内部 UI 插件通过 `PageContribution` 贡献，声明 `id`、标题、工厂、分组、排序和说明；独立一级页面使用 `top_level=True`，同组仅一页时直接打开并隐藏二级菜单。关联管理入口由贡献的 `management` 声明目标和上下文。桌面外壳负责导航、上下文投递、命令反馈及关闭流程；不承担股票查询、任务映射和调度业务逻辑。

新增页面可以注册到现有分组，不需要改侧栏硬编码列表。插件增减页面时，保留仍存在页面的控件和未保存状态；当前页面被停用时回到总览，总览不可用时选择其他可用页面。界面插件全部停用后，外壳提供恢复入口。

工作台、采集管理、股票、新闻、日历、系统管理、说明文档各有独立界面插件。停用某个界面不会停止对应采集服务，但会释放该界面的未保存草稿。普通导航与分页仍保留草稿。开发边界见 [管理界面插件](ui-plugins.md)。

## 保留规则

采集记录每项目 100 条、归档记录每项目 100 条、错误记录每项目 300 条，全部只存 Redis 内存。MySQL 保存当前股票列表、历史财经新闻、交易日历，以及任务、网站频控与下载资源配置。成功 HTTP 原文不留存；待归档的规范化业务数据先入 Redis，提交后删除对应消息。只重启应用可保留断点；Redis 服务或电脑重启后断点、下次执行时间、未归档数据和记录会丢失；已保存配置仍保留，启动后重建计划。固定间隔从启动重新计时，每日定时取下一个北京时间时间点。

## 说明文档

一级入口直接打开文档。内部按“使用指南 / 数据说明 / 技术参考”分类：使用指南讲操作，数据说明解释展示范围与时间，技术参考列字段、断点和维护参数。默认仅展示使用指南，避免数据库字段和日常操作混在一个长目录里。

右上角搜索覆盖全部分类，结果显示所属分类；清空搜索回到当前分类，切换分类会记住上次文章。股票表参考中的时间是最后实际变更批次的时间，不等于最后一次采集。实际股票数据应到“数据浏览 → 股票列表”查询。

## 大量项目的管理

采集任务支持关键字、业务分类、来源网站组与状态组合筛选，每页 25 项；右侧查看所选任务和编辑计划，窄窗口自动上下布局。网站组和采集历史也支持分页。数据页面按需创建，不随接入数量增长而全部加载。完整注册协议与验证范围见 [可扩展工作区](scalable-workspace.md)。
