# 桌面使用说明

桌面以使用目的分成四类，不把基础服务与日常数据操作混在一起。

| 分类 | 页面 | 主要用途 |
| --- | --- | --- |
| 工作台 | 总览 | 股票覆盖、数据更新时间、待入库数量、最近采集及常用跳转 |
| 数据中心 | 股票列表 | 按市场、代码、名称查询当前完整列表，复制所选股票 |
| 数据中心 | 财经快讯 | 搜索新浪新闻、筛选重点、分页阅读和复制正文 |
| 数据中心 | 交易日历 | 按月份查看交易、休市和未采集日期，检查月份完整性 |
| 采集管理 | 采集任务 | 执行或暂停任务、设置更新计划、查看进度 |
| 采集管理 | 运行记录 | 采集 / 归档 / 错误三个标签；按项目查看结果、样本和修复后的精确清理 |
| 系统管理 | 网站频控 | 管理同一网站组共享的请求间隔 |
| 系统管理 | 运行状态 | 检查服务连接、归档进度及异常，手动归档 |
| 系统管理 | 插件管理 | 按功能分类启停插件；技术诊断按需展开 |
| 系统管理 | 说明文档 | 离线搜索 Redis 键、MySQL 表和字段、配置参数及保留规则 |

## 常用操作

- 找股票：打开股票列表，选择全部市场或沪、深、北市场，输入代码或名称，按 Enter 或查询。清空搜索保留当前市场；查看全部股票时再将市场选为“全部市场”。
- 查交易日期：打开交易日历，选择年份和月份，或用上个月、下个月、回到本月导航。未来安排可能修订；“未采集”不是休市。首次补历史，以后维护本月至下一年年底，详见 [巨潮日历](cninfo-calendar.md)。
- 复制数据：点击一行，Ctrl 或 Shift 选择多行，再用 Ctrl+C 或“复制选中行”。复制内容带列标题，可粘贴到表格。
- 更新数据：打开采集任务，点击立即采集；未完成批次可从断点继续。需要放弃旧断点时使用从头重新采集。已有完整股票列表仍可查询。
- 改自动更新频率：在任务的执行计划中选择手动、固定间隔或每日定时，填写当前方式需要的时间并保存。表格显示已保存的计划，编辑中的草稿有提示，可撤销。切换页面或状态刷新不会覆盖草稿；未保存草稿不承诺跨程序重启保留。
- 改网站访问速度：打开系统管理中的网站频控。网站组页面会显示域名范围及关联任务；同一组中的插件共享设置。
- 查采集失败：运行记录的“采集记录”查看失败执行；“错误记录”按项目查看阶段、请求地址、HTTP 状态、元数据与脱敏错误原文。每条原文最多 64 KiB，页面说明是否截断，并显示原始长度和 SHA-256。
- 查入库过程：在“归档记录”查看每个项目最近 100 条归档尝试、结果、条数和批次。只有完整列表通过验证并完成事务提交才算成功发布。
- 清理已修复错误：先修复问题并完成验证，Ctrl / Shift 选择对应错误记录，勾选确认后点击“清除已修复记录”。删除只针对选中 ID，期间新到错误保留；查看页面和下一次采集成功不会自动清除。
- 排查服务：先查看运行状态。插件管理属于高级维护，日常任务暂停应在采集任务页操作。

快捷键：Alt+1 总览、Alt+2 股票列表、Alt+3 采集任务。时间统一显示为北京时间。较小窗口下采集设置区域可滚动。

## 页面扩展

页面均由内部 UI 插件通过 `PageContribution` 贡献，声明 `id`、标题、工厂、分组、排序和说明。桌面外壳负责导航、命令反馈及关闭流程，通过 `navigate(page_id)` 跳转；不承担股票查询和调度业务逻辑。

新增页面可以注册到现有分组，不需要改侧栏硬编码列表。插件增减页面时，保留仍存在页面的控件和未保存状态；当前页面被停用时回到总览。界面插件整体停用后，外壳提供恢复入口。

## 保留规则

采集记录每项目 100 条、归档记录每项目 100 条、错误记录每项目 300 条，全部只存 Redis 内存。MySQL 保存当前股票列表、历史财经新闻和交易日历。成功 HTTP 原文不留存；待归档的规范化业务数据先入 Redis，提交后删除对应消息。只重启应用可保留断点；Redis 服务或电脑重启后断点、计划、未归档数据和记录会丢失。
