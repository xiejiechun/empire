# 共享下载资源精简实施 · 2026-10-29

用户要求简单使用。本轮只保留同时下载数、下载缓冲上限和一行实际运行状态，删除桌面设备规划及容量推荐入口。维持共享下载器、代理、频控、预取、取消回收及归档背压，不增加自动调参或任务优先级。

桌面只提交两个字段，后端持配置锁合并最新完整配置并执行原校验，未展示的响应、文件、磁盘保护不变。存储格式和数据库结构不变，不重写用户已有配置。保存仅更新持久设置，不热替换在途资源；重启生效。保留已有维护工具的完整设置契约。

运行信息直接来自当前HTTP服务：在途下载、全局缓冲预留/上限、缓冲及全局窗口等待数。后者不包含站点频控或出口等待，页面明确区别；服务缺失或刷新失败显示不可用，不填零假装空闲。预留预算不是进程RSS。

表单刷新不覆盖草稿，保存期间继续编辑时旧回执不得清除新草稿。窄窗口可换行，滚轮不改数值。验收覆盖隐藏保护值保留、非法预算拒绝、SQL失败不改变配置、保存不替换当前额度，以及界面刷新/保存竞态。
