# 每日复盘全景导图

## 当前实现

入口为“市场观察 → 每日复盘”，沿用React、Ant Design、Electron外壳、明暗主题、可折叠侧栏和公共滚轮保护。页面用于收盘复盘及下一交易日前准备，六条主线为整体行情、资金流向、连板梯队、晋级断板、核心判断、次日观察。

2026-11-16整体行情和资金流向按用户授权接入真实归档；缺值显示“缺少数据来源”。资金流向展示明盘、暗盘合计及含暗盘个股流入/流出前5，板块榜按当前同花顺行业成分自行合计同日含暗盘主力资金，固定标注“按当前成分股回看”，逐行显示覆盖数量和部分覆盖；ETF净申赎保留缺值。首次进入或重启默认北京时间今天，切页保留会话选择；日期切换立即查询，显式刷新只读已有数据。日历、事实和样本口径见[真实行情契约](daily-review-market.md)。不生成持久报告、不触发采集，也不使用虚拟行情回退。

其余四条分支仅在2026-07-31展示带独立标识的虚拟样例，准备2026-08-03；其他日期显示待接入和指定缺值文案。点击“查看虚拟样例”返回，整体行情和资金仍为该日真实值。其他虚拟分支的首板分类、连板证券、判断与预案不与真实整体行情相互推导。

## 本机记录与交互

分支按需展开，点击虚拟连板证券打开收盘详情。切页保留阅读位置，日期切换回到顶部。日期滚轮不改值，页面正常滚动；行情异步回执按日期和页面生命周期核对。

观察预案按稳定ID立即保存到本机，虚拟笔记显式保存；当前会话切页或关闭编辑窗保留未保存草稿，重启只保留成功保存的内容。保存失败明确提示且不关闭编辑。本机数据只属于原虚拟样例，不写MySQL、Redis或归档队列，其他日期笔记禁用。
