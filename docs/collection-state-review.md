## 明确边界

collection_state 是最近一次 **SQL 确认** 的状态，不是 Redis 摘要的全量副本或历史流水。可信 Redis 命中不为了刷新进度再写 SQL；Redis 服务重启后，不能恢复之后仅在缓存中确认的每次核验时间或未归档断点。

股票 publication 保留最后一次业务内容变化批次，界面“更新于”不会因为重复采集而改变。日历 observed 每月只留一个版本上界，仍位于项目同一条状态行中。新闻保留历史业务数据，但不保留逐轮 SQL 运行记录。

迁移后已移除旧股票专用发布表及已迁入状态行的旧日历观测键；其必要状态已保留于 collection_state，业务数据未删除。不得用旧版程序继续写入新结构。
