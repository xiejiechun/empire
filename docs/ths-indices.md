# 同花顺当前指数及成分

## 入门与范围

来源为 https://q.10jqka.com.cn/zs/ 的完整目录及每个指数的成分接口，只保存当前状态。同一股票可以属于多个指数；目录的“重要”、字母区间及“其他”是网站分组，不冒充官方指数分类。代码原值包含数字及1A/1B等形式。来源名单按实际响应保留，不从名称推导成员，不提供权重、行情、历史调样或生效日期。

## 日常操作与生命周期

采集管理的“同花顺当前指数及成分”每天北京时间18:00完整刷新，代理优先且允许受频控的直连回退，用户保存的配置优先。数据浏览搜索“同花顺当前指数及成分”，查询指数或证券；成员视图输入完整六位来源代码按指数或证券编号精确查询，其他文字模糊匹配名称或编号。数据准备分别核验目录和当前成员。

初始化读取完整目录一次，每个指数请求一次 `/zs/detail/code/{code}/field/code/order/asc/page/1/size/10000/ajax/1/`。空分页栏、请求指数身份、连续序号、代码严格升序、链接身份、完整闭合表格及低于10000行共同构成单响应完整性证明；size参数本身不是证明。明确“暂无成份股数据”保存来源暂无状态，不推断真实零成员，不将旧成员当当前有效成员。

通用单响应需至少8MiB以容纳最大当前名单，在“采集管理 → 下载资源”保存后正常重启生效；开发已为本机保存8MiB，原512MiB共享缓冲与其他设置保持。本插件不在启动时覆盖已保存额度，用户降低额度仍按较低边界执行并报超限。

每个完整单元校验后与已入队断点原子发布，继续下一指数，不逐指数等待归档；全部入队后核对本轮最终进度且消息已处理才显示完成。下载前后失败保留最后成功入队位置，恢复从下一指数继续；已入队消息交统一归档重放，SQL提交后确认失败安全重放。Redis丢失重新读取目录并完整刷新，不用SQL最大页推断网络已完成。fresh继续尚未归档的旧轮次，随后普通轮次可刷新全部。每日全量发现目录和成员修订，无历史版本承诺。

## 存储设计卡与字段字典

固定来源ths，项目ths-indices，正式数据集index.catalog及index.members，一个项目一条collection_state。正式表stock_index（index_code ASCII6主键、name VARCHAR100、source_group VARCHAR40、members_available可空布尔、member_count无符号整数、member_hash可空SHA256）与stock_index_member（index_code ASCII6＋source_code ASCII12主键、unified_code可空ASCII9、name VARCHAR100）。成员保留来源证券编号，已识别沪深北身份结构化关联统一代码；来源未提供可确定市场的证券只保存来源身份，不猜测关联。目录及成员核心字段不放JSON；状态JSON只保存有界目录/单元摘要、观察版本和进度，最多1000指数。

正式查询：有界指数目录页，按指数读取成员，按统一证券或来源代码反查所属指数；每页200、最多500，主键游标分页。成员反查索引(unified_code,index_code)、(source_code,index_code)，不保存行情及HTTP正文。来源暂无时旧成员保留但查询标为历史参考。目录退役的指数及其成员在目录事务中移除，只替换本来源的当前关系。目录SQL确认后由统一归档器先失效该来源成员摘要再写入新目录摘要，防止移除后重新加入被旧缓存跳过。Redis失效失败保留原消息，SQL已提交后的重放仍重新声明失效，不能因本轮无新删除而漏掉。

唯一键和内容比较逐索引批量执行；相同内容不执行业务DML，只有成员、名称、分组或可用性变化才写。观察时刻仅作为本插件当前请求代次排序，不称来源版本；迟到旧代次不覆盖已确认新代次。目录与其移除关系、单指数成员与摘要、对应项目状态均各自在同事务提交。公共可信摘要命中免SQL，成功即清对应业务消息。

容量预算：目录最多1000项、每项成员少于10000，总当前关系不超过100万；一个响应取公共generic正文上限与插件8MiB上限的较小值，单消息遵守公共入队上限，超限失败不偷偷拆截。当前状态五年不按天累积，预算含索引512MiB，放大实验100000成员；成员页P95<=50ms、100000初始写入<=20秒。重复写零业务DML、少量修订批写、来源暂无及恢复、同数异集、冷/热摘要、SQL提交重放纳入验收。

迁移为独立维护入口create_index_schema.py，先核实关闭Empire及队列为0，取得既有SQL维护锁，仅新增两表，前后核对已有表数量/结构及状态摘要，启动不建表；新空库init-db使用现行schema.sql。没有旧指数表需转换，不删除已有其他业务。容量与实际来源核验分别记evidence，未完成测量不能标已验收。

## 故障与限制

登录页、重复、截断、身份不符、非完整单页和网络失败均报错，不标来源暂无，不推进对应断点。来源明确暂无的目录项仍保存，可以完成来源采集，但当前成员准备显示有限制。完整性核验目录及每项实际响应和归档证明；来源暂无、无法确定市场关联以及仅当前归属的限制列在“用途条件”，普通分析为“可用（有限制）”，历史选股仍不满足。真实漏采、集合不一致或查询失败继续阻断，不能归为来源限制。目录完整不能证明官方全世界所有指数收录；当前成员不用于还原历史选股。

## 数据浏览

先搜索指数目录并选择指数，再独立查询其成员；目录及成员均后台分页，成员计数来自正式查询。支持统一证券身份反查，保留市场避免同代码串市场；成员可跳转股票数据，指数可带指数身份跳转历史日行情。当前成员不作历史成分。
