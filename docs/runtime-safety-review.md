# 请求异常与后台健康逐项验收

日期：2026-09-26。范围为系统审计 P2-06～P2-08：异常限流响应、跨源重定向凭据、关键后台任务健康。未新增业务采集器，未调整下载容量、站点频率或任务计划；归档公平调度和 SQL 读写排队优化属于下一阶段。

## 日常行为

- 网站 429 仍冷却同组所有代理与本机直连。合法长冷却不会缩短；请求超时或取消仅释放本次资源，不清除网站冷却。
- 非法 `Retry-After` 回退 30 秒；超出时间表示能力的纯数字采用保守阻断并提供诊断。不会因数值溢出结束后台，也不会将异常 `NaN` 当成无需等待。
- 同源跳转保留原认证行为；跨源跳转剥离认证及 Cookie，禁止 HTTPS 降级到 HTTP。
- 在工作台、运行状态和插件管理查看后台异常。关键循环退出显示“运行失败”；服务暂时异常、未处理的普通后台任务错误及依赖异常显示“运行异常”。正常一次任务完成和正常停用不误报。
- 关键循环故障不自动重启，不重放可能已提交的写入。处理原因后，正常停用相关插件再启用，或正常退出并重开；尚有资源的失败插件不能直接重复启动。

## 核查结果

| 项目 | 实际实现 | 验证证据 |
| --- | --- | --- |
| 限流头校验 | 单一 `parse_retry_after` 接受 ASCII 非负整数秒或 HTTP 日期；无穷大、NaN、负值、小数及指数等非法值回退；到期日期为 0 | 7 天、1 年、2 年日期、9999 年日期、非有限值和超长数字测试 |
| 极端数值与等待 | Redis 绝对截止时间不超过精确整数上界 `2**53-1` 毫秒；超长合法整数保守饱和并记录 `cooldown_saturated/cooldown_note`。许可分段最多等待 60 秒，但不修改冷却期限 | 400/5000 位整数无解析溢出；真实 Redis 中保存有限截止时间；取消后仍保留冷却 |
| 全组冷却与回收 | 共享下载器设置组冷却，直连、独立代理 IP 不能绕过；失败与取消回收缓冲、下载槽和代理许可 | 12 项真实 Redis 隔离测试，覆盖直接路径与生产路由路径；网络全部为 Mock，无目标网站压力 |
| 跨源凭据边界 | 按协议、IDNA 主机、有效端口比较 origin；不同端口、协议、终点点号均有边界。删除请求认证/Cookie 参数并在客户端合并默认值后清理最终请求，跨源后不恢复 | 显式认证、客户端默认认证、请求头、Cookie jar、域 Cookie、跳回原站、端口 0/443/444、HTTP 升级等测试 |
| 安全跳转与文件 | HTTPS 降级拒绝，目标仍检查声明域名和频控；无凭据的正文与文件共享相同路径；无效地址异常不回显敏感目标 | 直连/代理 × 正文/文件测试，拒绝时目标未请求；取消后流关闭、额度归零、无残留临时文件 |
| 关键循环真实状态 | 归档、调度、代理发现、Redis 监测四个常驻任务标记 critical。意外返回、异常或取消均使实际插件状态 FAILED；启动时回调竞态不能覆盖失败 | 故障注入、启动竞态、三级依赖状态传播、失败后重复启动拒绝、正常停止与重新启用测试 |
| 有界且脱敏的诊断 | 每插件最多 100 条、每条 2048 UTF-8 字节；存储和日志前统一脱敏，不把异常对象/traceback 放入错误集合；界面诊断展示最近 3 条与累计数量 | 105 次失败压入后的数量/字节边界、特殊异常字符串失败、日志无原始凭据、正常单次任务不误报 |
| 页面与文档 | 工作台告警、运行状态卡、插件状态及启用按钮反映真实健康；软件内说明、桌面说明和架构同步更新 | Qt 页面断言通过；新版 EXE 正常启动，工作台实际截图核查 |

服务已有的可恢复错误处理不变；没有新增自动重启器。历史未处理的普通后台异常摘要保留到该插件正常停用，不用后续一次成功自动“消除”历史错误。关键任务退出后仍保留所属服务的资源所有权，直到显式正常停止完成；这不意味着所有业务对象和失败 Task 的内存都能在退出瞬间释放。
