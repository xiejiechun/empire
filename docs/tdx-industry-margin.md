# 通达信行业融资融券

## 如何查看

本次目标是独立的行业融资融券采集插件，默认补齐2016-01-01至来源最新日期。已接入共享下载、统一归档与正式查询；实采、历史入库与发布状态见下方验收记录。

## 数据范围与更新

来源页面 `tdxsj_rzrq_rzrqhy.html` 使用 `CWServ.tdxsj_rzrq_hy`：`["0",""]`取得最新日期，`["1","YYYYMMDD"]`取得当天完整行业集合，无分页参数。2026-10-30共享代理核实2016-01-04及2026-10-28均返回30个行业；2016-01-01和01-02返回有效空集合。最新日期为2026-10-28。来源未在响应中回显查询日期，按请求日期关联，不宣称独立日期签名。

完整单元为一个自然日的完整行业快照，保留来源有效空集合，但不能将空响应推断为休市。初始按自然日请求，避免周末推算或依赖其他采集任务漏掉实际来源记录。缺失日期依据SQL快照集合补齐；日常回看最近7个自然日，较老历史按日期序号分90个桶每日轮转，连续日常运行90天覆盖历史修订；停机期间不承诺修订发现时效。显式日期范围可补查，普通失败不升级全历史重采。

初始化完成条件为所声明范围每个日期已校验、原子入队且整轮成功清队。按日期有界预取、顺序入队，整轮入队后才等归档。Redis存活按最后已入队日期续采；Redis丢失按SQL已归档日期补缺，并执行日常回看及轮转。断点不存完整日期数组。推荐默认北京时间每天19:30执行，已有保存配置优先。

预算（不含有界重试）：首次1次最新日期请求+D次完整日期请求；日常1+缺失日期+最近7天+当日历史桶，范围去重。2016年至今约3954天，初始化约10MiB正文、约12万行业明细；普通无变化约50次/130KiB，入队每日期1条，可信摘要免SQL；新增1日只增加1个完整单元，修订仅写变化行。每请求至多2次共享重试，无认证请求。SQL丢失内存状态不触发全历史下载。按天接口由页面核实，没有已验证批量/范围接口；不把附加未支持参数作为批量能力。

## 字段与日期

设计卡：业务粒度为日期×来源行业名称。来源不提供行业代码或分类版本，名称作为来源身份，不能宣称历史时点行业成员口径。完整日期头和明细同事务，头保存规范摘要、行数及契约版本；不存逐轮运行表或成功原始响应。业务数字DECIMAL(28,8)，未知保留NULL且数据准备报告，不能填零。行业名称上限64字符，完整日期上限256行业，重复行业即失败。

正式查询：日期全行业与单行业日期范围，主键(trade_date,industry_name)，二级索引(industry_name,trade_date)，稳定游标每页最多200。完整性审计比较明细键集合、正文摘要和日期头，不仅比条数。融资融券差值查询计算为融资余额－融券余额/10000，页面在任一余额为零时直接显示零的特殊公式不作为原始事实。当前不提供行业占比派生字段。

容量：一年约1.1万行业行，五年约5.5万，2016至今约12万，按行及索引512字节保守预估约60MiB；日期头约4000条。完整日响应实测约2.6KiB。目标单页查询P95≤100ms，单日审计≤1秒；隔离容量实测见 docs/evidence/tdx-industry-margin-capacity-2026-10-30.json。

## 限制与排错

来源没有公布时刻及历史修订版本，以请求开始时刻防止旧响应覆盖，不适合严格历史版本信号回放。未知、错误、缺列、重复行业、数值超界均不推进断点；有效空日与未采集分开。空集合不能覆盖已存在的非空集合，需诊断来源变化。相同业务内容零DML，版本确认保存在每项目一条统一状态；可信摘要、SQL事务后重放及成功清队由公共归档器执行。

显式维护新增本插件表，不在启动建表；维护前核实队列及已有业务，实施和发布须避开正在进行的个股融资融券任务共享文件/数据库操作。开发实采按全部日期范围约5%抽样完整日期，固定包含2016边界、空日与最新日期；不宣称全历史实采完成。正式历史补齐独立执行。
