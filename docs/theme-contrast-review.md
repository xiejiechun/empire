# P2-21 焦点与非文本对比度验收

日期：2026-09-27。

## 已实施

- 移除列表、表格和标签栏的整块蓝色焦点外框。键盘焦点改为当前列表项左侧标记、当前表格单元格底部标记，以及当前标签的浅背景和加粗下划线；一级导航仍保留文字、浅色选中背景和左侧位置标记。
- 输入框边界调整为 `#858f9f`/白色，未选复选框边界调整为 `#747f90`/白色，滚动条滑块调整为 `#7d899a`/`#fafbfc`，按 WCAG 相对亮度公式均达到 3:1 的项目设计目标。
- 焦点色 `#2459b8`/白色超过 4.5:1。主操作、输入控件与条目焦点不只依靠轻微颜色变化，还通过边界宽度、位置标记或下划线变化表达。
- 应用启动时读取 Windows High Contrast 设置；启用时不加载 Empire 固定桌面样式，由 Qt/Windows 原生调色板接管颜色。普通模式继续使用现有品牌视觉。

## 验证

- 自动测试计算上述颜色的 WCAG 对比度，阻止关键交互边界退回低于 3:1。
- 自动测试覆盖普通样式与高对比度原生样式分支，以及条目级焦点规则。
- 880×560 和 1320×860 离屏截图已重新生成并人工查看；一级导航文字周围原生小矩形焦点框已消失，当前页面位置仍清楚。

## 边界

这些结果是项目设计基准，不是 WCAG 合规认证。Windows High Contrast、系统文本放大、不同显卡/屏幕及 Narrator/NVDA 仍需在真实桌面人工验收。高对比度设置在应用启动时读取；切换系统模式后正常重启 Empire 可确保所有已创建页面和富文本文档统一采用目标主题。
