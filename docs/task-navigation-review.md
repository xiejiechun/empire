# 采集任务两级菜单与统一运行详情

2026-10-02。用户要求采集任务使用一级、二级菜单，运行详情更统一清晰。

## 实现范围

任务页内部使用“数据来源 → 具体任务”的两级菜单，来源按贡献声明生成，任务状态位于独立列；不增加固定外壳菜单。查询仍每页最多25项，分组数量仅表示本页。选来源不执行任务命令；选任务后右侧显示该任务的运行详情与配置。刷新复用节点并保留选择、展开和滚动；定位关联任务展开来源，不影响原筛选、页码和草稿。

运行详情统一四个分区：状态与进度、时间与计划、网络、异常。当前轮次和最近轮次分开取值，缺数据不填零，来源特有指标按实际提供展示。归档确认仍由任务完成状态表达，不将100%入队比例解释为入库。错误以可复制纯文本完整显示。配置保存与撤销仅在配置标签显示，保留按任务草稿和原命令路径。

任务菜单、详情字段与页面交互分别由 task_menu.py、task_runtime.py、tasks.py负责，退役旧 task_progress.py 拼接段落。没有修改采集、调度、归档规则或数据库结构，没有手工修改业务数据，不需生命周期迁移及来源重复实采。
